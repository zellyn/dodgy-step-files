## OCCT source pointer + prose

Branch (prose-laundered): ShapeAnalysis_Shell::FreeEdges returns
the compound of edges belonging to only one face in the shell. The
lazy-init field `myFree` is reset to TopoDS_Compound() on each call
but NOT initialised with `aBuilder.MakeCompound()` first. If no free
edges are added (because the shell IS closed), the returned compound
is null rather than an empty compound — caller's `IsNull()` checks
incorrectly conclude "no free edges" via a different code path.

### Attempt 1 (wave 55, 2026-06-17) — INVALID

- **Approach**: Shell with intentionally free edges to invite the analyser.
- **Refutation**: `EDGE_LOOP('',(#400,#401,#402))` has only 3 edges

  is a CLOSED loop of edges; parser-level rejection before
  ShapeAnalysis_Shell ever runs.

## Why it's hard

Same class as Twi238: when the defect class requires *non-closed*
wire/edge topology, Part-21's EDGE_LOOP constraint blocks the
fixture. The genuine free-edges scenario needs a face wrapped in
OPEN_SHELL with edges that the shell-edge-count algorithm sees as
"only one face neighbour" — which can be encoded with PROPERLY CLOSED
EDGE_LOOPs whose edges happen to lack adjacent-face owners due to
shell layout.
