Ps003 — Single ADVANCED_FACE with same_sense flipped on outer skin

§12.3a shells / orientation (sub-class: pathological-success / single-face-flip)

P1 — silent data loss

Sources

  • deduced from ADVANCED_FACE.same_sense semantics
  • bug-report patterns "one face is inside-out", "ray-cast hits surface from wrong direction", "hole in shell where there shouldn't be one"

Description

A unit cube where five faces correctly orient outward but the TOP face has ADVANCED_FACE.same_sense=.F., effectively inverting that face's normal so it points down into the solid instead of up. Topology is consistent (every edge has degree 2), the shell is closed, and the kernel reports a valid solid. Tier-3 introspection (face-normal outward-test against a near-by interior point) reveals one face's effective normal points the wrong way.

Reproducer recipe

Unit cube with the standard 6-face / 12-edge / 8-vertex topology. The top face's ADVANCED_FACE has same_sense=.F.; the underlying PLANE.position.axis still points +Z. All loops are oriented in the "with-surface" sense.

Expected kernel behavior

Verify each face's effective outward normal is consistent with the shell's outside; flip, reject, or report the inconsistent face. A correct kernel should not silently return a solid that fails point-in-solid tests near the flipped face.

Notes

Tier-3 metric: ray cast from a clearly-exterior point along -Z toward the cube; should hit the top face's outward side first. With same_sense=.F. the outward side is now inward. Synonyms: "one face is inside-out", "ray-cast hits surface from wrong direction", "hole in shell where there shouldn't be one", "single face same_sense flipped on cube", "top face normal points down into solid".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(27) ifc=schema_n/a

Tier-3 assertions

  • n_edges_total >= 24
  • face[0].surface_type == "plane"
  • face[5].surface_type == "plane"
