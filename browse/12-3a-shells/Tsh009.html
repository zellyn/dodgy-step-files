Tsh009 — Solid built from open shell with inward-pointing outer-shell normals

Description

`MANIFOLD_SOLID_BREP` built from a shell whose face normals collectively point inward (rather than outward as a solid requires), so the computed volume is negative and the inside/outside classification is inverted. The shell is closed; its orientation is just backward.

Reproducer recipe

`MANIFOLD_SOLID_BREP` referencing `CLOSED_SHELL` whose `ADVANCED_FACE` `same_sense` flags collectively orient the shell normals inward; or build a solid from a sewn shell that closes correctly but whose orientation is backward.

Expected kernel behavior

detect the inverted orientation by checking that computed volume is positive (or by a containment test against an interior point) and flip the shell's orientation; or reject as malformed.

Notes

**See also**: Tfa034, Tsh010, Tsh015, Tsh018, Tsh032, Tsh036. Synonyms: "solid has negative computed volume", "outward face normals point inward", "inverted solid orientation", "inside and outside swapped on body", "closed shell built backwards".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CLOSED_SHELL')
  • contains(b'MANIFOLD_SOLID_BREP')
  • count_entity_def(b'ADVANCED_FACE') == 6
