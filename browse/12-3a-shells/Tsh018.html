Tsh018 — Volume orientation mismatch between `LastShape()` and parent solid

§12.3a shell-orientation

P1 — silent data loss

topology

View raw fixture (.stp) step-examples/12-3a-shells/Tsh018.stp

Sources

  • 13-quaoar.md B006 (BRepPrimAPI_MakeRevol::LastShape)

Description

Constructor returns the closing face oriented FORWARD via `LastShape()`, but the same face inside the resulting solid is REVERSED. Code using `LastShape()` to drive a follow-up operation sees an inconsistent normal direction.

Reproducer recipe

After `BRepPrimAPI_MakeRevol`, compare orientation of `LastShape()` with orientation of the equivalent face found via `TopExp_Explorer(solid, TopAbs_FACE)`.

Expected kernel behavior

heal; `LastShape()` (and `FirstShape`/`Generated`/`Modified`) should report a face with the same orientation it carries inside the parent solid.

Notes

**See also**: Tfa034, Tsh009. Synonyms: "face orientation different inside vs outside parent", "child face flipped relative to its solid", "follow-up operation sees wrong face normal direction", "API returns inconsistent orientation after revolve", "first-or-last shape disagrees with explorer".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(17) ifc=schema_n/a
