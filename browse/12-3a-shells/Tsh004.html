Tsh004 — Sheet bodies imported in place of solids (FEA pipeline)

§12.3a shell-orientation

P1 — silent data loss

round-trip topology

View raw fixture (.stp) step-examples/12-3a-shells/Tsh004.stp

Sources

  • 17-standards-bodies.md M021
  • 14-brlcad-rhino.md K023

Sender

Rhino, ICEM Surf, older CATIA workbenches, surface modellers in general

Description

STEP intended to carry a solid arrives as `OPEN_SHELL` / `SHELL_BASED_SURFACE_MODEL` because (a) writer never sewed faces into a `MANIFOLD_SOLID_BREP` or (b) edge tolerances exceeded receiver's sewing tolerance. FEA/CFD pipelines reject the body for meshing. Round-trip degradation also seen in Rhino-to-Rhino and Rhino-to-SolidWorks.

Reproducer recipe

Export from a surface-only mode; ensure no `MANIFOLD_SOLID_BREP` is emitted; adjacent face boundaries differ by tolerance > receiver's sewing tolerance.

Expected kernel behavior

heal; sew within scaled tolerance, attempt `MakeSolid`; fall back to surface model only if sew fails; report which edge gaps blocked closure.

Notes

**See also**: Gs039, Tsh001. Synonyms: "surface model imported in place of solid", "STEP gives sheet body instead of solid", "FEA mesher refuses imported body", "Rhino round-trip drops solid", "loose face boundaries prevent solid promotion".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'OPEN_SHELL')
  • contains(b'SHELL_BASED_SURFACE_MODEL')
  • count_entity_def(b'ADVANCED_FACE') == 5
