Tsh013 — Face has multiple outer wires (face needs splitting into disjoint regions)

§12.3a shell-orientation

P1 — silent data loss

Sources

  • 05-occt-shapefix.md F031 (FixSplitFace)

Description

A single face carries two or more outer wires that enclose disjoint regions of the supporting surface. The STEP spec requires exactly one outer bound per face; the input describes a multiply-connected region that should have been emitted as multiple faces sharing the same supporting surface.

Reproducer recipe

`ADVANCED_FACE` whose face bounds list contains two non-nested `FACE_OUTER_BOUND` entries.

Expected kernel behavior

split the face into multiple faces (one per outer wire) on the same supporting surface, or reject as malformed. Kernels that accept multiply-connected face descriptions implicitly must still treat the regions as topologically distinct.

Notes

Synonyms: "face has two outer boundaries", "disjoint regions packed into one face", "face covers two separate islands", "multiply-connected face needs splitting", "two outer wires on same face".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count(b'FACE_OUTER_BOUND') >= 2
  • count_entity_def(b'ADVANCED_FACE') == 1
