Description

LoadShells accepts CLOSED_SHELL with zero faces without reporting error. Empty shell silently passes validation and crashes downstream processors expecting face list.

Reproducer recipe

Create a CLOSED_SHELL with empty face aggregate: `#100=CLOSED_SHELL('empty',())`. Load via STEP reader. Call ShapeAnalysis_Shell.LoadShells(). Kernel silently accepts, no error reported.

Expected kernel behavior

Kernel must reject empty shell or emit clear validation error.
