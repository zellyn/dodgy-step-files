Tsh001 — ManifoldSolidBrep.outer references OPEN_SHELL

§12.3a shell-orientation

P1 — silent data loss

Sources

  • 03-occt-tests.md R046

Sender

unspecified producers; pattern attested in OCCT bug 25169

Description

STEP files emit a `MANIFOLD_SOLID_BREP` whose `outer` shell is an `OPEN_SHELL`, contradicting the schema's requirement that the outer shell be a `CLOSED_SHELL`.

Reproducer recipe

`#N=MANIFOLD_SOLID_BREP('',#M);` where `#M=OPEN_SHELL('',(..));`.

Expected kernel behavior

heal: accept with warning; if topology demonstrably closes, promote to closed shell; otherwise treat as compound of faces.

Notes

**See also**: N026, Tsh002, Tsh003, Tsh004, Tsh005, Tsh006. Synonyms: "solid built from open shell instead of closed", "manifold solid wrapping non-manifold geometry", "solid body has leaks", "outer boundary of solid is not watertight", "schema says closed but file says open".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'OPEN_SHELL')
  • contains(b'MANIFOLD_SOLID_BREP')
  • count_entity_def(b'ADVANCED_FACE') == 6
