Description

An `OPEN_SHELL` with TWO `ADVANCED_FACE`s — a `CYLINDRICAL_SURFACE` (radius 5, axis +Z) quarter-patch spanning theta:[0,90deg], z:[0,10], and a `PLANE` at x=5 (normal +X, matching the cylinder's own outward radial normal at theta=0) spanning y:[-5,0], z:[0,10]. Both faces reference the SAME `EDGE_CURVE` entity for their shared boundary (the vertical generatrix line x=5,y=0,z:[0,10]) — the corpus's standard shared-edge-reuse convention. A plane tangent to a cylinder along one of its own generatrices is the textbook G1 (smooth, non-sharp) shared-edge case, unlike Bo025's mis-tagged-G1-edge framing (that class inverted: this fixture's edge should end up correctly classified, testing the *encode* path itself).

Reproducer recipe

Two `ADVANCED_FACE`s (one `CYLINDRICAL_SURFACE`, one `PLANE` tangent to it along a generatrix) sharing exactly one `EDGE_CURVE` entity for their common boundary, with the plane's normal matching the cylinder's own outward radial normal along that line.

Expected kernel behavior

on default STEP import, classify the shared edge's continuity as tangent (G1) rather than leaving it at the un-encoded sharp-corner default (C0), and expose that classification via the standard continuity-query API (the loaded shape’s per-edge continuity query).
