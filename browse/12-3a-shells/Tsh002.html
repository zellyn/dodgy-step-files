Tsh002 — FACETED_BREP.outer references OPEN_SHELL

§12.3a shell-orientation

P1 — silent data loss

Sender

unidentified producer (file submitted to OCCT forum)

Description

The `FACETED_BREP` schema requires a `CLOSED_SHELL`, but some producers reference an `OPEN_SHELL` instead. The receiver aborts with "not supported", losing the geometry entirely.

Reproducer recipe

`#N=FACETED_BREP('',#M);` where `#M=OPEN_SHELL('',(..));`.

Expected kernel behavior

reject with precise diagnostic, or accept by promoting the shell to closed when its topology actually closes within tolerance.

Notes

**See also**: Tsh001. Synonyms: "faceted solid imported as empty", "faceted brep with non-watertight shell", "tessellated solid loses geometry on import", "faceted body declared closed but isn't", "solid aborts with not-supported error".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Closure intent

solid (defect kind: gap) — authored as a closed solid; openness is the defect — heal it shut.

Byte assertions

  • contains(b'OPEN_SHELL')
  • contains(b'FACETED_BREP')
  • count_entity_def(b'ADVANCED_FACE') == 6

Tier-3 assertions

  • n_faces_total == 0
