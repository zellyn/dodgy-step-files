Tsh066 — Same `CLOSED_SHELL` referenced from two `MANIFOLD_SOLID_BREP` entities

§12.3a shells/orientation (sub-class: shell sharing)

P1 — silent data loss

spec-violation topology

View raw fixture (.stp) step-examples/12-3a-shells/Tsh066.stp

Sources

  • bug-reporter language: "two solids point at the same shell", "shell shared between bodies"
  • deduced from EXPRESS — neither AP203 nor AP242 explicitly forbids the cross-reference

Sender

deduced — assembly exporters that emit one body per part definition and two bodies that happen to instance the same template shell, or buggy writers that re-use a shell handle without cloning

Description

An EXPRESS-level CLOSED_SHELL entity is referenced as the `outer` attribute of two distinct MANIFOLD_SOLID_BREP entities. The spec describes shells as belonging to one solid (the outer shell of MANIFOLD_SOLID_BREP); cross-referencing the same shell from two solids creates an aliasing situation. A receiver that builds in-memory topology by walking from each solid into its shell produces two solids both pointing at the same shell object; modifications to one (orientation flip, healing) affect the other. Receivers that copy-on-read the shell produce two independent copies and lose the producer's intent (if any) of "shared shell". Bug-reporter language: "two solids share a shell", "shell aliasing", "mutating one solid changes another", "same shell in two solids".

Reproducer recipe

one CLOSED_SHELL `#100` containing six face references; two MANIFOLD_SOLID_BREP entities `#200=MANIFOLD_SOLID_BREP('a',#100)` and `#201=MANIFOLD_SOLID_BREP('b',#100)`; both referenced from the same SHAPE_REPRESENTATION.

Expected kernel behavior

detect the shared-shell aliasing and either reject as malformed (recommended, solid identity becomes ambiguous), copy-on-read with a documented policy, or refuse to mutate either solid until the alias is resolved.

Notes

Distinct from Tsh051 (REPRESENTATION_MAP-style shell sharing, that path is documented). Tsh066 is the direct-reference variant. Synonyms: "shell shared between bodies", "manifold-solid-brep alias", "two solids point at the same shell", "mutating one solid changes the other", "shell aliased between MANIFOLD_SOLID_BREPs".

Expected validation
