Tsh245 — Purpose-built equidistant candidate tie-break AND reciprocity-asymmetric configuration

Description

An `OPEN_SHELL` with SIX `ADVANCED_FACE`s in two spatially isolated (100mm apart in Y) groups. Group 1: reference edge R (y=0) has TWO candidates genuinely equidistant at 0.6mm (B above, C below) — both within a 1.0mm sewing tolerance of R, but 1.2mm apart from each other (beyond tolerance, so B and C never see each other), forcing the `arrMinDist` tie-break to pick exactly one. Group 2: D (reference), E (0.01mm from D), F (0.011mm from D, only 0.001mm from E) — D's nearest candidate is E, but E's OWN nearest candidate is F, not D, a genuine reciprocity failure.

Reproducer recipe

Six face-hosted free edges in two isolated groups: three genuinely-equidistant/near-equidistant parallel candidates for a tie-break test, and three candidates at staggered distances (D-E < D-F, but E-F < D-E) forming a reciprocity-asymmetric chain.

Expected kernel behavior

for equidistant candidates, deterministically select exactly one winner via the closest-sampled-point tie-break, never both and never neither; for a reciprocity-asymmetric configuration, only accept a pairing when it is a genuine mutual best-match, walking to the next candidate (or accepting the reciprocal pair among the OTHER edges) rather than forcing a lopsided merge.

Notes

Live-verified (this worktree's OCP/OCCT 7.8.1, runtime the sewing stage(tolerance=1.0)` scaffold): Group 1 — the tie-break resolves to a single definite winner: R merges with C (resulting shared-edge midpoint y≈-0.3, `nfaces==2`) while B (y=0.6, `nfaces==1`) is left free/unmerged (which of B/C wins is an `arrMinDist`-ordering implementation detail, not asserted directionally — the load-bearing fact is that exactly one wins, not both/neither). Group 2 — D remains free/unmerged (y=100.0, `nfaces==1`) while E and F — whose distance IS each other's mutual minimum — merge into one shared edge (y≈100.0105, `nfaces==2`), exactly the reciprocity-failure/mutual-match behavior this class targets. Group 1's non-test (triangle apex) leg edges use deliberately very different depths (3/40/-40mm) — an earlier attempt with near-equal apex depths (3/3.6/-3.6mm) let R/B/C's near-parallel leg edges spuriously chain-merge with each other via the unrelated ordinary gap-merge mechanism, contaminating the tie-break test; fixed by making the legs diverge rapidly. Synonyms: "equidistant candidate tie-break", "arrMinDist closest-point selection", "reciprocity-asymmetric candidate chain", "mutual best-match sewing candidate", "non-reciprocal nearest-neighbor edge merge".
