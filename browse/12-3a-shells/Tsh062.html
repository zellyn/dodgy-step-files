Description

A class of long-running regressions in same-surface face merging manifests as "valid input → invalid output" where the failure mode varies per case (missing face, duplicated edge, inverted normal) but the input pattern is consistent: complex Boolean-result shape with non-trivial topology. Typical fixture precondition: an OPEN_SHELL of multiple ADVANCED_FACEs (e.g., 5) each on its own CYLINDRICAL_SURFACE, and each cylinder having a degenerate seam edge where the start and end VERTEX_POINTs share identical coordinates but are separate entities (e.g., #104 and #106 both at (1,0,0)). The kernel-branch defect is "no post-merge invariant check"; the merge writes its result without running validity check.

Reproducer recipe

Compound from Boolean-fuse of 5 CYLINDRICAL_SURFACE faces at random angles, often with degenerate seam edges (distinct VERTEX_POINTs sharing coords); pass through unify; check shape validity (no duplicate edges, every edge incident to ≤ 2 faces, every face's wires closed).

Expected kernel behavior

Reject with E_INVALID_TOPOLOGY diagnostic, or heal and accept: every shape-modifying operation runs a topology validity check on its output; if the output is invalid, the algorithm reports failure (rejects) and leaves the input shape unchanged.

Notes

**See also**: Tsh053, Tsh057. Synonyms: "face merge produces invalid topology", "no post-merge validity check", "valid input invalid output after merge", "Boolean-fuse result corrupted by unifier", "merge of cylinder faces with degenerate seam fails".
