Tsh022 — Non-manifold STEP loses XCAF attributes (color/PMI) on read

§12.3a shell-orientation

P1 — silent data loss

topology

View raw fixture (.stp) step-examples/12-3a-shells/Tsh022.stp

Sources

  • 08-occt-gitlog.md G098, G099 (Mantis 31485, 32914)

Description

STEP reader's non-manifold path skipped XCAF attribute application; STEP export in non-manifold mode lost all but one face / some compound parts.

Reproducer recipe

STEP file with `NON_MANIFOLD_SURFACE_SHAPE_REPRESENTATION` carrying colors; or non-manifold OCCT shape exported via `write.step.nonmanifold 1`.

Expected kernel behavior

Heal and accept: coerce colours / styles through the non-manifold path; emit and bind every face on export.

Notes

**See also**: M045. Synonyms: "non-manifold STEP loses colors and PMI", "color attributes dropped on multi-shell import", "PMI lost when reading non-manifold body", "XCAF metadata not applied to non-manifold parts", "writer drops faces in non-manifold export".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • count_entity_def(b'ADVANCED_FACE') == 2
