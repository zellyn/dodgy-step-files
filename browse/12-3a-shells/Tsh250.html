Tsh250 — Two stacked full-period cylindrical shells whose facing seam candidate carries only one explicit 2D curve representation

Description

Two independent `OPEN_SHELL`s, each one full-period wraparound `ADVANCED_FACE` on a `CYLINDRICAL_SURFACE` (matching this corpus's established closed-cylinder-face pattern: bottom full circle, one vertical seam-line edge, top full circle reversed, second vertical seam-line edge reversed) — i.e. each face's own top/bottom boundary is a genuine closed (start==end) seam edge. The lower shell sits directly below the upper shell with a gap comfortably within sewing tolerance, so their facing seam edges (the lower shell's top boundary, the upper shell's bottom boundary) are a live, reachable merge candidate pair. The lower shell's candidate seam edge is built with only ONE explicit 2D curve representation (the forward direction only) instead of the dual forward-and-reversed pair a merged seam participant needs.

Reproducer recipe

`shell_lower` (`CYLINDRICAL_SURFACE` radius 5, z:[0,4]) whose top boundary is an `EDGE_CURVE` wrapping a `SURFACE_CURVE` with a single `PCURVE` (u:[0,2*pi] forward only); `shell_upper` (same cylinder geometry, z:[4.0005,8.0005], a 0.0005 gap) whose bottom boundary is an ordinary `EDGE_CURVE` referencing its 3D `CIRCLE` directly (no explicit 2D curve entity at all).

Expected kernel behavior

when a closed/periodic seam edge participates in a merge, preserve both its forward and reversed 2D-curve representations on the resulting shared edge, since a periodic surface maps the same edge to two different locations in its own parameter space depending on which side it is approached from; discarding one representation silently destroys the surface's seam continuity at that edge.

Notes

Live-verified (this worktree's OCP/OCCT 7.8.1, runtime sewing scaffold, non-manifold mode enabled): both shells load independently as live, reachable shapes (2 faces / 8 edges / 16 vertices, no defect-driven translation failure of any kind); the sewing operator finds `NbContigousEdges()==3` and genuinely merges the facing seam pair down to a single shared edge (2 faces / 8 edges after merging, one fewer free-edge pair than before) at a tight, gap-proportional achieved tolerance — confirming the near-gap seam candidate pair is a real, reachable merge opportunity, not a dead scaffold, with the single-2D-curve seam edge as the actual participant under test. Synonyms: "seam edge single pcurve merge", "closed surface seam dual representation", "periodic edge forward reversed pcurve", "stacked cylinder seam merge", "missing reversed seam pcurve". Provenance tier: bytes-sufficient.
