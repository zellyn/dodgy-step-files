Tsh253 — Two adjacent (not coincident) coplanar faces whose shared-boundary candidate is traversed in opposite directions on each side

Description

Two `ADVANCED_FACE`s in one `OPEN_SHELL`, each its own unit square, adjacent (not coincident) and coplanar: Face A occupies one unit square, Face B occupies an adjacent unit square offset by a genuine 0.0005mm gap, within sewing tolerance. Both faces use the ordinary outward-normal traversal convention — under that convention, Face A's boundary edge along the shared line is traversed in one direction while Face B's corresponding boundary edge is traversed in the opposite direction: the "one candidate is effectively reversed relative to the other" pairing case, arising here from perfectly ordinary, correctly-oriented adjacent-face geometry rather than any input defect.

Reproducer recipe

`OPEN_SHELL` with two `ADVANCED_FACE`s: Face A unit square with boundary edge traversed start-to-end in the +X direction; Face B an adjacent unit square (0.0005mm gap) whose corresponding boundary edge is traversed in the -X direction under the same outward-normal convention.

Expected kernel behavior

compute the correct endpoint correspondence for the two candidate edges according to their actual relative orientation (crossing the pairing when one edge runs opposite the other, rather than assuming a fixed first-to-first pairing), and reuse an already-shared endpoint rather than creating a redundant new one when an endpoint is already common to a prior merge.

Notes

Live-verified (this worktree's OCP/OCCT 7.8.1, runtime sewing scaffold): the pair merges cleanly (`NbContigousEdges()==1`, `NbMultipleEdges()==0`) into a genuinely valid, non-degenerate 2-face shell (both faces retained; the resulting edge-to-face-count profile shows six ordinary free edges plus exactly one edge now shared by both faces), the shared edge's achieved tolerance `0.000525` (gap-proportional) — sharply distinct from the sole prior fixture's outcome, where the equivalent merge instead collapses the whole shape to an empty result. This is a second, independent demonstration of the same cross-pairing mechanism landing on a genuinely valid output. Synonyms: "reversed edge orientation merge", "cross pairing endpoint correspondence", "adjacent face opposite traversal direction", "sewing endpoint pairing valid result", "shared boundary reversed sense merge".
