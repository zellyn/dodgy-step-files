Tsh076 — Shell-count escalation on decomposition

§12.3a (shells)

topology

Sources

  • OCCT method line ShapeFix_Shell.Perform:102 (Perform_at102)

Description

Input shell decomposition by GetShells() creates 3+ closed sub-shells, escalating NbShells count unexpectedly. Downstream logic assuming single output shell breaks.

Reproducer recipe

Create a CLOSED_SHELL containing three disconnected cubes (three independent face clusters with no shared edges). Call ShapeFix_Shell.Perform(). Observe NbShells increases from 1 to 3, breaking orientation-fix logic that expects single shell.

Expected kernel behavior

Kernel must reconcile multi-shell output or emit error if input cannot be treated as single shell.

Expected validation

occt=unknown/unknown gmsh=unknown ifc=schema_n/a

Tier-3 assertions

  • n_faces_total == 3
