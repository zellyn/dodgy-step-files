Tsh042 — `bad vertex`: vertex misplaced relative to incident edges

Sender

TransMagic Diagnostic Part 2 doc

Description

The `VERTEX_POINT` coordinate does not coincide with the curve evaluation at the edge's parameter endpoint(s) — wire orientation/snap defect at corners.

Reproducer recipe

`EDGE_CURVE` referencing a `LINE` from (0,0,0) to (10,0,0) but with start `VERTEX_POINT` at (0.001, 0.001, 0); offset both ends similarly.

Expected kernel behavior

heal — snap vertex to curve endpoint within tolerance; if outside, mark tolerant edge or reject.

Notes

**See also**: Gs030, Tfa019, Twi011. Synonyms: "vertex coordinate doesn't match curve endpoint", "corner snap defect at edge ends", "vertex offset from line by tolerance", "wire vertex misplaced relative to underlying line", "endpoint position disagrees with curve evaluation".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Tier-3 assertions

  • face[0].surface_type == "plane"
  • n_edges_total >= 4
  • n_vertices_total >= 8
  • face[0].sliver_aspect_max_min > 1e6
