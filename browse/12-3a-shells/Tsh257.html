Description

A `RECTANGULAR_COMPOSITE_SURFACE` (inside a bare `GEOMETRIC_SET`) has two `SURFACE_PATCH` segments: a GOOD patch whose `parent_surface` is a `RECTANGULAR_TRIMMED_SURFACE` wrapping a `PLANE` (a genuine `Geom_BoundedSurface`, `[0,5]x[0,5]`), and a BAD patch whose `parent_surface` is a raw, un-trimmed `PLANE` entity directly — an illegal type for `surface_patch.parent_surface` (EXPRESS type `bounded_surface`; `PLANE` alone is an elementary, unbounded surface). The low-level STEP entity reader hard-flags the bad `SURFACE_PATCH` ("Entity has illegal type") and it never resolves, so the per-patch loop simply never produces a face for it, while the good patch's face is built normally.

Reproducer recipe

`#6=RECTANGULAR_TRIMMED_SURFACE('',#5,0.0,5.0,0.0,5.0,.T.,.T.)` (`#5` a `PLANE`); `#7=SURFACE_PATCH(#6,.CONTINUOUS.,.CONTINUOUS.,.T.,.T.)` (good). `#12=PLANE('bad_patch_surface',#11)` (raw, unbounded); `#13=SURFACE_PATCH(#12,.CONTINUOUS.,.CONTINUOUS.,.T.,.T.)` (bad — illegal `parent_surface` type). `#14=RECTANGULAR_COMPOSITE_SURFACE('tsh257_rcs',((#7),(#13)))`, wrapped in `GEOMETRIC_SET('tsh257_gs',(#14))` inside a `MANIFOLD_SURFACE_SHAPE_REPRESENTATION`.

Expected kernel behavior

the bounded-surface translation step is only reachable for patches whose `parent_surface` resolved to a valid surface entity of bounded kind; a patch whose declared attribute type is wrong is dropped by the low-level reader before ever reaching that step, and the surrounding composite-surface per-patch loop simply produces one fewer face in its output compound rather than failing the whole composite surface or the whole model.

Notes

Live-verified (this worktree's OCP/OCCT 7.8.1): the low-level entity-check pass on this fixture shows a hard `F:SURFACE_PATCH: Parameter n0.1 (parent_surface) : Entity has illegal type` check specifically on the bad patch's entity, confirming the low-level reader itself rejects it (not merely a downstream geometric-construction failure). The reader's root-transfer step nonetheless returns 1 transferred root and 1 output shape, with the resulting shape carrying exactly 1 face / 4 edges (the trim-rectangle boundary the face-builder auto-generates for the surviving patch) / 8 (raw) vertices, `face[0].surface_type == "plane"`, `brepcheck.valid == True` — confirming the good patch alone survived and the bad patch was silently skipped, not fatal to the model. Synonyms: "RectangularCompositeSurface drops failed patch", "surface_patch illegal parent_surface type skipped", "composite surface partial continuation", "one bad patch doesn't sink the whole composite surface", "bounded_surface type violation silently dropped".
