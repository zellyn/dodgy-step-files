Tsh012 — Mixed `.T.`/`.F.` flags on `ORIENTED_EDGE` mismatched against parameter direction

§12.3a shell-orientation

P1 — silent data loss

Description

`EDGE_CURVE.same_sense` boolean missing or illegal-formatted leaves an uninitialized bool, leading to non-deterministic edge direction. Generic boolean enum parsing defaults to true if value is not `.T.`/`.F.`.

Reproducer recipe

`ADVANCED_FACE → EDGE_CURVE` with omitted/`.U.`/stripped `same_sense` boolean.

Expected kernel behavior

Warn and accept: coerce the default to `.T.` and emit a warning; normalize deterministic initialization across compilers.

Notes

Synonyms: "uninitialized boolean flag in edge curve", "missing T or F orientation flag", "edge same-sense field is unset or unknown", "edge direction non-deterministic between runs", "ORIENTED_EDGE flag corrupted to .U.".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'.U.')
  • contains(b'EDGE_CURVE')
  • count_entity_def(b'ADVANCED_FACE') == 1
