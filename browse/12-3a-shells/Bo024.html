Bo024 — Closed shell whose face orientations imply negative volume

Sender

Description

A `MANIFOLD_SOLID_BREP` references a closed shell whose faces are collectively oriented inward; the divergence theorem applied to the shell yields a negative volume. The kernel cannot decide which side is "inside" without flipping. Bug-reporter language: "solid has negative volume", "shell normals point inward", "kernel says solid is inside-out".

Reproducer recipe

A six-face cube `CLOSED_SHELL` where all six face `same_sense` flags are set so normals point toward the center.

Expected kernel behavior

Compute volume via divergence; heal by flipping the outer shell if negative, or reject.

Notes

**See also**: Tsh009. Distinct: Tsh009 captures the same input pattern; this entry captures the kernel's decision point; a closed-solid orienter that has the option to flip versus reject. Synonyms: "solid has negative volume", "shell normals point inward", "kernel says solid is inside-out", "all face normals point to centre", "divergence theorem returns negative".
