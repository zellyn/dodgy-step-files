Tsh067 — Inner void shell extends beyond outer shell extent (void poking through)

§12.3a shells/orientation (sub-class: BREP_WITH_VOIDS containment)

Sources

  • 16-iso-spec ISO 10303-42 §BREP_WITH_VOIDS (the void-shells must be entirely contained inside the outer shell)
  • bug-reporter language: "STEP void escapes the part", "inner shell pokes out"

Sender

deduced — Boolean-cut exporters that emit a BREP_WITH_VOIDS where the cut tool's bounding shell extends past one face of the host part

Description

BREP_WITH_VOIDS expresses a solid with internal cavities: an outer CLOSED_SHELL plus one or more inner CLOSED_SHELLs (the voids). The spec implicitly requires each inner shell to be entirely inside the outer shell — a void cannot exit the part. A producer that boolean-subtracts a long pin-shaped tool whose extent exceeds the host part along one axis, and emits the result as BREP_WITH_VOIDS without trimming the tool's shell, leaves a void shell whose extent pokes through one face of the outer shell. Topology is inconsistent: at the face where the void pokes out, the outer face has a hole the void enters but the void's exit through that face is unmodelled (or modelled as a separate face that contradicts the outer-shell closure). Bug-reporter language: "inner shell escapes the outer", "void pokes through face", "BREP_WITH_VOIDS not contained".

Reproducer recipe

outer CLOSED_SHELL is a 10x10x10 mm cube. Inner CLOSED_SHELL is a 2x2x15 mm tall pin shell aligned along Z, centred at the cube's centre — the pin extends 2.5 mm above and below the cube's top and bottom faces. Both shells reference the same Z-axis. A BREP_WITH_VOIDS entity wraps both.

Expected kernel behavior

validate that each void shell is geometrically contained in the outer shell; reject when a void shell pokes through. Tolerance handling: if the void's protrusion is below the working precision, heal by trimming the void to the outer-shell boundary; if measurable, reject and name the offending face.

Notes

Synonyms: "void escapes part", "BREP_WITH_VOIDS protrusion", "inner shell exceeds outer".
