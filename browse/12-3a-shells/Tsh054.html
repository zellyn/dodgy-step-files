Tsh054 — Merging adjacent same-surface faces crashes when input has chained placements

Description

A compound built from a sub-shape via location chain (e.g., assembly child positioned via `MAPPED_ITEM`) is fed to a same-surface face merge. The algorithm tries to modify a sub-shape that is shared across instances, raising "shape is modified and removed simultaneously" in debug builds and segfaulting in release.

Reproducer recipe

Compound containing two `MAPPED_ITEM` instances of the same `MANIFOLD_SOLID_BREP` at different placements. Both share the same underlying topology pointers. Run face unification on the compound.

Expected kernel behavior

same-surface face merging must operate on a deep copy of the input topology, never mutating shapes shared across instances; or reject compounds with shared sub-topology.

Notes

**See also**: Tsh048. Synonyms: "face merge crashes on chained placements", "shape modified and removed simultaneously error", "segfault when merging compound with shared topology", "mutating shared sub-shape during unification", "MAPPED_ITEM instances corrupt face merge".
