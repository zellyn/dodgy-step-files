Tsh254 — Genuine cross-item shared EDGE_CURVE: identical entity reused by two SHELL_BASED_SURFACE_MODEL items in one non-manifold representation, orientation reversed

Existing fixture M045 hits more than one raw candidate only incidentally (an unrelated attribute-loss demonstration) and its shells were independently grep-verified to each carry their OWN `EDGE_CURVE` entities — no genuine cross-shell entity sharing.

Description

Two hinge-like `ADVANCED_FACE`s — `face_a` on the `z=0` plane, `face_b` on the `x=5` plane — each wrapped in its own `OPEN_SHELL`/`SHELL_BASED_SURFACE_MODEL`, listed as two SEPARATE items (not merged into one SBSM) directly inside one `NON_MANIFOLD_SURFACE_SHAPE_REPRESENTATION`. Both faces' `EDGE_LOOP` reference the SAME `EDGE_CURVE` entity (`#16`, named `shared_hinge_edge`, running `(5,0,0)`→`(5,1,0)`) for their common boundary — `face_a` traverses it forward (`.T.`), `face_b` traverses it in reverse (`.F.`) — a genuine single-entity, cross-item, opposite-orientation reuse, distinct from M045's per-shell entity duplication.

Reproducer recipe

`face_a`: unit-rectangle-ish plane `(0,0,0)-(5,0,0)-(5,1,0)-(0,1,0)`, `z=0`, whose second boundary edge is `EDGE_CURVE('shared_hinge_edge',#8,#9,#15,.T.)` (`#16`). `face_b`: plane `x=5`, boundary `(5,1,0)-(5,0,0)-(5,0,1)-(5,1,1)`, whose FIRST boundary edge is `ORIENTED_EDGE('',*,*,#16,.F.)` — the identical `#16` entity, reversed. Each face in its own `OPEN_SHELL`/`SHELL_BASED_SURFACE_MODEL`; both SBSM items listed together as `NON_MANIFOLD_SURFACE_SHAPE_REPRESENTATION('',(#41,#66),#9060)`.

Expected kernel behavior

when non-manifold reading is active, the second (and subsequent) reference to an already-translated `EDGE_CURVE` resolves to the identical previously-built edge, with orientation reversed to match the new context's `ORIENTED_EDGE` sense, rather than being independently re-translated into a geometrically-coincident but topologically-distinct duplicate edge.

Notes

**Empirical finding (live-verified, decisive, this worktree's OCP/OCCT 7.8.1)**: verified directly against the non-manifold-mode entity cache's actual scoping — a `SHELL_BASED_SURFACE_MODEL` item creates one shared per-item translation cache for ALL shells it directly contains (so shells merged into one SBSM would hit the generic already-bound-entity reuse path instead, NOT the cited NM-specific branch); listing the two SBSMs as separate top-level items of one `NON_MANIFOLD_SURFACE_SHAPE_REPRESENTATION` gives each its own fresh per-item cache while sharing the SAME non-manifold-mode entity map across items — exactly the scoping the cited branch requires. Confirmed via a direct reader load with non-manifold reading enabled: a shape-traversal map over the resulting shape shows exactly one edge shared by both faces (`n_faces_total=2`, edges drop from the unmerged 8 to 7, vertices from 16(raw)/8(distinct) to 6 distinct) — the identical edge object, not a coincidentally-equal duplicate. With non-manifold reading left at its default (off, as used by this corpus's standard tier-3 harness), the NM-specific reuse path is inactive and each face independently re-translates `#16`'s geometry into its own edge (8 edges, no sharing) — the Tier-3 fields below describe this DEFAULT read; the cross-item reuse is a supplementary, explicitly-enabled-mode finding, consistent with this corpus's established convention for non-manifold-mode-gated mechanisms (see Tsh248-250). Synonyms: "shared EDGE_CURVE across shells", "non-manifold entity identity reuse", "cross-shell edge dedup with orientation reversal", "already-bound edge reused under non-manifold mode", "hinge edge shared by two independent shells".
