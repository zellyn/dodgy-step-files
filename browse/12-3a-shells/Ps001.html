Ps001 — Negative-volume cube: every face normal points inward

Sources

  • deduced from MANIFOLD_SOLID_BREP semantics
  • bug-report patterns "STEP file has negative volume", "model imports with reversed normals", "mass-properties says volume = -1000mm^3"

Sender

not sender-specific; observed when a writer normalizes faces using a wrong convention or after an in-place "flip-all-normals" debug op leaks into a release.

Description

A topologically closed CLOSED_SHELL whose every constituent face has its supporting surface's stored normal pointing into the volume rather than out. Loop orientations are internally consistent with the flipped surface frames, so edge-degree-2 and orientation-coherence checks pass. Kernel accepts the file silently; tier-3 introspection (signed volume integral, ray-cast-from-far-away parity) reveals signed volume is negative; i.e., the "solid" is actually the complement of the intended cube.

Reproducer recipe

A unit cube with 8 vertices, 12 line edges, 6 PLANE surfaces. Each PLANE's AXIS2_PLACEMENT_3D.axis points toward the cube center rather than away. Each face's edge-loop is consistent with that flipped axis. Wrap as MANIFOLD_SOLID_BREP and reference from ADVANCED_BREP_SHAPE_REPRESENTATION.

Expected kernel behavior

Compute signed volume (or equivalent enclosure parity) and detect negative orientation. Either flip all face normals to restore positive volume, reject as malformed, or expose the signed-volume measurement so downstream code can decide. Should not silently report a positive mass or a positive enclosed volume.

Notes

Tier-3 metric: signed-volume integral over the closed shell. A clean unit cube returns +1.0; this fixture returns -1.0. Synonyms: "STEP file has negative volume", "model imports with reversed normals", "mass-properties says volume is negative", "all face normals point inward", "cube comes in as its complement".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(27) ifc=schema_n/a

Tier-3 assertions

  • n_edges_total >= 24
  • brepcheck.valid == true
  • face[0].surface_type == "plane"
  • face[5].surface_type == "plane"
