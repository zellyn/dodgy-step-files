Gp046 — ShapeFix_Edge.FixVertexTolerance face-context null underestimates multi-surface tolerance

§12.2a (pcurves)

crash geometry

View raw fixture (.stp) step-examples/12-2a-pcurves/Gp046.stp

Sources

  • deep-pass v3 record matching OCCT method/branch (see file comment)

Description

Edge shared by a PLANE and a CYLINDRICAL_SURFACE; the shared vertex is bound to both surfaces. When FixVertexTolerance runs with face context null, it computes vertex tolerance using only one of the surfaces, underestimating the required value compared to the multi-surface case.
