Gp196 — Seam edge whose two banks are declared as 2D circles: the forward bank cannot be determined and the edge is hard-failed

  • a `Geom2d_Circle` is neither (it derives from `Geom2d_Conic`), so both downcasts fail and the initial 0 is returned. Also `StepToTopoDS_TranslateEdgeLoop.cxx:667-675`, which resets `done` and swallows a failed edge whose STEP start and end vertex entities are the same object.

Description

A closed-cylinder face is bounded by the canonical four-entry loop — bottom circle, seam forward, top circle reversed, seam reversed — so the seam `EDGE_CURVE` is referenced TWICE inside the one `EDGE_LOOP`, the formal-seam encoding. Its geometry is a `SEAM_CURVE` carrying two DISTINCT `PCURVE`s, one per bank at u=0 and u=2π, but each of those pcurves' definitional representation holds a 2D `CIRCLE` rather than the usual 2D `LINE`. The two banks are then of a 2D curve kind from which no traversal direction can be extracted, so which bank is the forward one for this edge/wire/face orientation is genuinely indeterminate — and the receiver refuses to guess. Every prior fixture in this class (Gs193, Gp013, Gp011, Gs028, Twi022, Gp190) translates successfully; none reaches this branch. The seam edge's start and end vertices are deliberately distinct `VERTEX_POINT`s (z=0 and z=1) because a same-entity start/end (a full-circle seam, Gp011's shape) is swallowed by a separate equal-vertices recovery path and would hide the failure.

Reproducer recipe

`CYLINDRICAL_SURFACE` radius 1, axis +Z. Seam 3D geometry `LINE` (1,0,0)→(1,0,1). Each bank: `AXIS2_PLACEMENT_2D` at `(u_bank, 0.5)`, `CIRCLE('seam_bank_u0_circle_pcurve',#plc,0.5)` (and `seam_bank_u2pi_circle_pcurve` at u=2π) — both circles genuinely pass through their bank's two seam endpoints `(u_bank,0)` and `(u_bank,1)` — wrapped in `DEFINITIONAL_REPRESENTATION` + `PCURVE` on the cylinder. `SEAM_CURVE('',#line3d,(#pc_u0,#pc_u2pi),.PCURVE_S1.)`; `EDGE_CURVE('indeterminate_seam_edge',#v_bottom,#v_top,#seam,.T.)`; `EDGE_LOOP('',(#oe_bottom_circle,#oe_seam_T,#oe_top_circle_F,#oe_seam_F))` → `FACE_OUTER_BOUND` → `ADVANCED_FACE` → `OPEN_SHELL` → `SHELL_BASED_SURFACE_MODEL`.

Expected kernel behavior

when the two banks of a seam cannot be ordered, the edge is hard-failed and reported rather than silently assigned an arbitrary bank; the failure then propagates to the wire ("at least one edge failed") and the face is left without an outer bound, so nothing downstream inherits a guessed parametrisation.

Live-verified (2026-07-31, this worktree, OCP/OCCT 7.8.1): the transfer check list carries " Seam curve not mapped" TWICE — once per traversal of the twice-referenced seam edge — followed by " Edge with equal vertices failed, scipped" (the two full-circle boundary edges), "At least one edge failed : wire not done", " EdgeLoop not mapped to TopoDS" and "No Outer Bound : Face not done": exactly the cascade the cited lines predict. The transferred shape is therefore the cylinder face with no wire at all — `n_edges_total == 0`, `n_vertices_total == 0`, face area 8e+100 (the unbounded natural-surface placeholder). That placeholder IS the claim here, as for Tfa252, so this entry is listed in the tier-3 placeholder lint's intentional-placeholder set. Perturbation control (byte-level A/B): replacing each pcurve's 2D `CIRCLE` with a 2D `LINE` spanning the same two bank endpoints — nothing else changed — makes all six check messages vanish and the face translate normally (1 wire, 4 edges, 8 vertices, zero failures).
