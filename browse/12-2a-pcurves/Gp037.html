Gp037 — Pcurve projection produces infinite line instead of bounded

§12.2a pcurves

crash geometry

View raw fixture (.stp) step-examples/12-2a-pcurves/Gp037.stp

Sources

  • OCCT MANTIS#0026198 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A projection of a 3D curve onto a surface produces a 2D curve that extends infinitely in the parametric domain instead of being bounded to the input curve's parameter range. Downstream consumers (face-bound check, mesher) read the unbounded curve and either crash or produce infinite tessellation.

Reproducer recipe

3D curve segment with parameter range `[0,1]`; project onto plane. Resulting pcurve has parameter range `[-∞, +∞]`.

Expected kernel behavior

projection range matches input range exactly; never produce unbounded pcurves from bounded inputs.

Notes

**See also**: Gp035. Synonyms: "pcurve projection produces unbounded line", "projection emits infinite parameter range", "bounded 3D curve becomes infinite pcurve after projection", "unbounded pcurve crashes mesher", "projection range doesn't match input curve range".
