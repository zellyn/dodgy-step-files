Gp045 — Edge copy during SameParameter recomputation inherits stale parameter range when curve is BSpline.

§12.2a

geometry

View raw fixture (.stp) step-examples/12-2a-pcurves/Gp045.stp

Sources

  • synthesized — no external source cited

Description

FixSameParameter copies EDGE_CURVE to new TEdge but preserves old range bounds. New BSpline's actual knot domain differs from preserved bounds, causing parameter mismatch between 3D and 2D curves. Geometry: PLANE host; 3D B-spline degree 2, knots (0.0, 0.333, 0.667, 1.0); matching PCURVE B-spline.

Reproducer recipe

Expected kernel behavior

Edge copy trap: parameter range bounds become stale when BSpline geometry is recomputed. SameParameter recomputation fails to detect and correct the range corruption.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Tier-3 assertions
