Gp038 — Vertex 3D point and pcurve do not match within tolerance

§12.2a pcurves

P1 — silent data loss

Sources

  • OCCT MANTIS#0025634 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

An edge's vertex point in 3D and the pcurve evaluated at the corresponding parameter disagree beyond vertex tolerance. The edge passes 3D-curve-vs-vertex check (because 3D curve does match vertex) but fails 2D-pcurve check.

Reproducer recipe

Edge with vertex V at `(1.0, 0.0, 0.0)`; 3D curve is a line from `(1.0, 0.0, 0.0)` to `(2.0, 0.0, 0.0)`. Pcurve on the hosting face evaluates at parameter 0 to UV `(0.5, 0.0)` whose 3D image is `(1.05, 0.0, 0.0)` — beyond vertex tolerance.

Expected kernel behavior

Reject if either fails: vertex-pcurve consistency check separate from vertex-3D-curve check; both must pass independently.

Notes

**See also**: Twi060, Twi088, Twi059. Synonyms: "vertex 3D point and pcurve disagree at endpoint", "pcurve evaluation at edge endpoint differs from vertex", "vertex-pcurve consistency check fails", "edge passes 3D check but fails 2D check", "UV at parameter doesn't lift to vertex 3D position".
