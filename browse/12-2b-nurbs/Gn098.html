Description

ShapeAnalysis_Curve.IsPlanar exactly-2-points

Reproducer recipe

Expected kernel behavior

accept, but diagnose the ambiguity: a 2-control-point (degree-1) curve, i.e. a straight line segment, does not by itself determine a unique plane -- any plane containing the line satisfies a planarity test trivially. A kernel evaluating planarity for a 2-pole curve should recognize the input is under-determined for that question, and either defer to the plane it is otherwise embedded in (its host surface, if any) or flag the check as inapplicable, rather than reporting an arbitrary default plane as if it were meaningful.
