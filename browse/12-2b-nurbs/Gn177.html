Description

A single `ADVANCED_FACE` on a `B_SPLINE_SURFACE_WITH_KNOTS` (degree 2×1, 3×2 control net) encodes an EXACT quarter-circle profile (radius 2.0, classic 3-pole rational-quadratic weights `(1.0, sqrt(2)/2, 1.0)`) extruded straight along Z (the second, degree-1 direction, uniform weight, genuinely polynomial). The complex `RATIONAL_B_SPLINE_SURFACE` instance is genuinely rational — live-verified (`Geom_BSplineSurface::IsVRational()==True`, non-uniform weight array; OCCT's own internal `urational`/`vrational` naming is a documented historical swap — see `Geom_BSplineSurface.cxx:22` `// jct : 19-01-99 ; permutation de urational et vrational dans Rational.` — so the "rational" flag lands on the profile direction empirically) — not a uniform-weight polynomial surface written in rational form. A target consumer whose importer only accepts non-rational (polynomial) B-spline surfaces cannot represent this profile exactly; it must re-approximate. This is orthogonal to Gn011 (excess DEGREE) and Gn026 (continuity restriction): here degree (2) and segment count (1×1) are both trivially within any reasonable cap, and continuity is not at issue — only the rational/weighted representation itself is the trigger.

Reproducer recipe

`(B_SPLINE_SURFACE(2,1,((p1,p2),(p3,p4),(p5,p6)),.UNSPECIFIED.,.F.,.F.,.F.) B_SPLINE_SURFACE_WITH_KNOTS((3,3),(2,2),(0.0,1.0),(0.0,1.0),.UNSPECIFIED.) BOUNDED_SURFACE() GEOMETRIC_REPRESENTATION_ITEM() RATIONAL_B_SPLINE_SURFACE(((1.0,1.0),(0.7071067811865476,0.7071067811865476),(1.0,1.0))) REPRESENTATION_ITEM('name') SURFACE())` as `ADVANCED_FACE.face_geometry`, boundary a 4-edge loop (two exact `TRIMMED_CURVE`-over-`CIRCLE` isoparametric edges at the two Z-extremes, two straight `LINE` isoparametric edges at the two profile extremes).

Expected kernel behavior

A receiver enforcing a polynomial-only B-spline surface constraint must detect `IsURational()||IsVRational()` and re-approximate via `GeomConvert_ApproxSurface` (or equivalent) within a stated tolerance, producing a surface with both rationality flags false, rather than silently passing the rational surface through or rejecting the file outright.
