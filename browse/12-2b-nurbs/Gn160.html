Description

Periodic B-spline curve with parameter wrapping

Reproducer recipe

Expected kernel behavior

accept and heal: a periodic degree-2 curve's own period is 1.0, and a projection or parameter-lookup routine can validly return exactly 1.0 (the period value) for a point at the seam, rather than the equivalent 0.0. A kernel must treat a returned parameter equal to the full period as equivalent to 0.0 on a periodic curve (wrap it), especially when building an EDGE_CURVE whose vertices are declared at parameters 0 and 1 across the same seam -- failing to wrap can make the edge's two endpoint parameters look distinct when they in fact reference the same physical point.
