Fi007 — Fillet leaks off the boundary of its host face

§12.7 feature defects (sub-class: fillet domain overflow)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/Fi007.stp

Sources

  • OCCT BRepFilletAPI_MakeFillet documentation (fillet-leaks-off-face) (uncovered class evidence)

Sender

deduced — OCCT uncovered-class sweep

Description

The rolling-ball trace for a fillet leaves the parametric domain of one of the adjacent faces before reaching the contour endpoint. Bug-reporter language: "fillet runs off face", "fillet leaks", "fillet exceeds face boundary".

Reproducer recipe

A small face adjacent to the spine; the fillet radius requires the rolling ball to leave the face's UV domain.

Expected kernel behavior

Heal and accept: truncate fillet at the face boundary; emit diagnostic.

Notes

Synonyms: "fillet overshoots face", "fillet runs off face", "fillet leaks past face boundary", "rolling-ball escapes parametric domain".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(3) ifc=schema_n/a

Tier-3 assertions

  • face[0].area < 1e-3
  • n_edges_total >= 1
  • face[0].surface_type == "plane"
  • n_vertices_total >= 2
