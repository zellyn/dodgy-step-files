M108 — AP238 freeform_milling_operation without surface-tolerance attribute

  • deduced from ISO 10303-238 §5.8 freeform_milling_operation surface-tolerance requirement

Sender

deduced — STEP-NC publisher omitting surface-deviation tolerance attribute

Description

A `FREEFORM_MILLING_OPERATION` is declared without an associated surface-deviation tolerance (chord-tolerance / scallop-height). The CAM consumer either invents a default (often loose, leaving visible cusps) or rejects the operation. Bug-reporter language: "AP238 freeform op has no tolerance", "STEP-NC scallop height missing", "surface finish quality unspecified".

Reproducer recipe

`FREEFORM_MILLING_OPERATION($, $, $, $, $, $)` — all optional tolerance attributes left as `$`.

Expected kernel behavior

reject as ambiguous; or apply a documented default and warn.

Notes

Synonyms: "freeform tolerance missing", "AP238 surface deviation unspecified", "freeform milling no chord tolerance", "scallop-height attribute absent". Synonyms: "freeform tolerance missing", "AP238 surface deviation unspecified".
