M032 — Validation property name not in CAx-IF list / mismatches associated general_property name

Description

`property_definition.name` does not match a recognized CAx-IF validation-property keyword, or a user-defined-attribute `general_property.name` differs from the linked `property_definition.name`.

Reproducer recipe

GVP whose `name` is `'volume mm3'` instead of `'volume'`.

Expected kernel behavior

Warn and accept: warn; ignore unrecognized property.

Notes

Synonyms: "GVP name not in CAx-IF list", "validation property name unrecognized", "general_property name mismatch", "non-standard validation property name".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'volume mm3')
  • contains(b'GENERAL_PROPERTY')
  • contains(b"'Volume'")

Tier-3 assertions

  • shape_null == True
