M060 — External reference resolves to the same file as the main file

Description

An assembly references an external STEP file via a `DOCUMENT_FILE` link, but the resolved path equals the main file's path. The reader recurses into itself. Bug-reporter language: "external reference loops", "self-reference STEP", "external file is same as main".

Reproducer recipe

A `DOCUMENT_FILE` whose `id` points back at the file's own filename.

Expected kernel behavior

Detect identity and skip with warning; or treat as a no-op reference.

Notes

Synonyms: "STEP self-reference loop", "external reference loops", "external file is same as main", "DOCUMENT_FILE points to self". **See also**: A012, Ad052.
