M042 — Color override at root label not applied (regression)

Description

STEP color attached to root label was lost in OCCT 7.5/7.6 (regression from 6.8).

Reproducer recipe

STEP file with color on root product, expressed as `STYLED_ITEM` on top-level shape.

Expected kernel behavior

Heal and accept: color override mechanism works through assemblies/parts/instances. Must not silently drop root-level overrides.

Notes

Synonyms: "root color override lost", "color regression OCCT 7.5", "STEP color at root not applied", "label color override dropped". **See also**: A018, A019.

Expected validation

occt=empty/empty gmsh=signal(11) ifc=schema_n/a

Byte assertions

  • contains(b'STYLED_ITEM')
  • contains(b'NEXT_ASSEMBLY_USAGE_OCCURRENCE')
  • contains(b'COLOUR_RGB')

Tier-3 assertions

  • shape_null == True
