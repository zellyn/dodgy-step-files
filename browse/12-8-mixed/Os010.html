Os010 — ThruSections loft profiles have inconsistent edge counts

§12.8 (sub-class: loft profile edge mismatch)

Sender

deduced — OCCT uncovered-class sweep

Description

Two loft profiles are both closed wires but with different edge counts (3 edges vs 5 edges). The "ruled" lofting algorithm needs a 1-to-1 correspondence between profiles' edges. Bug-reporter language: "loft profiles inconsistent", "loft edge count mismatch".

Reproducer recipe

Profile 1: a triangle (3 edges). Profile 2: a pentagon (5 edges). Both closed.

Expected kernel behavior

Resample profiles to a common edge count, or reject.

Notes

Synonyms: "loft can't pair edges", "loft profiles inconsistent", "loft edge count mismatch", "ThruSections profiles have different edge counts". **See also**: Os009.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
