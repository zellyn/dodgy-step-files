M153 — AP210 buried via has only one terminating layer reference

§12.8 mixed (sub-class: AP210 buried via termination)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M153.stp

Sources

  • 16-iso-spec ISO 10303-210 §6 (buried_via two-endpoint invariant)
  • bug-reporter language: "AP210 buried via one end", "PCB via dangling layer", "ECAD buried via missing termination".

Sender

deduced — ECAD exporter that lost one termination during via-class promotion (through-hole -> buried)

Description

A buried `VIA_DEFINITION` is declared with a single terminating `LAMINATE_OR_PLY_DEFINITION`. A buried via must terminate at two distinct internal plies; with only one termination, the via is dangling - it begins at one layer and goes nowhere. Bug-reporter language: "AP210 buried via single end", "PCB via missing endpoint".

Reproducer recipe

`VIA_DEFINITION('dangling_via',..,(ply_inner_2))` with `DESCRIPTIVE_REPRESENTATION_ITEM('via_kind','BURIED')`.

Expected kernel behavior

validate buried vias have exactly two termination plies; reject or warn.

Notes

Synonyms: "buried via dangling", "AP210 via half-defined", "ECAD via single endpoint".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'VIA_DEFINITION')
