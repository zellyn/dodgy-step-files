M027 — Surface-sampling-point validation property failure

§12.8 (sub-class: validation-property)

P1 — silent data loss

Sources

Description

A finer-grained validation than volume/area: a set of (u,v,XYZ) sample points is embedded; on retrieval the receiver evaluates the surface at the same (u,v) and verifies XYZ match. Catches local NURBS reparametrization issues invisible to a volume checksum.

Reproducer recipe

A B-spline surface re-fit during translation passes the volume check but fails several surface-sampling-point checks.

Expected kernel behavior

archive-reject on failure; CAD-to-CAD warn only.

Notes

Synonyms: "surface sampling validation fails", "validation property fails check", "(u,v,XYZ) sample point mismatch", "NURBS reparametrization breaks GVP". **See also**: M026, N031.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'COMPOUND_REPRESENTATION_ITEM')
  • contains(b'SHAPE_ASPECT')

Tier-3 assertions

  • shape_null == True
