M039 — STYLED_ITEM not parented under MDGPR/DRAUGHTING_MODEL (Inventor)

§12.8 (sub-class: appearance)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M039.stp

Sources

  • 08-occt-gitlog.md (G003)
  • OCCT ec661e4
  • Mantis 0024159

Sender

Autodesk Inventor 2014

Description

Inventor emits `STYLED_ITEM` entities not parented under `MECHANICAL_DESIGN_GEOMETRIC_PRESENTATION_REPRESENTATION` or `DRAUGHTING_MODEL`, and OCCT skipped them, dropping all colors.

Reproducer recipe

STEP file with bare `STYLED_ITEM` entities at top level.

Expected kernel behavior

heal — accept and apply styles even without a presentation-representation parent.

Notes

Synonyms: "STYLED_ITEM not under MDGPR", "Inventor styled_item dropped", "presentation parent missing", "all colors lost on Inventor STEP". **See also**: A018, A020.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(27) ifc=schema_n/a

Tier-3 assertions

  • face[0].surface_type == "plane"
  • face[5].surface_type == "plane"
