M005 — "Number of facets" validation property must include flat triangles dropped on import

§12.8 (sub-class: validation-property + tessellation)

Description

Some receivers strip degenerate or near-flat triangles on import. The "Number of Facets" tessellated validation property counts what the writer wrote, including those triangles. Receivers that drop them then report a mismatch.

Reproducer recipe

Build a tessellated solid with degenerate triangles (zero-area / collinear). Attach a `tessellated validation property` representation with name `'number of facets'` whose `integer_representation_item` value includes them.

Expected kernel behavior

count degenerate triangles when validating; do not silently strip.

Notes

Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT crashes (`signal(11)`). The crash is on the kernel side — the file is spec-conformant Part-21.
