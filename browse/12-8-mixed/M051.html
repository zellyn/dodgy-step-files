M051 — Bare GEOMETRIC_SET / GEOMETRIC_CURVE_SET with non-geometric children or mesh-as-surfaces

Sender

OpenVSP (free-standing surfaces); aero/preliminary-design tools; legacy producers

Description

STEP `GEOMETRIC_SET`/`GEOMETRIC_CURVE_SET` may aggregate items beyond curve/surface/point (axis placements, scalar measures), or may contain a free-standing set of bounded surfaces with no shell/face superstructure. Many importers reject as "no solid found" or skip silently. Files containing only wireframe data or only bounded surfaces lose visibility.

Reproducer recipe

STEP file with only `GEOMETRIC_SET` referring to `B_SPLINE_SURFACE_WITH_KNOTS` instances and no shell/face boundary, or `GEOMETRIC_SET` aggregating `LINE`+`AXIS2_PLACEMENT_3D`+text.

Expected kernel behavior

accept; emit one face/surface object per surface; offer optional stitching pass; preserve as wireframe shape; never silently drop.

Notes

Synonyms: "bare GEOMETRIC_SET silent-empty", "wireframe-only file appears empty", "GEOMETRIC_CURVE_SET with non-geometric children", "bare surface set rejected as no solid". **OCC behavior**: silently produces empty results on bare `GEOMETRIC_SET` / `GEOMETRIC_CURVE_SET` files without surfacing the wireframe-only or surface-only nature of the input; kernel mishandling; the catalog above forbids silent drop.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'DESCRIPTIVE_REPRESENTATION_ITEM')
