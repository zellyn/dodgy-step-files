M188 — AP238 deburring_operation references edge not present in workpiece

§12.8 mixed (sub-class: AP238 deep machining)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M188.stp

Sources

  • 16-iso-spec ISO 10303-238 §5.8 deburring_operation edge-presence invariant
  • bug-reporter language: "AP238 deburring of phantom edge", "STEP-NC deburr edge missing from part", "phantom edge in deburring op".

Description

A `DEBURRING_OPERATION` references an edge feature that isn't part of the `WORKPIECE`'s geometry. The deburring path is computed against a phantom edge; the tool either swings into empty space or contacts the workpiece in an unintended location. Bug-reporter language: "AP238 deburring edge not on part", "STEP-NC phantom edge in deburring", "deburr op references missing edge".

Reproducer recipe

a `WORKPIECE` whose declared edges are `#500` and `#501`; a `DEBURRING_OPERATION` whose target edge is `#510` (declared in file but not part of the workpiece's edge list).

Expected kernel behavior

validate deburring-op edge reference against workpiece geometry; reject as malformed.

Notes

Synonyms: "AP238 deburring phantom edge", "STEP-NC deburr edge missing from workpiece", "deburring op references foreign edge", "phantom edge in deburring sequence".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'phantom_edge_NOT_ON_PART')
