M114 — AP209 hex element with aspect ratio greater than 10000

Sender

deduced — adaptive remesher producing a "ribbon" hex along a thin-feature edge

Description

A linear hex element has dimensions e.g. `1000.0 × 0.1 × 0.1` (mm). Aspect ratio is 10000:1. Stiffness matrix is severely ill-conditioned; bending stresses diverge from any analytical reference. Bug-reporter language: "AP209 sliver element", "FEM hex aspect ratio enormous", "extremely thin hexahedron".

Reproducer recipe

A `VOLUME_3D_ELEMENT_DESCRIPTOR` with corner node coordinates spanning 1000mm in X but 0.1mm in Y and Z.

Expected kernel behavior

warn on aspect-ratio outliers (> threshold); let user opt to keep or reject element.

Notes

Synonyms: "sliver element", "AP209 thin hex", "high aspect ratio".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
