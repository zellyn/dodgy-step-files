M047 — Texture / bitmap (IMAGE_TEXTURE / TEXTURE_MAPPING) loss on translation

§12.8 (sub-class: appearance + raster textures)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M047.stp

Sources

  • 11-translator-vendors.md (W025)
  • HOOPS Exchange 2025.1.0 SDHE-21230

Description

Image textures and UV mappings lost when exporting to a tessellated format that supposedly supports them. Out-of-scope for pure-STEP kernels but indicates expected coverage.

Reproducer recipe

A face with a `TEXTURE_MAPPING` referencing an `IMAGE_TEXTURE` exported through a STEP→glTF pipeline.

Expected kernel behavior

heal/accept; preserve UV and image binary; warn on unsupported texture types.

Notes

Synonyms: "texture lost on translation", "IMAGE_TEXTURE not preserved", "UV mapping dropped", "bitmap material lost".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(4) ifc=schema_n/a

Byte assertions

  • contains(b'IMAGE_TEXTURE')
  • contains(b'TEXTURE_MAPPING')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 4
