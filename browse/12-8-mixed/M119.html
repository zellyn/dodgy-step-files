M119 — AP209 shell element with zero plate thickness

Sources

  • deduced from AP209 §6 surface_3d_element_descriptor thickness positivity

Sender

deduced — FEA exporter omitting / zeroing thickness on a default shell template

Description

A `SURFACE_3D_ELEMENT_DESCRIPTOR` for a `linear_quadrilateral` shell carries an associated thickness measure of `0.0`. Bending stiffness K = E*t³/12(1-v²) collapses to zero. Out-of-plane deflections diverge. Bug-reporter language: "AP209 shell zero thickness", "FEM plate has no bending stiffness", "shell thickness missing".

Reproducer recipe

A surface element descriptor whose thickness `MEASURE_WITH_UNIT` carries `POSITIVE_LENGTH_MEASURE(0.0)` (which is itself schema-illegal — POSITIVE means > 0).

Expected kernel behavior

reject zero thickness; or warn and substitute a default minimum thickness.

Notes

Synonyms: "zero-thickness shell", "AP209 plate degenerate", "shell element zero thickness", "FEM plate has no bending stiffness", "shell thickness measure is 0".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'STRUCTURAL_ANALYSIS_DESIGN')
  • contains(b'SURFACE_3D_ELEMENT_DESCRIPTOR')
  • contains(b'POSITIVE_LENGTH_MEASURE(0.0)')
