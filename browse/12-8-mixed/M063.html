Sender

deduced — OCCT uncovered-class sweep, Pass C

Description

A `SHAPE_REPRESENTATION` has no `GEOMETRIC_REPRESENTATION_CONTEXT` attached, or the context is missing units. The reader silently applies default units (typically mm). Bug-reporter language: "STEP no units, defaulted", "kernel guessed units", "model 1000× wrong".

Reproducer recipe

A `SHAPE_REPRESENTATION` with `context_of_items` referencing a context that lacks `LENGTH_UNIT`.

Expected kernel behavior

Reject as malformed (units are mandatory in AP203/214/242), or warn loudly and require explicit user confirmation of the assumed unit.

Notes

Synonyms: "STEP no units, defaulted", "kernel guessed units", "model 1000x wrong", "no unit context, default mm applied", "SHAPE_REPRESENTATION lacks unit context". Common cause of "model is 1000× wrong" symptom.
