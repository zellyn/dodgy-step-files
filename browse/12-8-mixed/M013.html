M013 — Saved-view supplemental geometry split across multiple CGRs

§12.8 (sub-class: supplemental)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M013.stp

Sources

  • 02-caxif.md
  • PMI v4.1 §9.4.2.2
  • Supplemental Geometry §5.5

Description

A part may have many supplemental elements but only some belong in a particular Saved View. Recommended pattern is one global CGR with all elements PLUS additional `shape_representation` instances tagged with `description_attribute = 'supplemental geometry subset'`.

Reproducer recipe

Two saved views; ten supplemental planes total; views 1 and 2 each show a different subset of three planes via two `shape_representation`s tagged with the magic description.

Expected kernel behavior

Heal and accept: kernel reads the magic description and treats those `shape_representation`s as supplemental subsets.

Notes

Synonyms: "saved view supplemental split", "CGR scattered across views", "supplemental geometry in multiple representations", "saved-view subset CGR". **See also**: Pmi017.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONSTRUCTIVE_GEOMETRY_REPRESENTATION')
  • contains(b'supplemental geometry subset')

Tier-3 assertions

  • shape_null == True
