M146 — AP210 drill diameter exceeds pad diameter (annular ring inverted)

§12.8 mixed (sub-class: AP210 via geometry)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M146.stp

Sources

  • 16-iso-spec ISO 10303-210 §6 (via_definition drill_diameter vs pad_diameter)
  • IPC-2222 annular-ring rules
  • bug-reporter language: "AP210 drill bigger than pad", "PCB via no annular ring", "ECAD via cuts through pad".

Sender

deduced — ECAD exporter that wrote pad sizes from a default library while drill sizes came from per-via overrides

Description

A `VIA_DEFINITION` declares a drill_diameter (e.g. 0.5 mm) larger than the surrounding pad_diameter (0.3 mm). The drilled hole is wider than the copper pad - there is no annular ring of copper around the drill. The via cannot be electrically connected. Bug- reporter language: "AP210 annular ring inverted", "PCB drill > pad", "ECAD via no copper ring".

Reproducer recipe

`VIA_DEFINITION('inverted_via', LENGTH_MEASURE(0.5),..)` with pad geometry of diameter 0.3 declared via `PROPERTY_DEFINITION`.

Expected kernel behavior

validate drill_diameter < pad_diameter; reject or warn.

Notes

Synonyms: "annular ring negative", "PCB pad cut through", "AP210 drill > pad".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

  • contains(b'ELECTRONIC_ASSEMBLY_INTERCONNECT_AND_PACKAGING_DESIGN')

  • contains(b'pad_diameter')
