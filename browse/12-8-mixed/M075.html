M075 — AP238 selective control-flow references unresolved branch executable

deduced — STEP-NC publisher with broken downstream linking

Description

A `SELECTIVE` (or other control-flow construct: `PARALLEL`, `IF_STATEMENT`) lists branch executables in its `its_elements` list, but one or more of those entity ids are not declared in the file. The branch cannot execute because there is nothing to dispatch to. Bug-reporter language: "STEP-NC selective references unknown branch", "machining program has dangling subroutine reference".

Reproducer recipe

`SELECTIVE('material_branch',(#100,#999,#101,#998),$)` where `#999` and `#998` are not declared.

Expected kernel behavior

detect missing references; reject the program as un-executable or skip the malformed branches and warn.

Notes

Synonyms: "missing subroutine", "STEP-NC dangling executable", "selective branch unresolved", "control-flow target not declared".

occt=empty/empty gmsh=empty ifc=schema_n/a
