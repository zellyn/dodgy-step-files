M175 — AP238 drilling_operation tool axis not normal to feature face

§12.8 mixed (sub-class: AP238 deep machining)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M175.stp

Sources

  • 16-iso-spec ISO 10303-238 §5.8 drilling_operation tool-axis-vs-feature-normal invariant
  • bug-reporter language: "AP238 drill axis tilted", "STEP-NC drilling skewed hole", "drill not perpendicular to face".

Description

A `DRILLING_OPERATION` declares a tool_axis vector tilted 30 degrees from the feature's hole-axis. The controller either drills a slanted hole (mismatching the design intent) or refuses the operation because the tool axis isn't normal to the feature face. Bug-reporter language: "AP238 drill operation tilted", "STEP-NC drill axis off normal", "drilling tool not perpendicular".

Reproducer recipe

a `ROUND_HOLE` whose locator's axis is `(0,0,1)`; a `DRILLING_OPERATION` whose `tool_axis` is `(0.5, 0.0, 0.866)` (30 deg tilt).

Expected kernel behavior

validate tool_axis against the targeted feature's hole-axis; reject or warn.

Notes

Synonyms: "AP238 drilling tilted axis", "STEP-NC drill not normal to face", "drilling op axis mismatch with feature", "drill operation skewed".
