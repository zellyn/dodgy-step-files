M124 — AP209 fea_model includes element referencing a node outside its node-set

§12.8 mixed (sub-class: AP209 model node-set membership)

P1 — silent data loss

assembly

Sources

  • deduced from AP209 §6 fea_model.its_node_set / its_element_set consistency

Sender

deduced — FEA exporter writing element-set and node-set from separate sources without intersection check

Description

A `FEA_MODEL_3D` declares a `NODE_GROUP` of nodes `(n1, n2, n3)` as `its_node_set` and a `VOLUME_3D_ELEMENT_DESCRIPTOR` referencing nodes `(n1, n2, n3, n4)` in `its_element_set`. Node `n4` is outside the model's declared node set. The element implicitly extends the model with `n4` (silently expanding the active node set), or solver assembly fails. Bug-reporter language: "AP209 element refers to outside node", "FEM model node-set inconsistent", "element outside model".

Reproducer recipe

`FEA_MODEL_3D` with a 3-node `its_node_set` and a 4-node tet element in `its_element_set`.

Expected kernel behavior

validate that all element nodes lie within the model node-set; reject or auto-expand with diagnostic.

Notes

Synonyms: "AP209 model node-set leak", "element outside FEA model", "fea_model node-set inconsistent", "element references node not in node_set", "FEM element extends model implicitly". Synonyms: "AP209 model node-set leak", "element outside FEA model".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
