M147 — AP210 surface-mount component oriented on wrong board side

§12.8 mixed (sub-class: AP210 component placement orientation)

Sources

  • 16-iso-spec ISO 10303-210 §6 (component placement constraints)
  • bug-reporter language: "AP210 SMD wrong side", "PCB BGA on bottom", "ECAD top-only part placed bottom".

Sender

deduced — ECAD exporter that emitted placement transforms from a flipped-board view without re-validating mount-side constraints

Description

A component placement transform on the bottom side (origin at z=0, normal = -Z) is applied to a part declared as a top- only SMD package (e.g. BGA). The footprint resolves below the board surface; the BGA balls face away from the PCB. The placement is fundamentally invalid. Bug-reporter language: "PCB component wrong side", "AP210 mount-side violation".

Reproducer recipe

`AXIS2_PLACEMENT_3D` with `DIRECTION (0.0,0.0,-1.0)` placed at z=0; component PRODUCT carries `DESCRIPTIVE_REPRESENTATION_ITEM('mount_constraint','TOP_ONLY')`.

Expected kernel behavior

validate placement side against mount_constraint; reject or warn.

Notes

Synonyms: "AP210 wrong-side placement", "BGA on bottom", "PCB SMD orientation error".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'ELECTRONIC_ASSEMBLY_INTERCONNECT_AND_PACKAGING_DESIGN')
  • contains(b'AXIS2_PLACEMENT_3D')
  • contains(b'TOP_ONLY')
