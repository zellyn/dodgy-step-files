M132 — AP203 material-class APPLIED_GROUP_ASSIGNMENT without a material reference

§12.8 (sub-class: AP203 material specification missing)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M132.stp

Sources

  • 16-iso-spec ISO 10303-203 §5.6 (material assignment via group)
  • bug-reporter language: "AP203 material group has no material", "PDM part says steel but no grade", "material classification incomplete".

Sender

deduced — PDM exporter using a generic GROUP scaffold without binding the specific material

Description

An `APPLIED_GROUP_ASSIGNMENT` classifies a part as belonging to a 'material' GROUP, but the GROUP has no associated `MATERIAL_DESIGNATION` or specification reference. The part is tagged as having a material without identifying which material. Bug-reporter language: "material specification missing", "AP203 material grade not declared", "PDM material attribute empty".

Reproducer recipe

`GROUP('material_class',..)` with no `MATERIAL_DESIGNATION` link; `APPLIED_GROUP_ASSIGNMENT(group,(part_PD))`.

Expected kernel behavior

detect material groups missing a designation; warn, drop the assignment, or reject.

Notes

Synonyms: "AP203 material missing", "material spec stub", "PDM material grade absent".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONFIG_CONTROL_DESIGN')
  • contains(b'APPLIED_GROUP_ASSIGNMENT')
  • count_entity_def(b'MATERIAL_DESIGNATION') == 0

Tier-3 assertions

  • shape_null == True
