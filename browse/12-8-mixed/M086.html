M086 — AP210 via drilled outside the conductor / board outline

§12.8 mixed (sub-class: AP210 via geometry)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M086.stp

Sources

  • deduced from AP210 §6 via_definition geometric containment

Sender

deduced — ECAD exporter writing via at design-grid coordinates before clipping

Description

A `VIA_DEFINITION`'s drill location places the via center at a point outside the board outline / `LAMINATE_OR_PLY_DEFINITION`'s boundary. The drill physically misses the substrate. Downstream impedance / continuity checks fail because the via doesn't pierce any copper. Bug-reporter language: "PCB via off-board", "AP210 via outside outline", "ECAD via drilled into air".

Reproducer recipe

Board outline (0.30, 0.30) mm; `VIA_DEFINITION` with axis center (50, 50, 0).

Expected kernel behavior

validate via location against ply outlines; reject, clamp into the board, or warn.

Notes

Synonyms: "via outside board", "drill misses substrate", "AP210 via off-board", "drill location outside outline", "PCB via doesn't pierce copper".

occt=empty/empty gmsh=empty ifc=schema_n/a
