M158 — AP210 assembly footprint pitch conflicts with component-library footprint

§12.8 mixed (sub-class: AP210 footprint override conflict)

P1 — silent data loss

View raw fixture (.stp) step-examples/12-8-mixed/M158.stp

Sources

  • 16-iso-spec ISO 10303-210 §6 (component placement vs library cross-check)
  • bug-reporter language: "AP210 pin pitch wrong", "PCB SOIC pads don't match SSOP component", "ECAD footprint override".

Sender

deduced — ECAD exporter that wrote a per-design footprint override against a library entry of a different package

Description

An assembly's local `PRODUCT_DEFINITION` declares an SOIC-8 footprint with 1.27 mm pitch but the component library's `PRODUCT_DEFINITION` for the same MPN declares 0.65 mm pitch (effectively SSOP). The assembly's pads will not align with the component pins.

Reproducer recipe

two `PRODUCT_DEFINITION`s for the same MPN with different declared pin pitch via `DESCRIPTIVE_REPRESENTATION_ITEM`.

Expected kernel behavior

cross-check assembly vs library pitch / package; reject or warn on conflict.

Notes

Synonyms: "AP210 footprint override conflict", "PCB SOIC vs SSOP", "ECAD pitch mismatch".

occt=empty/empty gmsh=empty ifc=schema_n/a
