M002 — AP242 Edition 1 disallows axis2_placement_3d in tessellated_shape_representation

Description

AP242 Ed.1's `tessellated_shape_representation` accepts only `tessellated_representation_item` in its `items`, so an `axis2_placement_3d` for assembly placement cannot be inside it. Workaround is to use a plain `shape_representation` and keep tessellated items under a separate representation. Files written by tools that ignore this rule fail schema validation.

Reproducer recipe

Author an AP242 Ed.1 file containing one `tessellated_shape_representation` whose `items` list includes both a `tessellated_solid` and an `axis2_placement_3d` for component placement.

Expected kernel behavior

reject for AP242 Ed.1; with AP242 Ed.2+ the constraint is relaxed.

Notes

Synonyms: "axis2_placement in tessellated_shape", "AP242 Ed.1 schema violation", "placement inside tessellation rejected", "AP242 ED1 disallows axis_placement in tess shape".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'AXIS2_PLACEMENT_3D')
  • matches(rb'TESSELLATED_SHAPE_REPRESENTATION\([^)]*#133')
