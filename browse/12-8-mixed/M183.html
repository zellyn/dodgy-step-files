M183 — AP238 workpiece_setup coordinate system not aligned with machine axes

§12.8 mixed (sub-class: AP238 deep machining)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M183.stp

Sources

  • 16-iso-spec ISO 10303-238 §5.4 workpiece_setup machine-axis-alignment guidance
  • bug-reporter language: "AP238 workpiece setup rotated", "STEP-NC setup not square to machine", "fixture skew without rotary axis".

Description

A `WORKPIECE_SETUP`'s placement axes are rotated 17.3 degrees about the machine Z-axis with no rotational fixturing declared. The machine cannot drive its X/Y stages along the workpiece's local axes; every toolpath issues compound moves that exceed acceleration limits. Bug-reporter language: "AP238 workpiece-setup rotation without rotary axis", "STEP-NC setup not aligned to machine", "workpiece coords skewed".

Reproducer recipe

`WORKPIECE_SETUP` whose `AXIS2_PLACEMENT_3D` x-axis is `DIRECTION((0.9550, 0.2974, 0.0))` (17.3 deg rotation), with no rotary fixturing referenced.

Expected kernel behavior

validate workpiece-setup orientation against machine axes when no rotary stage is declared; warn or reject.

Notes

Synonyms: "AP238 workpiece-setup rotated", "STEP-NC fixture not square", "setup CS skew without rotary stage", "workpiece coords misaligned".
