M159 — AP210 connector keying / polarization missing

§12.8 mixed (sub-class: AP210 connector keying attribute)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M159.stp

Sources

  • 16-iso-spec ISO 10303-210 §6 (connector polarization attributes)
  • bug-reporter language: "AP210 connector no key", "PCB header reversible", "ECAD connector polarization missing".

Sender

deduced — ECAD exporter that wrote a connector PRODUCT without copying the polarization / keying property from the library

Description

A connector PRODUCT (e.g. a 4-pin power harness) has no polarization or keying property and no `DESCRIPTIVE_REPRESENTATION_ITEM` indicating shell orientation. The component can be inserted rotated 180 deg, swapping VCC and GND. The defect is a missing required attribute, not an outright contradiction.

Reproducer recipe

`PRODUCT('PWR_HDR_4',..)` with four `TERMINAL`s (VCC / SIG / SIG2 / GND) and no keying / polarization PROPERTY.

Expected kernel behavior

detect connectors that lack polarization attributes; warn (or reject for safety-critical nets).

Notes

Synonyms: "AP210 connector reversible", "PCB harness unkeyed", "ECAD safety-attribute missing".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(4) ifc=schema_n/a
