M040 — STYLED_ITEM.item is NULL or unresolved

§12.8 (sub-class: appearance)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M040.stp

Sources

  • 08-occt-gitlog.md (G027, G063)
  • OCCT aff1875, b80d766, f0bef12
  • Mantis 0028147, 0028797, 0029633

Description

STEP file has `STYLED_ITEM` with NULL `item` reference, or `PRESENTATION_STYLE_ASSIGNMENT` with NULL elements in its `styles` set; OCCT's IsKind() call dereferenced NULL.

Reproducer recipe

`STYLED_ITEM(name,(..),#null)` or PSA with unresolved style reference.

Expected kernel behavior

Heal and accept: null-check and skip styling for that item.

Notes

Synonyms: "STYLED_ITEM null item", "presentation_style_assignment null element", "OCCT NULL deref on STYLED_ITEM", "null reference in style chain". **See also**: A018, A020.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'STYLED_ITEM')
  • contains(b"STYLED_ITEM('null_item_style',(#606),$)")
