M025 — Tessellated geometry preserved on round-trip vs always recomputed

§12.8 (sub-class: tessellation)

P0 — receiver crash / hang / OOM

crash round-trip

View raw fixture (.stp) step-examples/12-8-mixed/M025.stp

Sources

  • 17-standards-bodies.md (M034)
  • JT Content Harmonization Guideline
  • CAx-IF Tessellated 3D Geometry RP v1.1

Description

AP242 supports tessellated geometry via `TESSELLATED_SHAPE_REPRESENTATION`. Tools that re-tessellate from precise B-Rep on receive get a different mesh than the one stored; breaking visual diff, PMI-on-tessellation links, and validation.

Reproducer recipe

File containing both precise B-Rep and tessellated repr; on import the kernel discards the tessellation and recomputes.

Expected kernel behavior

Heal and accept: preserve embedded tessellation when present; recompute only when explicitly requested.

Notes

Synonyms: "round-trip tessellation lost", "tessellation always recomputed", "stored mesh replaced on receive", "validation property fails check". **See also**: M056, Pmi045.

Expected validation

occt=signal(11)/signal(11) gmsh=signal(11) ifc=schema_n/a

Byte assertions

  • contains(b'MANIFOLD_SOLID_BREP')
  • contains(b'TESSELLATED_SOLID')
  • contains(b'COMPLEX_TRIANGULATED_SURFACE_SET')
