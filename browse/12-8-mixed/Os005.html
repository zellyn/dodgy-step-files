Os005 — Offset edge-trim step fails (edges don't trim cleanly against neighbours)

§12.8 (sub-class: offset edge trim)

P1 — silent data loss

  • OCCT BRepOffset_MakeOffset.cxx:1401 (CannotTrimEdges) (uncovered class evidence)

Sender

deduced — OCCT uncovered-class sweep

Description

After offsetting each face independently, the edges between neighbouring offset faces don't intersect cleanly to produce shared trim curves.

Reproducer recipe

A solid with two adjacent faces whose normals differ by a small angle and whose offset distances are large enough that the offset surfaces miss each other.

Expected kernel behavior

Extend or extrude offset surfaces until they intersect; or reject with diagnostic.

Notes

Synonyms: "offset re-join failure", "offset edge trimming failed", "offset faces don't reconnect", "offset edges don't intersect cleanly".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(15) ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Tier-3 assertions

  • face[0].surface_type == "plane"
  • face[1].surface_type == "plane"
