M104 — AP238 producer emits SETUP where WORKPIECE_SETUP is required

§12.8 mixed (sub-class: AP238 setup type)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M104.stp

Sources

  • deduced from ISO 10303-238 §5.4 setup vs workpiece_setup distinction

Sender

deduced — STEP-NC publisher merging machine setup and workpiece setup into one entity

Description

AP238 distinguishes `SETUP` (machine-fixture configuration: vise, palette, tombstone) from `WORKPIECE_SETUP` (workpiece-on-fixture placement and clamping). A producer emits a single `SETUP` and references it from contexts that expect a `WORKPIECE_SETUP`. Consumers conflate the two and lose either the fixture geometry or the workpiece-clamp data. Bug-reporter language: "AP238 setup vs workpiece_setup confusion", "STEP-NC fixture data lost", "wrong setup entity type".

Reproducer recipe

A `MACHINING_WORKINGSTEP`'s `its_setup` attribute references a `SETUP` (rather than the `WORKPIECE_SETUP` per AP238 schema).

detect type mismatch; reject or coerce with diagnostic.
