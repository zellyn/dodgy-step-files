M037 — AP209 FEM element wrong node count

Description

A finite-element entity declares `quadratic_tetrahedron` topology but lists 8 nodes instead of 10; or unknown element type.

Reproducer recipe

AP209 file with `curve_3d_element_descriptor` declaring quadratic tet shape but with `node_list` of length 8.

Expected kernel behavior

Heal and accept: drop element; warn.

Notes

Synonyms: "AP209 element wrong node count", "FEA element node count wrong for hex8", "quadratic_tetrahedron with 8 nodes", "unknown FEM element type".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'quadratic_tetrahedron')
  • contains(b'VOLUME_3D_ELEMENT_DESCRIPTOR')

Tier-3 assertions

  • shape_null == True
