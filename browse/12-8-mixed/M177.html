M177 — AP238 coolant_operation requests through-tool flow on tool with no internal cooling

§12.8 mixed (sub-class: AP238 deep machining)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M177.stp

Sources

  • 16-iso-spec ISO 10303-238 §5.8 coolant_operation tool-capability cross-check
  • bug-reporter language: "AP238 through-tool coolant on solid shank", "STEP-NC coolant floods spindle", "tool has no internal channel".

Description

A `COOLANT_OPERATION` specifies through-spindle / through-tool coolant delivery, but the referenced milling tool has no internal-cooling channel attribute. Activating through-tool flood on a solid-shank tool either floods the spindle bearings or stalls the coolant pump. Bug-reporter language: "AP238 through-tool on solid endmill", "STEP-NC coolant capability mismatch", "coolant through tool with no channel".

Reproducer recipe

a `MILLING_CUTTING_TOOL` declared without an `internal_cooling` attribute; a `COOLANT_OPERATION` with mode `.THROUGH_TOOL.` targeting that tool.

Expected kernel behavior

validate coolant-mode capability against tool attributes; reject incompatible combinations.

Notes

Synonyms: "AP238 through-tool coolant on non-coolant tool", "STEP-NC coolant capability mismatch", "internal cooling not declared", "coolant through-tool stalls pump".

Expected validation

  • contains(b'COOLANT_OPERATION')
  • contains(b'.THROUGH_TOOL.')
