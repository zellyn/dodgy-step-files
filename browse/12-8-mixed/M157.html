M157 — AP210 solder mask covers a pad that should be exposed

§12.8 mixed (sub-class: AP210 solder-mask layer association)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M157.stp

Sources

  • 16-iso-spec ISO 10303-210 §5 (solder_mask_layer / pad exposure)
  • bug-reporter language: "AP210 solder mask over pad", "PCB pad masked", "ECAD reflow blocked".

Sender

deduced — ECAD exporter that emitted solder-mask outlines from CAM polygons before pad-clearance subtraction

Description

A solder-mask layer outline (a `PLY_BOUNDARY_REPRESENTATION` with a `LAMINATE_OR_PLY_DEFINITION` of a solder-mask material) encloses a pad that the placement record (and the net it connects to) requires to be exposed for soldering. The fabricated board has the pad masked over - the component cannot be reflowed onto it.

Reproducer recipe

`LAMINATE_OR_PLY_DEFINITION('solder_mask_top', ..,green_LPI,..)` with `PLY_BOUNDARY_REPRESENTATION` polygon enclosing a `TERMINAL` that requires reflow.

Expected kernel behavior

subtract pad geometry from solder-mask polygons; validate that pads required for reflow are exposed; reject or warn.

Notes

Synonyms: "AP210 solder mask error", "PCB pad blocked", "ECAD reflow obstruction".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'ELECTRONIC_ASSEMBLY_INTERCONNECT_AND_PACKAGING_DESIGN')
  • contains(b'solder_mask')
  • contains(b'PLY_BOUNDARY_REPRESENTATION')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
