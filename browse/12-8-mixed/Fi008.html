Description

The fillet builder finishes producing geometry but the resulting solid fails downstream validation: it has self-intersecting fillet surfaces, missing trimming patches, or a non-watertight shell. The kernel returns a result + a "bad shape" diagnostic. Bug-reporter language: "fillet result is invalid", "kernel says fillet is bad".

Reproducer recipe

A solid where the fillet's rolling-ball intersects a non-adjacent face mid-spine, requiring an unmodelled patch.

Expected kernel behavior

Reject the result and signal failure; or repair via local Boolean cuts.

Notes

Synonyms: "fillet returns broken solid", "fillet result is invalid", "HasResult but BadShape", "fillet produces non-watertight shell", "self-intersecting fillet patches".

Expected validation

occt=shape(1)/shape(1) gmsh=reject ifc=schema_n/a

Tier-3 assertions

  • face[0].surface_type == "plane"
  • face[2].surface_type == "plane"
