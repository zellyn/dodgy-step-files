Description

A loft completes but the longitudinal edges between profile vertices have no 3D curve attached (only pcurves on adjacent surfaces). Downstream consumers need explicit 3D curves. Bug-reporter language: "loft edge missing 3D curve", "loft produces pcurve-only edges".

Reproducer recipe

Result of a loft request where the algorithm omits 3D curve construction for edges.

Expected kernel behavior

Always synthesize 3D curves from pcurves; emit warning if synthesis residual exceeds tolerance.
