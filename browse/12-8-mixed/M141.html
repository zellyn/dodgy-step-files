M141 — AP203 PRODUCT_CATEGORY hierarchy contains a cycle

Sources

  • 16-iso-spec ISO 10303-44 (product_category_relationship acyclicity)
  • bug-reporter language: "AP203 category cycle", "product category infinite loop", "PDM classification cycle".

Sender

deduced — PDM exporter that produced category links from a graph rather than a tree without cycle detection

Description

`PRODUCT_CATEGORY_RELATIONSHIP` entries form a cycle: category 'electronics' is sub-of 'mechanical_assembly' which is sub-of 'electronics'. Walking the category tree to discover a part's parent class loops indefinitely. Bug-reporter language: "AP203 category cycle", "infinite hierarchy", "PDM categorization loops".

Reproducer recipe

two `PRODUCT_CATEGORY_RELATIONSHIP` entries forming an `A -> B -> A` cycle.

Expected kernel behavior

detect cycles in the category graph; reject or break the cycle with a warning.

Notes

Synonyms: "AP203 hierarchy loop", "category infinite recursion", "PRODUCT_CATEGORY contains cycle", "PDM category tree loops", "category sub-of forms cycle".
