M122 — AP209 ply orientation expressed in wrong reference frame

§12.8 mixed (sub-class: AP209 material orientation frame)

Sources

Sender

deduced — composite-modeling tool storing fiber direction in global coordinates while solver expects element-local

Description

A composite ply's fiber-orientation vector is recorded as global-coordinate `(1,0,0)` (i.e. world-X), but the solver convention is that ply orientations are expressed in the element-local material coordinate system. On a curved shell, the global-X reading wraps around the surface and rotates relative to the laminate; some elements end up with fibers running across instead of along the intended path. Bug-reporter language: "AP209 ply orientation frame wrong", "composite fibers not aligned with surface", "local vs global material direction".

Reproducer recipe

A laminate ply orientation referencing a global `AXIS2_PLACEMENT_3D` with axis `(0,0,1)` instead of an element-attached local frame; surface curves in 3D so the global-X interpretation is inappropriate.

Expected kernel behavior

Warn and accept, or heal and accept: validate that the orientation reference frame matches solver convention; either warn or transform (coerce) into the solver frame.

Notes

Synonyms: "AP209 fiber frame mismatch", "ply orientation in wrong CSYS", "ply vector in global vs local frame", "composite orientation reference frame wrong". Synonyms: "AP209 fiber frame mismatch", "ply orientation in wrong CSYS".
