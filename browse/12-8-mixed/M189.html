M189 — AP238 boring tool diameter declared as negative

§12.8 mixed (sub-class: AP238 deep machining)

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M189.stp

Sources

  • 16-iso-spec ISO 10303-238 §5.7 boring_tool diameter-positivity invariant
  • bug-reporter language: "AP238 boring bar negative diameter", "STEP-NC bore tool size below zero", "negative tool dimension".

Description

A `BORING_TOOL`'s diameter `MEASURE_WITH_UNIT` carries a negative value (-12.0 mm). The controller either rejects the file or computes a negative-radius offset toolpath, sending the boring bar in the wrong direction. Bug-reporter language: "AP238 boring tool negative diameter", "STEP-NC tool dimension below zero", "boring bar negative size".

Reproducer recipe

`BORING_TOOL` whose diameter is `MEASURE_WITH_UNIT(LENGTH_MEASURE(-12.0), mm_unit)`.

Expected kernel behavior

reject negative tool diameters; treat as malformed.

Notes

Synonyms: "AP238 boring tool negative size", "STEP-NC bore-bar diameter < 0", "negative boring tool dimension", "tool size below zero on boring op".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'AP238_STEP_NC_MIM')
  • contains(b'BORING_TOOL')
  • contains(b'-12.0')
