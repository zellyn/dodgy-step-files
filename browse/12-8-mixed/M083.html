M083 — AP209 nodal load applied to a node not in the model node set

§12.8 mixed (sub-class: AP209 load attachment)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M083.stp

Sources

  • deduced from AP209 §7 fea_model node-set invariants

Sender

deduced — FEA exporter that pruned mesh but not loads

Description

A `NODE_WITH_FORCE` references a `NODE` by id, but that node is not part of any `FEA_MODEL_3D`'s `its_node_set`. The load floats free of the discretized model and contributes nothing to the assembled load vector. Bug-reporter language: "FEM load not applied", "AP209 force on orphan node", "load went to nothing".

Reproducer recipe

`FEA_MODEL` whose `its_node_set` excludes `#210`, combined with `NODE_WITH_FORCE(#210, ..)`.

Expected kernel behavior

Warn and accept: warn on loads attached to nodes outside the active model; either heal (snap the load to the nearest model node) or drop it.

Notes

Synonyms: "orphan node load", "FEM load lost on import", "AP209 force on phantom node", "load applied to node not in model", "nodal load floats free".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'FEA_MODEL')
