M178 — AP238 inspection_probing path passes through workpiece body

§12.8 mixed (sub-class: AP238 deep machining)

crash spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M178.stp

Sources

  • 16-iso-spec ISO 10303-238 §6.2 inspection_probing safe-approach invariant
  • bug-reporter language: "AP238 probe crashes into part", "STEP-NC inspection path collides", "stylus shears off".

Description

An `INSPECTION_PROBING` op's approach segment runs from the probe-storage position straight through the workpiece body to reach the touch point. The probe stylus shears or breaks. Bug-reporter language: "AP238 probe path through part", "STEP-NC inspection collision", "stylus crashes against workpiece".

Reproducer recipe

an `INSPECTION_PROBING` op whose probe path `POLYLINE` runs from `(50,50,200)` to `(50,50,-5)` while the workpiece body occupies the box `(0.100, 0.100, 0.50)`.

Expected kernel behavior

collision-check probe paths against workpiece envelope; reject the op or warn loudly.

Notes

Synonyms: "AP238 probe collision", "STEP-NC inspection path crashes", "probe stylus shears", "inspection trajectory through workpiece".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(3) ifc=schema_n/a

  • contains(b'AP238_STEP_NC_MIM')
  • contains(b'INSPECTION_PROBING(')
  • contains(b'probe_path_through_part')

  • shape_null == False
  • n_edges_total == 1
