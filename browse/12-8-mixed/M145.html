M145 — AP210 fixed-side reference inverts top/bottom semantics

§12.8 mixed (sub-class: AP210 layer-side reference)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M145.stp

Sources

  • 16-iso-spec ISO 10303-210 §5 (laminate side conventions)
  • bug-reporter language: "AP210 top side mirrored", "PCB side reference inverted", "ECAD layer fixed_side wrong".

Sender

deduced — ECAD exporter that wrote `fixed_side` from a numeric layer index using inverted top/bottom conventions

Description

A board with stackup top -> top_signal -> .. -> bottom is exported with the `top_signal` ply annotated as `fixed_side = 'BOTTOM'`. Components placed by the assembly using `fixed_side` to disambiguate top/bottom land on the wrong PCB face. Bug-reporter language: "PCB top side mirrored", "AP210 fixed-side reference inverted".

Reproducer recipe

a `LAMINATE_OR_PLY_DEFINITION` named 'top_signal' with a `PROPERTY_DEFINITION('layer_side_reference','..',ply)` and `DESCRIPTIVE_REPRESENTATION_ITEM('fixed_side','BOTTOM')`.

Expected kernel behavior

validate `fixed_side` against the ply's position in the LAMINATE_TABLE; reject or warn.

Notes

Synonyms: "PCB top/bottom inverted", "AP210 side reference flipped", "fixed_side semantic wrong", "stackup top labeled BOTTOM". Synonyms: "PCB top/bottom inverted", "AP210 side reference flipped".
