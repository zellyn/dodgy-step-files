M018 — Crash on empty TESSELLATED_SHELL((), $) argument list

§12.8 (sub-class: tessellation)

P0 — receiver crash / hang / OOM

Sources

  • 18-other-issues.md (I004)
  • OCCT issue #667

Description

Schema requires `TESSELLATED_SHELL` argument 1 to be a set of at least one item; producer emits empty list `()`. ReadFile crashes.

Reproducer recipe

Add `#607638=TESSELLATED_SHELL('',(),$);` to any AP242 file referencing it from a `SHAPE_REPRESENTATION`.

Expected kernel behavior

heal; reject the malformed entity, continue reading.

Notes

Synonyms: "empty TESSELLATED_SHELL crashes", "ReadFile crash on empty shell", "tessellated shell with empty argument list", "crash on TESSELLATED_SHELL((),$)". Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT crashes (`signal(11)`). The crash is on the kernel side; the file is spec-conformant Part-21.
