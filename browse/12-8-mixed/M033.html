M033 — Constructive geometry / supplemental geometry not allowed type

Description

Supplemental-geometry RP allows only specific entity types (point, axis, plane, cylinder, etc.). The file uses an unsupported type or omits some `items` referenced by GISU.

Reproducer recipe

`constructive_geometry_representation` whose items include an unsupported entity, or where a GISU references an item missing from the items list.

Expected kernel behavior

Reject (drop) or warn-and-accept.

Notes

Synonyms: "supplemental geometry wrong type", "CGR has unsupported entity", "supplemental items beyond allowed list", "GISU references wrong type". **See also**: M011.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONSTRUCTIVE_GEOMETRY_REPRESENTATION')
  • contains(b'B_SPLINE_SURFACE_WITH_KNOTS')
