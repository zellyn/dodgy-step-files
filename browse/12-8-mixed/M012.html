M012 — tessellated_constructive_geometry_representation requires AP242 Ed.4

§12.8 (sub-class: tessellation + supplemental)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M012.stp

Sources

  • 02-caxif.md
  • Supplemental Geometry v1.3 §4 and Annex A.6

Description

TCGR (tessellated supplemental geometry) was added in AP242 Ed.4. Files using it under earlier AP242 schemas fail validation.

Reproducer recipe

AP242 Ed.2 STEP file containing a `tessellated_constructive_geometry_representation` entity.

Expected kernel behavior

writer scoped to Ed.1–Ed.3 must not emit TCGR; reader must reject under those editions.

Notes

Synonyms: "TCGR requires AP242 Ed.4", "tessellated supplemental geometry rejected", "AP242 edition too old for TCGR", "schema-version vs entity-vocabulary disagreement".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'TESSELLATED_CONSTRUCTIVE_GEOMETRY_REPRESENTATION')
  • contains(b'442 2 1 4')
