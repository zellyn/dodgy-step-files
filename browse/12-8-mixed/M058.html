M058 — File mixing AP203 schema declaration with AP214-only entity types in DATA

§12.8 (sub-class: schema declaration mismatch)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M058.stp

Sources

  • 16-iso-spec AP214 vs AP203 entity-set comparison

Description

ISO 10303-21 FILE_SCHEMA declares one (or more) active schemas. When a single FILE_SCHEMA names AP203 only but the DATA section contains entities defined only in AP214 (e.g. APPLIED_GROUP_ASSIGNMENT), strict AP203 readers either reject the unknown entity or attempt to parse it under AP203 with possibly wrong attribute interpretation.

Reproducer recipe

`FILE_SCHEMA(('CONFIG_CONTROL_DESIGN'))` with `APPLIED_GROUP_ASSIGNMENT(#20,(#10))` in DATA.

Expected kernel behavior

reject unknown entity types in the declared schema; or, in tolerant mode, accept under the most-capable available schema with a warning.

Notes

Synonyms: "AP203 tag with AP214 entities", "schema-version vs entity-vocabulary disagreement", "AP214-only entity in AP203 file", "mixed schema declaration". **See also**: Lh007, Lh019, M057.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONFIG_CONTROL_DESIGN')
  • contains(b'APPLIED_GROUP_ASSIGNMENT')
