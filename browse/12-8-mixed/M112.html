Description

Three `MULTI_POINT_CONSTRAINT` entries form a cycle: node A is a slave of node B (constraint X), node B is a slave of node C (constraint Y), node C is a slave of node A (constraint Z). Solver assembly cannot resolve the master-slave reduction; either the matrix is singular or the system iterates indefinitely. Bug-reporter language: "AP209 MPC cycle", "FEM constraint chain has loop", "master-slave loop in STEP file".

Reproducer recipe

Three `MULTI_POINT_CONSTRAINT` entities forming A→B→C→A.

Expected kernel behavior

detect cycle in MPC graph; reject as malformed; report which nodes participate in the cycle.

Notes

Synonyms: "MPC loop", "AP209 master-slave cycle", "multi_point_constraint dependency cycle", "MPC dependency cycle", "FEM constraint chain loops".
