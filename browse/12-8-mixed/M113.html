M113 — AP209 element_representation with degenerate jacobian (collapsed corner)

Sender

deduced — meshing pipeline failing to clean up coincident-node hex degeneracies

Description

A linear hex's eight corner nodes include two that are geometrically coincident (e.g. n7 == n8). The element collapses to a prism-shaped degenerate; jacobian determinant is zero at the collapsed corner. Solver either skips the element or returns NaN stresses. Bug-reporter language: "AP209 collapsed hex element", "FEM jacobian zero", "degenerate hex".

Reproducer recipe

A `VOLUME_3D_ELEMENT_DESCRIPTOR` whose 7th and 8th node references point to the same `NODE` (or two `NODE`s with identical coordinates).

Expected kernel behavior

detect collapsed corner; reject or auto-collapse to a wedge / prism element with diagnostic.

Notes

Synonyms: "degenerate jacobian", "AP209 zero-volume element", "FEM hex with coincident nodes".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
