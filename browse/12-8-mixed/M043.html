M043 — Layer with empty/duplicate name colliding with another

Description

Multiple `PRESENTATION_LAYER_ASSIGNMENT` entries with the same name caused conflict; OCCT didn't differentiate them by visibility.

Reproducer recipe

STEP with two `PRESENTATION_LAYER_ASSIGNMENT` of identical name but different visibility flags.

Expected kernel behavior

Heal and accept: group layers by (name, visibility) tuple.

Notes

Synonyms: "layer name collision", "duplicate PRESENTATION_LAYER_ASSIGNMENT", "layers not differentiated by visibility", "layer with empty name". **See also**: A022.
