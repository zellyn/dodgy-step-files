M029 — PMI-count validation property failure

Description

The number of dimensions / GD&T tolerances / datum features is embedded as a validation property; receiver reports a different count after import; typically because some PMI was tagged as graphic-only and dropped, or because composite callouts were exploded.

Reproducer recipe

12 PMI annotations declared in `validation_property`; 10 imported.

Expected kernel behavior

report; archive-reject; CAD-to-CAD continue with warning.

Notes

Synonyms: "PMI count validation fails", "validation property fails check", "GD&T count mismatch on import", "tolerance count differs after read". **See also**: M026.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'INTEGER_REPRESENTATION_ITEM')
  • contains(b'PROPERTY_DEFINITION')

Tier-3 assertions
