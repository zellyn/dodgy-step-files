M125 — AP209 node_group declares the same node id twice

Sender

deduced — FEA preprocessor concatenating two overlapping selections without dedup

Description

A `NODE_GROUP` contains the same `NODE` reference twice (e.g. `(#100, #101, #100)`). Constraints / loads applied to the group act twice on the duplicated node — the load is doubled or the BC is over- constrained. Bug-reporter language: "AP209 node group has duplicate", "FEM load applied 2x to one node", "node-group set semantics violated".

Reproducer recipe

`NODE_GROUP('fixed', (#100, #101, #100), $)`.

Expected kernel behavior

deduplicate silently and warn; or reject.

Notes

Synonyms: "AP209 duplicate node in group", "node-set with repeats", "node group lists same id twice", "duplicate NODE in NODE_GROUP". Synonyms: "AP209 duplicate node in group", "node-set with repeats".
