M049 — Schema migration: 53 retired kinematics entities (AP242 Ed.1)

§12.8 (sub-class: kinematics)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-8-mixed/M049.stp

Sources

  • 17-standards-bodies.md (M016)
  • STEP Tools "AP242 First Edition Notes"

Description

AP242 Ed.1 retired ~53 AP214/AP203 entities; `kinematic_structure`, `mechanism`, `kinematic_property_definition`, `cylindrical_pair_range` and many more. An archived AP214 file containing them cannot be re-validated against the AP242 schema.

Reproducer recipe

An AP214 Part 21 file using `kinematic_link_representation_relation` re-headered as AP242.

Expected kernel behavior

archive-stable in original AP214 form; on migration to AP242 either drop entities (recorded loss-of-fidelity note) or refuse migration.

Notes

Synonyms: "AP242 retired kinematics entities", "schema-version vs entity-vocabulary disagreement", "kinematic_structure entity gone", "AP214 kinematics not in AP242 Ed.1". **See also**: A031.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'KINEMATIC_LINK_REPRESENTATION_RELATION')
  • contains(b'CYLINDRICAL_PAIR_RANGE')
  • contains(b'MECHANISM')
