Ls006 — Numeric literal with embedded underscore digit-grouping

§12.1c numeric-literal grammar

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls006.stp

Sources

  • T045

Description

Modern languages tolerate `1_000_000`. Some in-house exporters borrow this and emit `IFCREAL(1_000.0)`. ISO 10303-21 disallows underscores in numerics.

Reproducer recipe

`#1=IFCREAL(1_000.0);`

Expected kernel behavior

Strict reject with clear "underscore not permitted in numeric literal".

Notes

**See also**: Ls001. Synonyms: "underscore in numeric literal", "1_000_000 in STEP REAL", "digit grouping in STEP number", "Python-style underscore in STEP", "thousands separator inside number".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • count(b'_') >= 2 or matches(rb'\d_\d{3}')

Tier-3 assertions

  • load == "ok"
