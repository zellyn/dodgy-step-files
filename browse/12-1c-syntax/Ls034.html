Ls034 — Enumeration value missing dotted delimiters or with bad casing

§12.1c enumeration token form

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls034.stp

Sources

  • T035, N021

Description

ISO 10303-21 enum literals are `.IDENT.` where IDENT is an EXPRESS-conformant identifier (uppercase letters and digits only). Defects: missing closing dot, lower-case body, digit-leading body, quoted body (`."LEFT".`), missing leading dot.

Reproducer recipe

`#1=IFCSIUNIT(*,.LENGTHUNIT,$,.METRE.);` (missing closing dot after LENGTHUNIT); `#2=DIRECTION_FLAG(.true.);`; `#3=DIRECTION_FLAG(TRUE);`

Expected kernel behavior

Strict reject; lenient mode may case-fold the identifier but the dots are non-negotiable.

Notes

**See also**: Ls035. Synonyms: "STEP enum missing dotted delimiters", "lowercase enum body", "missing leading dot on STEP enum", "quoted enum value", "STEP enum value malformed".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'.LENGTHUNIT,') or contains(b'.true.') or contains(b'(TRUE)') or contains(b'."LEFT".')
  • matches(rb'\.[a-z]+\.|\bTRUE\b|\bLEFT\.')
