Ls032 — Comment longer than implementation buffer

§12.1c comments

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls032.stp

Sources

  • T004 (`MAX_COMMENT_LENGTH 8192`)

Description

stepcode hardcodes an 8 KiB ceiling on comment body length. Files with multi-page log banners exceed this and trip rejection.

Reproducer recipe

Single `/* .. */` containing >8192 characters before first `DATA;` instance.

Expected kernel behavior

Comment length unbounded (memory-bound only); never silently truncate.

Notes

Synonyms: "STEP comment exceeds buffer", "8KB comment limit", "multi-page log banner in STEP", "long comment rejected by stepcode", "huge STEP comment overflows buffer". Provenance tier: bytes-only (Q5 full-corpus 2026-07-01).

occt=empty/empty gmsh=empty ifc=schema_n/a
