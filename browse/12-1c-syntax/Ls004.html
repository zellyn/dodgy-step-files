Ls004 — Fortran-style `D` exponent (`1.0D5`)

§12.1c numeric-literal grammar

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls004.stp

Sources

  • T023

Description

Some legacy Fortran-fronted exporters (older I-DEAS, CADAM converters) emit `1.0D5` instead of `1.0E5`. ISO 10303-21 only allows `E`/`e`.

Reproducer recipe

`#1=DIRECTION('',(1.0D5,0.,0.));`

Expected kernel behavior

Reject with diagnostic "exponent must be 'E', got 'D'".

Notes

**See also**: Ls001. Synonyms: "Fortran D exponent in STEP", "1.0D5 instead of 1.0E5", "legacy Fortran writer emits D exponent", "I-DEAS D-exponent REAL", "CADAM D-style exponent".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • matches(rb'\d[Dd][+-]?\d')
  • contains(b'1.0D5') or contains(b'1.5D-3')

Tier-3 assertions

  • load == "ok"
