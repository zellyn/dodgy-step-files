In001 — Model marked Loaded without entities; load skipped silently

Description

A reader's data state is "Unloaded"; the file was opened but the entity table was never populated (e.g., parser bailed silently after the header). Downstream consumers see an empty model and may not realize the load was incomplete. Bug-reporter language: "STEP loaded but empty", "no entities in file", "kernel imports nothing silently".

Reproducer recipe

A Part-21 file with a valid HEADER but a DATA section that contains only a comment, no entities; `ENDSEC` ends the section.

Expected kernel behavior

Reject load failures explicitly: distinguish "empty data" from "load failed" with separate diagnostic codes; never let the consumer see an empty model from a load failure. Must not silently accept failed load.

Notes

Bug-reporter synonyms: "silent empty load", "model unloaded". Provenance tier: runtime-only; bytes alone cannot demonstrate this defect; the symptom is a kernel-internal load-state value (Unloaded vs. Loaded) and a missing diagnostic, both of which manifest only at parse/load time. A behavioral test against a reader implementation is the appropriate venue. Synonyms: "STEP loaded but empty", "no entities loaded silently", "model unloaded after parse", "load skipped without error", "empty model after STEP read".
