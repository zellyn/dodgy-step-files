Ls043 — Excessively long entity name

§12.1c lexical / identifier limits

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls043.stp

Sources

  • A021, S002

Description

Parser copies entity name into a fixed-size identifier buffer; classic strcpy overflow. ISO conformance class permits long names but not unbounded. Embedded `-` (hyphen) in identifiers is also disallowed (`BS7752-1`).

Reproducer recipe

`#1=AAAA…(64 KiB)…(..);` and `#2=BS7752-1(..)`.

Expected kernel behavior

Maximum identifier length per ISO conformance class (e.g. 256 chars); reject overflow before allocation. Reject `-` in identifiers; lenient mode may map to `_`.

Notes

Synonyms: "very long STEP entity name", "fixed-buffer overflow on long name", "hyphen in STEP identifier", "BS7752-1 entity name rejected", "STEP entity name with dash".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • matches(rb'A{50,}|BS7752-1')
