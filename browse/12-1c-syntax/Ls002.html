Ls002 — REAL literal with no digit before the decimal point

§12.1c numeric-literal grammar

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls002.stp

Sources

  • N016

Description

Grammar requires at least one digit before the dot. `.5` is not legal; `0.5` is. C/Python `%g` formatters frequently emit bare `.5`.

Reproducer recipe

`#1=DIRECTION('',(.0,.0,1.0));`

Expected kernel behavior

Strict reject; lenient readers commonly accept implicit zero.

Notes

**See also**: Ls001. Synonyms: "REAL with no digit before decimal", ".5 instead of 0.5 in STEP", "leading-dot REAL literal", "%g formatter emits .5", "missing zero before decimal".
