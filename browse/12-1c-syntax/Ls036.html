Ls036 — Binary literal `"…"` malformed (bit-count nibble or hex case)

§12.1c binary-literal grammar

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls036.stp

Sources

  • T036, A024, N020

Description

ISO 10303-21 BINARY syntax is `"<n><hex>*"` where `<n>` is `0`–`3` indicating unused bits in the final hex digit; hex digits are uppercase, even-count is required. Defects: lower-case hex (`"0dead"`), wrong leading nibble (`"4DEAD"` or `"FF"`), missing leading nibble, odd hex-digit count (`"3DEAD"`).

Reproducer recipe

`BINARY_VALUE := "0DEAD";` (good) vs `"0dead";` vs `"4DEAD";` vs `"FF";` vs `"3DEAD";`

Expected kernel behavior

Strict reject malformed forms; in particular enforce leading nibble in 0.3 and even hex-digit count. Lenient mode may accept lowercase but warn.

Notes

Synonyms: "malformed BINARY literal in STEP", "binary literal lowercase hex", "wrong leading nibble on BINARY", "odd hex-digit count in STEP binary", "BINARY missing leading nibble".
