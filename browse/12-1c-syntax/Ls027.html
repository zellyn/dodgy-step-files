Ls027 — Legacy SCOPE/ENDSCOPE blocks (Edition 1) and EXPORT lists

§12.1c legacy structure

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls027.stp

Sources

  • Q073, N043 (Implementors Issues 001/002)

Description

Edition 1 had inline SCOPE/ENDSCOPE delimiters; Editions 2/3 removed them but legacy translators still emit them. EXPORT lists also appeared inside ENDSCOPE in Ed.1. Implementors Issues 001/002 record the disagreement on whether modern processors must parse SCOPE blocks.

Reproducer recipe

`DATA;\n#1=PRODUCT(..);\nSCOPE\n #2=..;\nENDSCOPE;\nENDSEC;`

Expected kernel behavior

Strict Ed.2/Ed.3 reject; lenient skip-to-matching-ENDSCOPE without aborting; emit a single informational warning per file.

Notes

Synonyms: "legacy SCOPE block in STEP", "Edition 1 SCOPE/ENDSCOPE", "EXPORT list in STEP", "old-style scope delimiters", "Ed.1 scope blocks in modern STEP".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'SCOPE') and contains(b'ENDSCOPE')
  • count(b'SCOPE') >= 2
