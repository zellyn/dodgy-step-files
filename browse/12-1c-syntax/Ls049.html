Ls049 — Boolean attribute given bare `TRUE` (no dots)

§12.1c enumeration token form

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls049.stp

Sources

  • Q053, G028

Description

`EDGE_CURVE.same_sense` is a BOOLEAN encoded as the dotted enum `.T.` or `.F.`. A writer that emits the bare keyword `TRUE` (no dots) drops the enum-token framing required by ISO 10303-21. Distinct from Ls034 in that the BOOLEAN slot of an `EDGE_CURVE` is the canonical `same_sense` kernel surface, where the kernel may default to `true` on read failure rather than rejecting.

Reproducer recipe

`EDGE_CURVE('',#12,#13,#14,TRUE);` — bare `TRUE` token at the BOOLEAN slot.

Expected kernel behavior

Strict reject; lenient mode may default to `.T.` with a warning.

Notes

**See also**: Ls034, Ls035, Ls050. Synonyms: "bare TRUE without dots in STEP", "BOOLEAN written without dot delimiters", "EDGE_CURVE same_sense bare keyword", "TRUE/FALSE without dot framing", "STEP boolean missing enum dots".
