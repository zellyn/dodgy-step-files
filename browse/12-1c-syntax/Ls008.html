Ls008 — Float literal with extreme exponent / non-finite real

§12.1c numeric-literal grammar

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls008.stp

Sources

  • A014

Description

`1.0E+999999` parsed via `strtod` yields `inf`; `NaN` results from malformed inputs. Geometry pipelines that compare via `<`/`>` then violate sort invariants in STL containers.

Reproducer recipe

`#1=CARTESIAN_POINT('',(1.0E+999999,0.,0.));`

Expected kernel behavior

Clamp magnitude or reject non-finite where geometry expects finite.

Notes

**See also**: Ad014. Synonyms: "1.0E+999999 overflows to infinity", "STEP REAL becomes inf", "NaN from STEP", "infinity in geometry pipeline", "non-finite REAL breaks sort".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'1.0E+999999') or contains(b'1.0E-999999')
  • count(b'E+999999') + count(b'E-999999') >= 1
