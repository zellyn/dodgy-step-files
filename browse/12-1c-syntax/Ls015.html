Ls015 — Missing comma between attribute values

Description

A list of attributes lacks a comma separator. SFA reports `"Expecting ',', found _3DV instead."`

Reproducer recipe

`#1=CARTESIAN_POINT('p' (0.,0.,0.));` (missing comma after `'p'`).

Expected kernel behavior

Strict reject with precise location diagnostic.
