Ls050 — Boolean attribute given long-form `.UNKNOWN.`

Description

`EDGE_CURVE.same_sense` is a BOOLEAN (`.T.`/`.F.`). Passing `.UNKNOWN.` (the long-form LOGICAL three-state value) is structurally identical to `.U.` but uses the long token, exercising readers that special-case `.U.` while accepting `.UNKNOWN.` through a different parser path.

Reproducer recipe

Expected kernel behavior

Reject the value at the BOOLEAN slot; never leave the bool uninitialised.
