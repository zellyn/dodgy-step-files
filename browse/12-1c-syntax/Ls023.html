Ls023 — Missing or malformed opening magic line `ISO-10303-21;`

§12.1c structural / framing

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls023.stp

Sources

  • T001, A028, N001

Description

First non-whitespace token must be `ISO-10303-21;` (case-sensitive, hyphens, no leading whitespace, no BOM). Real files prepend UTF-8 BOM (`EF BB BF`), use lowercase, miss the trailing semicolon, double the hyphens (`ISO--10303-21`), or wrap in an XML envelope.

Reproducer recipe

`\xEF\xBB\xBFISO-10303-21;\nHEADER;..` or `iso-10303-21\nHEADER;..`

Expected kernel behavior

Strict reject; lenient strip UTF-8 BOM, uppercase-compare keyword, warn. Reject UTF-16/UTF-32 BOMs with clear error.

Notes

**See also**: Le001. Synonyms: "missing opening ISO-10303-21 line", "STEP file no magic header", "lowercase iso-10303-21", "double-hyphen in ISO-10303-21", "BOM before STEP magic".

Expected validation

occt=reject/reject gmsh=reject ifc=reject

Byte assertions

  • count(b'ISO-10303-21;') >= 1 or contains(b'iso-10303-21')
  • matches(rb'iso-10303-21|ISO-10303-21')
