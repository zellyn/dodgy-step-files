Ls016 — Double comma / empty parameter slot

§12.1c punctuation

syntax

View raw fixture (.stp) step-examples/12-1c-syntax/Ls016.stp

Sources

  • T020, A016

Description

`(a,,b)` leaves an attribute slot empty. Correct null is `$`, derived is `*`. Empty slot is a generator bug. Parsers that map positional slots without re-checking arity may construct the entity with one fewer attribute, leading to uninitialised fields.

Reproducer recipe

`#1=IFCPERSON($,$,'',,$,$,$,$);` or `#1=CARTESIAN_POINT('',(0.,,1.));`

Expected kernel behavior

Reject with "expected parameter, found ','"; do not silently treat empty slot as `$`.

Notes

**OCC behavior**: silently treats the empty slot as `$` (omitted) and proceeds; kernel mishandling — the catalog above forbids silent slot-equivalence. Synonyms: "double comma in STEP aggregate", "(a,,b) empty slot", "STEP entity attribute slot empty", "empty parameter slot in entity", "consecutive commas in attribute list".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • matches(rb',\s*,') or matches(rb'\(\s*,')
  • count(b',,') >= 1
