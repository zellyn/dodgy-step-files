In013 — Transfer Status remains Void after Defined was expected: unknown entity type in DATA section silently skipped (e.g., made-up future-schema entity)

Description

A transfer process expected to produce a Defined result for an entity, but the result remains Void because no actor handled the entity type. The transfer log doesn't flag the void as an error. Typical fixture: the DATA section contains an entity of a made-up or future type (e.g., `HYPOTHETICAL_AP242_ED2_FUTURE_ENTITY`) that no standard schema defines and no kernel actor recognizes — the reader silently skips it. Bug-reporter language: "entity type not transferred", "kernel skipped entity silently", "unknown entity type ignored".

Reproducer recipe

An entity of a type the actor pool doesn't recognize (e.g., a made-up `HYPOTHETICAL_AP242_ED2_FUTURE_ENTITY` or an AP242 ed.2 entity that the reader wasn't compiled with).

Expected kernel behavior

Emit "no actor for entity type X" warning; track unrecognized types in a per-file summary.
