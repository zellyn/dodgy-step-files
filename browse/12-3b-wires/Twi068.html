Twi068 — Wire 3D-gap analysis must enumerate all gaps (EDGE_LOOP with multiple junctions where consecutive ORIENTED_EDGEs have mismatched VERTEX_POINTs, e.g., 0.05-0.07 mm gaps)

Sources

  • OCCT `ShapeAnalysis_Wire::CheckGaps3d` (`ShapeAnalysis_Wire.hxx:238`)

Description

The wire-wide 3D gap analyzer must visit every consecutive-edge junction and report each gap individually. A wire with multiple defective junctions should not be reported as "broken at junction 1" when it also breaks at junctions 3 and 5.

Reproducer recipe

A four-edge wire where the gaps between edge-pairs (1,2), (2,3), and (3,4) are each above tolerance.

Expected kernel behavior

Heal and accept: normalize a per-junction list of (junction_index, 3D_gap_distance); enables downstream batch repair / healing.

Notes

Per-wire counterpart to Twi072 (single-junction). Synonyms: "wire has multiple gap junctions", "all junction gaps must be enumerated", "list every gap location in wire", "per-junction 3D gap report for whole wire".
