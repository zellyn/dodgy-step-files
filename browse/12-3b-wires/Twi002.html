Twi002 — Single-edge EDGE_LOOP with non-coincident start/end vertex

§12.3b wire-loop

topology

View raw fixture (.stp) step-examples/12-3b-wires/Twi002.stp

Sources

  • 04-occt-translation.md Q002

Description

A loop containing exactly one ORIENTED_EDGE requires the underlying EDGE_CURVE start and end vertices to coincide (closed curve such as full circle/ellipse). Some files emit a single open edge as a "loop", violating the closure invariant.

Reproducer recipe

`EDGE_LOOP('',(#orient));` where `#orient`'s `EDGE_CURVE` has distinct start and end `VERTEX_POINT`s.

Expected kernel behavior

reject loop or heal by inserting closing edge; warn.

Notes

The defect is detected by the AP203/AP242 entity-reader's edge-loop attribute validator (every single-edge loop demands a closed underlying curve). **See also**: Twi017. Synonyms: "single edge loop with open curve", "one-edge wire start and end don't match", "circle wire has distinct endpoints", "loop closure invariant violated", "single ORIENTED_EDGE has open arc".

Expected validation

occt=shape(1)/shape(1) gmsh=reject ifc=schema_n/a

Tier-3 assertions

  • n_edges_total >= 1
  • face[0].surface_type == "plane"
  • n_vertices_total >= 2
