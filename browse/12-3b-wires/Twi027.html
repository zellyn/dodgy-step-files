Twi027 — ConnectEdgesToWires fails on INTERNAL-only edges / non-determinism

Description

A free-edges-to-wires connection pass throws when given a compound containing only INTERNAL-oriented edges (no wires, no faces). Separately, when given normal input the pass can return wires whose closed-or-open flag disagrees with the actual closure, or yield different orderings across repeated runs (non-determinism).

Reproducer recipe

STEP-imported compound of standalone edges all marked INTERNAL; or shape with edges that form rings under loose tolerance but the algorithm is run 100 times observing different orderings.

Expected kernel behavior

Warn and accept: detect non-manifold input; coerce / bypass connection or emit a warning; normalize to deterministic output.

Notes

**See also**: Tfa022. Synonyms: "all edges marked INTERNAL throw on connect", "compound of stray edges with no wires", "edge connection pass non-deterministic", "ring detection results vary between runs", "free edges fail to assemble into wires".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
