Reproducer recipe

Expected kernel behavior

Reject with a diagnostic naming entity #34: its LINE's third argument is written as an inline aggregate `(DIRECTION('',(1.0,0.0,0.0)),1.0)` rather than a `#N` reference to a VECTOR — Part 21 requires an object reference there, so the curve cannot be built and the reader must abort naming that entity rather than silently coercing or dereferencing a null curve. Independently, the wire's second edge (#80) is built on a zero-radius CIRCLE (#61) between vertices #41 and #70, both at (5.0,0.0,0.0) — a genuinely degenerate, zero-length edge that a kernel must also detect and reject once the file can be parsed at all.
