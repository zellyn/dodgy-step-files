Twi069 — Wire 2D-gap analysis must enumerate all pcurve gaps

§12.3b wires / loops / edges (sub-class: gap-analysis)

P1 — silent data loss

topology

Sources

  • OCCT `ShapeAnalysis_Wire::CheckGaps2d` (`ShapeAnalysis_Wire.hxx:240`)

Description

Pcurve-space analogue of Twi068. A wire whose pcurves have multiple gaps in UV should produce a per-junction list. Often produced when the wire is built by stitching pcurves from different sources without parameter alignment.

Reproducer recipe

A wire where edges' pcurve endpoints land at U values that disagree at junctions 1 and 3.

Expected kernel behavior

Heal and accept: normalize a per-junction (index, 2D_gap_distance) report.

Notes

Per-wire counterpart to Twi073. Synonyms: "wire has multiple parametric gaps", "all UV junction gaps must be enumerated", "per-junction 2D gap report for whole wire", "list every parametric gap in wire".
