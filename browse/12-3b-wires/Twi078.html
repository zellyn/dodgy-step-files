Description

Edges of a wire emitted in arbitrary order. The analyzer must reconstruct head-to-tail order using 3D and 2D vertex matching with a starting tolerance and report `STATUS_DONE` (reordered, no reversal needed); distinct from `STATUS_DONE2` (some edges needed flipping) and `STATUS_FAIL` (could not reorder).

Reproducer recipe

A wire whose four edges, when listed in order `[3, 1, 4, 2]`, form a valid square in head-to-tail traversal.

Expected kernel behavior

Heal and accept: coerce by trying increasing tolerance scales; normalize / emit the smallest reorder that succeeds; report which status was achieved.

Notes

Existing Twi-class entry covers reordering; this is the analyzer-level orchestrator. Synonyms: "wire-order analyzer reconstructs head-to-tail", "scrambled edge order needs reordering", "analyzer-level wire reorder orchestrator", "edges in random order can be reordered without flipping".
