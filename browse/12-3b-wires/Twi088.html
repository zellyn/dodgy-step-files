Twi088 — Edge in topology has no 3D curve attached

§12.3b (sub-class: missing 3D curve)

P1 — silent data loss

topology

View raw fixture (.stp) step-examples/12-3b-wires/Twi088.stp

Sources

  • OCCT BRepLib::BuildCurves3d (uncovered class evidence)

Sender

deduced — OCCT uncovered-class sweep

Description

An edge appears in face wires only via its pcurve representations on adjacent faces; there is no 3D curve attached to the edge itself. The edge is "implicit" (defined only by surface intersection). Bug-reporter language: "edge has only pcurve", "no 3D geometry on edge", "edge derived from surfaces only".

Reproducer recipe

An `EDGE_CURVE` whose `edge_geometry` is null, but `PCURVE`s on two adjacent faces describe the edge in UV.

Expected kernel behavior

Heal and accept: repair / reconstruct the 3D curve by intersecting the two pcurves' host surfaces; report the deviation.

Notes

Common when files are exported from surfacing tools. Synonyms: "edge has only parametric trace no spatial geometry", "implicit edge derived from surface intersection", "no spatial trajectory attached to edge", "topology has parametric trace only".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'pcurve_only_edge')
  • contains(b',$,.T.)')
  • count_entity_def(b'EDGE_CURVE') == 1

Tier-3 assertions

  • shape_null == True
