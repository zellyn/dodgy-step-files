Twi280 — AP242 Ed.3 `SUBPATH` named path sub-region dropped by Ed.2/AP214 readers

§12.3b wire-loop (sub-class: edition-boundary entity elision / path sub-region labelling)

P1 — silent data loss

silent-loss topology

View raw fixture (.stp) step-examples/12-3b-wires/Twi280.stp

Sources

  • steptools.com AP242 Ed.3 notes (`SUBPATH` §4.4 — one of 21 new Ed.3 entities). B4 wave-8 DEF-XX (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit labelled sub-regions of an ordered `PATH` so automated pocket-milling toolpath generation, inspection routines, and design-intent tools can query named segments of a path
  • earlier editions (Ed.2, Ed.1, AP214) do not carry this entity in their schema and their readers produce Void transfer status.

Sender

AP242 Edition 3 STEP files from CAM/CAD tools that emit named path sub-regions (pocket-milling toolpath segments, interior-corner segments, tool-lift segments); file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID).

Description

STEP AP242 Ed.3 file containing a single planar 5×5 mm carrier `ADVANCED_FACE` (so geometry loads) plus an independent `PATH('interior_pocket_path',(#oe1,#oe2,#oe3,#oe4,#oe5))` (5-segment ordered `ORIENTED_EDGE` list representing an interior pocket-milling toolpath) and a `SUBPATH('interior_corner_segment',(#oe3,#oe4))` labelling edges 3-4 as a named sub-region (the "interior corner" of the toolpath). Ed.3 readers resolve the entity and expose the sub-region labelling so automated pocket-milling toolpath generation that keys off `SUBPATH` labels can recover the sub-region; Ed.2 / AP214 readers produce Void transfer status on the entity — the `PATH` still loads but the sub-region labelling is lost.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); single planar carrier `ADVANCED_FACE` + `SHELL_BASED_SURFACE_MODEL`; independent `PATH('...',(#oe1,...,#oe5))`; `SUBPATH('interior_corner_segment',(#oe3,#oe4))`.

Expected kernel behavior

AP242 Ed.3 readers must resolve `SUBPATH` and expose the labelled sub-region; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(SUBPATH)` rather than silently discarding the entity.

Notes

steptools notes_ap242e3.html §4.4 (21 new Ed.3 entities). B4 wave-8 DEF-XX. Confidence: MEDIUM — accept-live-oracle. OCCT drops the Ed.3 entity and loads the geometry as if AP214 (face + path load, sub-path labelling absent) — that IS the defect. Expected validation captured from OCCT live behavior. Edition boundary: Ed.3 entity absent from Ed.2, Ed.1, AP214 schemas. Synonyms: "SUBPATH AP242 Ed.3 dropped", "PATH sub-region labelling lost Ed.2", "interior corner segment label absent Ed.2", "pocket-milling toolpath sub-region silent drop", "AP242 Ed.3 SUBPATH entity absent".
