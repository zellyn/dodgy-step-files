Twi001 — Empty edge_list in EDGE_LOOP

§12.3b wire-loop

P1 — silent data loss

crash topology

Sender

Unknown (bug33307 corpus); seen on real STEP imports

Description

STEP `EDGE_LOOP` declared with empty edge aggregate (`#10=EDGE_LOOP('',());`). Translator drops the wire and fails the parent face; bare reader crashed before guards added.

Reproducer recipe

`#10=EDGE_LOOP('',());` referenced by `FACE_OUTER_BOUND` of an `ADVANCED_FACE`.

Expected kernel behavior

reject the loop with diagnostic; do not propagate null wire to face; do not crash.

Notes

The defect bites in two places: the AP203/AP242 entity-reader's edge-loop attribute-validation, and the topology translator's edge-loop transfer pass. Both must guard against the empty list. **See also**: Tsh023. Synonyms: "wire has no edges", "empty edge list crashes reader", "loop with zero edges", "face has no perimeter", "translator drops face on empty wire".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b"EDGE_LOOP('',())")
  • count_entity_def(b'ORIENTED_EDGE') == 0
