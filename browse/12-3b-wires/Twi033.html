Twi033 — Wire contains two distinct edges that geometrically coincide

§12.3b wire-loop

P1 — silent data loss

topology

Sources

  • 05-occt-shapefix.md F030 (FixWiresTwoCoincEdges)

Description

A single wire contains two distinct edges whose 3D and 2D traces coincide within tolerance; both edges describe the same arc, but the wire references them as separate entries. Likely from a failed Boolean or duplicate-injection during translation.

Reproducer recipe

Wire `[e1, e2, e3, e2', e4]` where `e2'` is geometrically equal to `e2`.

Expected kernel behavior

detect the coincident edges and drop the duplicate, or reject as malformed.

Notes

**See also**: Tfa025. Synonyms: "wire has duplicate overlapping edges", "two edges describe same arc", "doubled edge in wire", "same arc referenced twice in EDGE_LOOP", "Boolean fallout left duplicate edges".

Expected validation

occt=shape(1)/shape(1) gmsh=reject ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Tier-3 assertions

  • n_edges_total >= 4
  • face[0].surface_type == "plane"
  • n_vertices_total >= 8
