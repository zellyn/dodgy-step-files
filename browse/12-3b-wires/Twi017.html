Twi017 — Closed 3D curve with two distinct VERTEX_POINTs (single-edge closed)

§12.3b wire-loop

Description

An EDGE_CURVE whose 3D curve is closed (full circle/ellipse) but cites two distinct VERTEX_POINTs as endpoints; per STEP/OCCT, a closed curve must reuse the same vertex at both ends.

Reproducer recipe

`EDGE_CURVE('',#v1,#v2,#circle_geom,.T.);` with `#circle_geom` a full `CIRCLE` and `#v1`, `#v2` distinct entities.

Expected kernel behavior

heal; translator reuses the first vertex on both ends.

Notes

The translator's edge-transfer pass must detect the closed-curve case and reuse the same vertex at both ends, regardless of how many distinct vertex entities the file references. **See also**: Twi002, Twi018. Synonyms: "circle edge has two distinct endpoints", "full circle stored with separate start and end vertex", "closed curve uses two vertex instances", "ellipse edge with mismatched endpoints", "periodic curve doesn't reuse vertex".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(3) ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Tier-3 assertions

  • n_edges_total == 1
  • n_vertices_total == 2
  • face[0].surface_type == "plane"
  • n_edges_total >= 1
  • edge[0].curve_type == "circle"
  • edge[0].analytic.radius == 1.0
