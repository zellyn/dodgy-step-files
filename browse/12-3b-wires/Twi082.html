Twi082 — Edge `same_range` flag claims parametric agreement that does not hold

Description

An edge declares its 3D-curve parameter range and pcurve parameter range to be identical (the `same_range` flag is set), but evaluating both at the boundary yields parameter pairs that differ by more than the edge's tolerance. Bug-reporter language: "parameter range mismatch", "same_range lies", "edge ranges disagree".

Reproducer recipe

Build an edge whose 3D `LINE` runs `t∈[0,10]` while the pcurve in UV runs `u∈[0,5]` (different parameterizations). Set the `same_range` flag true anyway.

Expected kernel behavior

Heal and accept: detect by comparing ranges; normalize / reset the flag, or repair one parameterization to match.

Notes

Bug-reporter synonym: "edge parameterization mismatch", "same_range flag claims agreement that doesn't hold", "parameter range mismatch between spatial and parametric curves", "edge same_range flag is wrong".
