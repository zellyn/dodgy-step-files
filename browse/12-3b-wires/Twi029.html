Twi029 — STEP writer drops entire wire if it contains a degenerate edge

§12.3b wire-loop

topology

View raw fixture (.stp) step-examples/12-3b-wires/Twi029.stp

Sources

  • 03-occt-tests.md R065 (bug25843_step)

Description

When an OCCT shape contains a wire with one or more degenerate edges (apex-bridge, seam) the writer historically omitted the entire wire on STEP export.

Reproducer recipe

BRep cone solid with apex degenerate edge; round-trip through OCCT writer; observe missing apex-bridge edge in output.

Expected kernel behavior

Heal and accept: emit degenerate edges; the reader normalizes / accepts them.

Notes

**See also**: Twi021. Synonyms: "writer drops wire with degenerate edge", "exporter omits cone apex bridge edge", "round-trip loses pole edges", "STEP write loses wires containing zero-length edges", "cone apex disappears on export".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(6) ifc=schema_n/a

Tier-3 assertions

  • face[0].surface_type == "cone"
  • n_edges_total >= 4
  • n_vertices_total >= 8
  • brepcheck.valid == True
