Description

vertex 4 is present in the vertex array at (5,5,5) but is not referenced by any triangle. In MeshFix's half-edge structure, such a vertex has a NULL e0 pointer — it was allocated but never connected. Two triangles form a valid quad; vertex 4 is a pure orphan with no incident edges.

Reproducer recipe

v0–v3 form a quad (2 triangles); v4=(5,5,5) added to vertex list but not used in any triangle.

Expected kernel behavior
