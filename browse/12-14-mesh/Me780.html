Me780 — polygon_soup_to_polygon_mesh orientation_inconsistency: adjacent t0=(v0,v1,v2) CCW and t1=(v1,v3,v2) opposing winding trigger orient_polygon_soup (Branch 1)

  • CGAL PMP `PMP.polygon_soup_to_polygon_mesh` Branch 1 (*orientation_inconsistency*: `if(!PMP::orient_polygon_soup(points, polygons)) { ... }`)
  • `MESH_HEAL_COVERAGE.md`.

Description

Two adjacent triangles sharing edge (v1,v2) with opposing winding. Triangle t0=(v0,v1,v2) has normal +Z (CCW). Triangle t1=(v1,v3,v2) has normal −Z, making the polygon soup orientation inconsistent across the shared edge. The soup-to-mesh converter must call orient_polygon_soup before building the half-edge structure → Branch 1 fires. Shared edge (v1,v2) n=2; four boundary edges n=1. Euler: V=4, E=5, F=2, chi=1.

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(1,1,0), v3=(0,1,0); t0=(v0,v1,v2) CCW normal +Z; t1=(v1,v3,v2) normal −Z; assert_edge_shared(v1,v2,2); boundary edges n=1; adjacent_triangles_inconsistent_winding(t0,t1); euler V=4,E=5,F=2,chi=1.

Expected kernel behavior

Branch 1 fires; orient_polygon_soup is called to rewind t1 so that the shared edge is traversed in opposite directions by the two adjacent polygons; conversion then proceeds.
