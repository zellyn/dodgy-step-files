Description

Post-retriangulation state: triangular hole (v0,v1,v2) has been re-filled with 3 Delaunay triangles using Steiner point vs=(1.5,1.0,0). Three frame triangles provide context. All edges from vs are interior (n=2); the original hole-boundary edges are now interior (n=2) shared between frame and re-tri triangles. Euler V=7,E=12,F=6,chi=1 confirms open-disk topology.

Reproducer recipe

v0=(0,0,0), v1=(3,0,0), v2=(1.5,3,0); vs=(1.5,1,0); 3 frame triangles + 3 re-tri triangles; assert edges (vX,vs) n=2; former boundary edges n=2; euler V=7,E=12,F=6,chi=1.

Expected kernel behavior

Branch 8 calls `TriangulateHole(e, vl)`; hole filled with 3 new triangles incorporating the Steiner point vs; mesh is repaired.
