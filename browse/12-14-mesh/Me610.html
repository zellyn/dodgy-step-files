Description

A single degenerate triangle (v0, v1, v2) where v0 and v1 both occupy (0,0,0). The squared length of the first edge sq_lengths[0] = dist(v0,v1)^2 = 0, triggering the early-exit guard at line 460 before any cap classification is attempted. A second valid context triangle is included. Vertex pair (v0,v1) distance is zero.

Branch 1 fires; is_zero(sq_lengths[0]) returns true for edge (v0,v1) with coincident endpoints; cap detection exits early without classifying the triangle.
