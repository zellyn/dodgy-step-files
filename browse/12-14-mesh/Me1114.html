Description

the mesh contains two valid non-degenerate triangles (0 and 2) and two zero-area collinear-vertex triangles (1 and 3). The degenerate triangles represent topology-blocker faces that would be evicted from faces_to_treat in the prior SI iteration. When they are removed, the candidate set becomes empty, triggering the Branch 5 early-exit check rather than an SI recomputation. Triangle 1 is collinear along Y-axis; triangle 3 is collinear along X-axis.

Reproducer recipe

Expected kernel behavior

detect zero-area faces; evict them from faces_to_treat; when set is empty, trigger Branch 5 check — exit loop early vs recompute SI.
