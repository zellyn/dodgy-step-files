Me148 — isInnerPoint_closest_is_edge_boundary: closest ray-hit is a boundary edge, isOnBoundary() true, return false

§12.14 mesh defects (sub-class: isInnerPoint / closest-is-edge boundary)

  • MeshFix `Basic_TMesh.isInnerPoint` Branch 15 (*closest_is_edge*: `if (closest_edge != NULL)`) and Branch 16 (*edge_on_boundary*: `if (closest_edge->isOnBoundary()) return false`)

Description

An open mesh of two triangles sharing interior edge (v0,v1). The four outer edges are mesh boundaries (each incident on exactly 1 triangle). When the closest ray-hit lies on a boundary edge, isOnBoundary() returns true and isInnerPoint returns false without ambiguity.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,1,0), v3=(1,-1,0); t0=(v0,v2,v1), t1=(v0,v1,v3).

Expected kernel behavior

if query projects onto a boundary edge, Branch 16 fires, return false.
