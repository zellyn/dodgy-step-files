Description

Closed tetrahedron — all 6 edges are interior (each shared by exactly 2 triangles). When TriangulateHole@L98 is called with any edge of this mesh, isOnBoundary() returns false and the function returns 0 immediately. No hole-filling can proceed on a closed mesh. Euler: V=4, E=6, F=4, chi=2 (genus-0 closed surface).

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0.5,1,0), v3=(0.5,0.5,1); t0=(v0,v2,v1), t1=(v0,v1,v3), t2=(v1,v2,v3), t3=(v0,v3,v2); all 6 edges assert_edge_shared n=2; euler V=4,E=6,F=4,chi=2.

Expected kernel behavior

Branch 1 fires; `!e->isOnBoundary()` is true for every edge; return 0 without attempting fill.
