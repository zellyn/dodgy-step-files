Description

Two disconnected closed components: a unit tetrahedron (component A) and a micro-tetrahedron at (20,20,20) with edge length 0.001 (volume ≈ 1.18e-10, component B). When no explicit volume threshold is supplied, Branch 2 computes `volume_threshold = 0.01 * bbox_diagonal^3`. Component B's volume is far below this default. Exercises `is_default_volume_threshold` / `bbox_diagonal` inference.

Reproducer recipe

unit tetrahedron at origin (t0-t3); micro-tetrahedron at (20,20,20) with s=0.001 (t4-t7).

Expected kernel behavior

infer volume_threshold from bbox diagonal; micro-component volume < threshold → flagged for removal.
