Me058 — parallel count-limit: 4 SI pairs; atomic counter fires Throw_functor at limit 3

§12.14 mesh defects (sub-class: self-intersection/parallel-count-limit)

spec-violation

View raw fixture (.mesh.json) mesh-examples/12-14-mesh/Me058.mesh.json

Sources

  • CGAL `PMP.self_intersections_impl` Branch 7 @ line 459 (*output-limit-in-parallel*)
  • `MESH_HEAL_COVERAGE.md`.

Description

four crossing pairs along the Z-axis (z=0, 10, 20, 30). In parallel mode with `do_limit`, the output callback is wrapped with a `Throw_functor + atomic_counter`; when any TBB thread causes the counter to reach `maximum_number`, the functor throws. With limit=3, pair D (z=30) triggers the atomic counter.

Reproducer recipe

four pairs of XY/XZ crossing triangles at z=0, 10, 20, 30 via `_pair(m, oz)` helper. Z-axis spread gives distinct AABB boxes.

Expected kernel behavior

parallel atomic counter fires at limit=3; TBB thread hitting pair D throws.
