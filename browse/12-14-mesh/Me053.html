Description

single pair of crossing triangles (XY plane and XZ plane sharing apex). When `throw_on_SI` is set, this pair raises `Throw_at_output_exception` rather than appending to the output iterator. Minimal geometry to fire Branch 4; used by callers that only need boolean SI presence.

Reproducer recipe

Expected kernel behavior

under throw_on_SI raise exception on this pair; under accumulate mode append (tri0,tri1).
