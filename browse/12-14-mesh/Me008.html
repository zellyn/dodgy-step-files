Me008 — isolated vertex: vertex 3 has no incident triangle

Sources

  • `MESH_DEFECT_TAXONOMY.md` #8 (`isolated_vertex`)
  • CGAL `remove_isolated_vertices`, `remove_isolated_points_in_polygon_soup`.

Description

vertex 3 at `(5,5,5)` is present in the vertex list but is not referenced by any triangle. It pollutes vertex-count-based Euler characteristic checks and wastes memory in index structures. CGAL `remove_isolated_vertices` silently removes it.

Reproducer recipe

4 vertices; single triangle referencing vertices 0, 1, 2; vertex 3 is an orphan unreferenced by any face.

Expected kernel behavior

detect unreferenced vertices and remove them or report them separately from mesh topology checks.
