Me351 — CreateTriangle_e2_e3_orientation_check: e2->v2 is junction with e3, assign e2->t1 slot

§12.14 mesh defects (sub-class: Basic_TMesh.CreateTriangle / orientation-slot-assignment)

Sources

  • MeshFix `Basic_TMesh.CreateTriangle` Branch 2 (*e2_e3_orientation_check*: `e2->commonVertex(e3)==e2->v2 && e2->t1==NULL`)
  • `MESH_HEAL_COVERAGE.md`.

Description

Reference triangle tref=(v0,v1,v2) occupies one slot of edge (v1,v2). The new triangle tf=(v3,v1,v2) is created by CreateTriangle with e2=(v1,v2). e2's head vertex v2 is also the start of e3=(v2,v3), so Branch 2 fires: e2->t1 is free, at2=&(e2->t1). After creation (v1,v2) becomes interior (n=2).

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(2,2,0), v3=(0,2,0); tref=(v0,v1,v2); tf=(v3,v1,v2). Assert edge(v1,v2) n=2, edge(v2,v3) n=1, other edges n=1.

Expected kernel behavior

Branch 2 fires; at2 set to &(e2->t1); shared edge (v1,v2) has n=2 after CreateTriangle.
