Description

3-triangle strip where a boundary edge e=(v0,v1) is split at midpoint vn=(1,0,0). Post-split: t0=(v0,vn,v2), t1=(vn,v1,v2), t2=(v1,v3,v2). ne1=(vn,v2) is the new edge appended to E; nt1=t1 is appended to T; vn is appended to V. Edge (v1,v2) is interior (n=2), shared between nt1 and the neighbor t2.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,2,0), v3=(3,2,0), vn=(1,0,0); t0=(v0,vn,v2), t1=(vn,v1,v2), t2=(v1,v3,v2).

Expected kernel behavior

V.appendHead(vn), E.appendHead(ne1), T.appendHead(nt1) registers all new elements in the mesh lists for subsequent passes.
