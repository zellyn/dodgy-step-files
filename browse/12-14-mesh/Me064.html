Description

Reproducer recipe

8 vertices; polygon 0 = clean triangle (v0,v1,v2); polygon 1 = hexagon (v3,v4,v5,v3,v6,v7) with v3 repeated.

Expected kernel behavior

skip polygon 0 (size ≤ 3); scan and split polygon 1 at v3; push_back the second sub-triangle.
