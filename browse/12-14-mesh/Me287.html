Me287 — checkGeometry_overlapping_triangles_dihedral: adjacent coplanar triangles with dihedral = 180° (Branch 8)

§12.14 mesh defects (sub-class: checkGeometry / overlapping-triangles-dihedral)

Sources

  • MeshFix `checkAndRepair::checkGeometry` Branch 8 (*OVERLAPPING_TRIANGLES_DIHEDRAL*: `getDAngle(e->t2) == M_PI`)
  • `MESH_HEAL_COVERAGE.md`.

Description

Two triangles sharing edge (v1,v2): t0=(v0,v1,v2) and t1=(v2,v1,v3) both lie in the z=0 plane. Both are wound counter-clockwise, giving normals in the +Z direction. The dihedral angle between them along the shared edge is 180° — they fold flat in the same direction. When projected, the triangles occupy the same half-space and form an overlapping coplanar pair. checkGeometry detects this via getDAngle returning π and returns the edge's v1 vertex.

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0,1,0), v3=(1,1,0) in z=0; t0=(v0,v1,v2) CCW; t1=(v2,v1,v3) CCW; shared edge (v1,v2) n=2; assert adjacent_triangles_normal_dot_gt > 0.99.

Expected kernel behavior

Branch 8 fires; defect logged as 'overlapping triangles detected', 'getDAngle(e->t2) == M_PI'; edge v1 returned as defect location.
