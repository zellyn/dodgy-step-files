Description

Cap triangle t0=(v0,v1,v2) with v2=(1,0.0001,0) as cap vertex. The long opposite base edge v0-v1 (length 2.0) is a boundary edge (n=1). The cap's long edges v0-v2 and v1-v2 are shared with upper support triangles (n=2). is_border returns true for the opposite halfedge of the cap vertex → algorithm removes the face.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,0.0001,0), v3=(0,1,0), v4=(2,1,0); t0=(v0,v1,v2) cap; t1=(v0,v2,v3), t2=(v3,v2,v4), t3=(v2,v1,v4) support; edge_shared(v0,v1,1); edge_shared(v0,v2,2); edge_shared(v1,v2,2); triangle_area_lt(0,0.001); triangle_aspect_ratio_gt(0,1000).
