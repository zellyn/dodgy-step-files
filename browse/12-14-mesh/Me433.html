Me433 — forceNormalConsistence boundary-edge-detected: open mesh; isOnBoundary() true → isclosed cleared (Branch 4)

Description

Four triangles forming an open two-square strip (L-shape). t0=(v0,v1,v3) and t1=(v0,v3,v2) form the left square; t2=(v1,v4,v5) and t3=(v1,v5,v3) form the right square. All triangles have +z normal (consistently oriented). Three interior edges are n=2: (v0,v3), (v1,v3), (v1,v5). Six boundary edges are n=1: (v0,v1),(v0,v2),(v2,v3),(v1,v4),(v4,v5),(v3,v5). forceNormalConsistence finds these boundary edges and sets isclosed=false → Branch 4. The hole_boundary oracle assertion confirms the boundary loop.

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0,1,0), v3=(1,1,0), v4=(2,0,0), v5=(2,1,0); t0=(v0,v1,v3), t1=(v0,v3,v2), t2=(v1,v4,v5), t3=(v1,v5,v3); interior edges n=2; boundary edges n=1; hole_boundary([v0,v1,v4,v5,v3,v2]).

Expected kernel behavior

Branch 4 fires on every boundary edge; isclosed is cleared; the return value indicates an open mesh.
