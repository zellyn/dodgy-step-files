Description

two triangle entries that reference the exact same three vertex indices (a true duplicate). MeshFix's `intersects` predicate fast-exits at Branch 2 before running any geometry test — identical triangles are not considered a self-intersection; they are a duplicate-triangle defect handled by the merge pass. Each edge is shared by exactly 2 (both copies).

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0,1,0). t0=(v0,v1,v2), t1=(v0,v1,v2) — same indices.

detect as duplicate-triangle defect (merge-duplicate-polygons path), not as self-intersection.
