Description

a 4-vertex polygon (v0,v1,v2,v0) is the minimum-size polygon that can be pinched (Branch 2 skips ≤3 vertices). v0 is repeated at positions 0 and 3. split_polygon_1 = (v0,v1,v2,v0) → simplify → (v0,v1,v2) [triangle]. split_polygon_2 = (v0) [trivial, skipped by small_polygon_skip]. A clean companion triangle is also in the soup, exercising the iteration past the split result.

Reproducer recipe

6 vertices; polygon 0 = 4-vertex pinched (v0,v1,v2,v0); polygon 1 = clean triangle (v3,v4,v5).

Expected kernel behavior

detect v0 repetition at position 3; split to triangle + trivial 1-vertex polygon; discard trivial sub-polygon via Branch 2.
