Me932 — PMP.orient self-intersecting-pair-detection: Component B shell has t4 pierced by t5; self_intersecting_cc.insert() fires (Branch 3)

§12.14 mesh defects (sub-class: self_intersection / orient-si-detection)

topology

Sources

  • CGAL PMP `PMP.orient (main dispatcher)` Branch 3 (*self-intersecting-pair-detection*: `if(does_self_intersect(...)) self_intersecting_cc.insert(cc_id)` @ line 1001)
  • `MESH_HEAL_COVERAGE.md`.

Description

Two closed components. Component A is a clean tetrahedron. Component B is a closed 8-face shell where face t4 (in the Y=0 plane) is genuinely pierced by face t5 (straddling Y=0, with vertices at Y=-1 and Y=+1). does_self_intersect returns true for Component B, so Branch 3 fires and it is inserted into self_intersecting_cc, skipping the nesting orientation test.

Reproducer recipe

Component A: clean tetra a0-a3; Component B: 8-face closed shell b0-b5 with t4 and t5 piercing each other; B unreachable from A; assert triangles_self_intersect([4,5]); euler V=10, E=18, F=12, chi=4.

Expected kernel behavior

Branch 3 fires; does_self_intersect(Component B) returns true; Component B inserted into self_intersecting_cc; orientation-by-nesting skipped for Component B.
