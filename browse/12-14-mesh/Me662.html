Description

Two triangles sharing interior edge (q0,q2) with four distinct vertex coordinates. Every point insert into the coordinate-keyed map succeeds; for each insertion id equals unique_points.size() so the point is pushed to unique_points (Branch 3 fires 4 times). After the scan, unique_points.size()==4==ini_points_n so no remapping is needed. Interior edge (q0,q2) n=2; four outer edges n=1. Euler: V=4, E=5, F=2, chi=1.

Reproducer recipe

q0=(0,0,0), q1=(2,0,0), q2=(1,2,0), q3=(0,2,0); t0=(q0,q1,q2), t1=(q0,q2,q3); assert_edge_shared(q0,q2,2); outer edges n=1; euler V=4,E=5,F=2,chi=1.

Expected kernel behavior

Branch 3 fires once per vertex (4 times); all inserts succeed; unique_points.size()==ini_points_n==4; merge_needed_check (Branch 4) does NOT fire; polygon indices unchanged.
