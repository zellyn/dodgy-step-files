Description

A mesh where hole corner h0=(1,2,0) is adjacent to a pre-selected triangle (IS_VISITED). Branch 1's scan sets IS_BIT(h0,6). When the boundary-traversal loop visits h0, Branch 3 fires: grd is forced to nbe+1 (above the fill threshold) and the inner loop breaks, skipping this hole entirely.

Reproducer recipe

selected patch: ts0=(s0,s1,h0), ts1=(s0,h0,s2) share h0; hole frame: tf0-tf2 surround triangular hole (h0,h1,h2) with anchor a; hole edges n=1; frame-to-fill edges n=2.

Expected kernel behavior

Branch 3 fires; IS_BIT(h0,6) is true; grd set to nbe+1; boundary-traversal inner loop breaks; hole is not filled.
