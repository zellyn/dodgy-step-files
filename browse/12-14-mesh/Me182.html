Description

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,1,0), vn=(1,0,0); t0=(v0,v1,v2). vn on edge (v0,v1).

Expected kernel behavior

e->t1 != NULL → v3 = e->t1->oppositeVertex(e) = v2; t2 is NULL so v4 is skipped.
