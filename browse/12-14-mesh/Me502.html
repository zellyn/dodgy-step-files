Description

Needle triangle t0=(v0,v1,v2) with short boundary edge v0-v1=0.001 (n=1). The long edges v0-v2 and v1-v2 are each shared with flanking healthy triangles (n=2). The shortest edge is a border halfedge → is_border returns true → algorithm calls Euler::remove_face to delete the needle triangle instead of collapsing through a boundary edge.

Reproducer recipe

v0=(0,0,0), v1=(0.001,0,0), v2=(0.5,0.866,0), v3=(1,0.866,0), v4=(-0.5,0.866,0); t0=(v0,v1,v2) needle; t1=(v1,v3,v2), t2=(v2,v4,v0) flanks; edge_shared(v0,v1,1); edge_shared(v1,v2,2); edge_shared(v0,v2,2); vertex_pair_distance_lt(v0,v1,0.002); triangle_area_lt(0,0.01); triangle_aspect_ratio_gt(0,100).

Branch 3 fires; is_border(min_edge) true; Euler::remove_face removes the needle triangle.
