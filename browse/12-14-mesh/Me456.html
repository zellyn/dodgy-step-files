Description

A 2x2 quad patch (component A, area = 2.0) and a nano-triangle (component B, area ≈ 1.25e-7, edge length 0.0005). After BFS removes component B (pa < eps_area), rem_comps = 1 > 0 triggers Branch 7: topology dirty flags d_boundaries=d_handles=d_shells=1 are set and removeUnlinkedElements() purges the unlinked nano-triangle. Interior edges (v0,v4), (v1,v5), (v1,v4) n=2; nano-triangle boundary edges n=1 each.

Reproducer recipe

v0-v5 form 2x2 grid (t0-t3); v6-v8 nano-tri at (50,50) with edge 0.0005 (t4); assert_triangle_not_reachable_from(t4,t0); assert_triangle_area_lt(t4,1e-4); interior edges n=2; nano boundary edges n=1.

Expected kernel behavior

Branch 7 fires; rem_comps == 1 > 0 → d_boundaries = d_handles = d_shells = 1; removeUnlinkedElements() called to purge component B.
