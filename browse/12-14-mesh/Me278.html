Description

Three triangles where t1 and t2 each cross t0 such that both independently contribute the same 3D intersection point (v0=(0,0,0) on t0's boundary). After collection the sorted intersection-point list contains a geometric duplicate. Branch 9 detects adjacent equal entries and maps the second id to the first via id_map, preventing double-insertion.

Reproducer recipe

t0 horizontal panel; t1 and t2 each touch t0's boundary at the same vertex (0,0,0); assert vertex_on_edge(v5, [0,1]); assert vertex_pair_distance_lt([5,8], 1e-12).

Expected kernel behavior

Branch 9 fires; points[indices[i]]==points[indices[i+1]] true for the duplicate; second id redirected to first via id_map; only one refinement point inserted.
