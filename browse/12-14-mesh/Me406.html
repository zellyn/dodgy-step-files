Description

Two triangles sharing interior edge (d0,d2); boundary vertices d1 and d3 both at (2,0,0) — minimal single-pair fixture. One candidate group {d1,d3} is formed and survives sanitize_candidates unchanged. The output loop runs exactly once, mapping each sorted index back to its halfedge descriptor → Branch 7 fires. Interior edge (d0,d2) n=2; four outer edges n=1. Euler: V=4, E=5, F=2, chi=1.

Branch 7 fires; the single surviving group is iterated and cycle_hedges[id] is used to populate hedges_with_identical_point_target with the actual halfedge descriptor pair.
