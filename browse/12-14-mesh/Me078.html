Description

vertex 0 is a singular vertex with 3 link CCs (three fans at different Z heights: z=0, z=2, z=4). After repair, the point_duplication_loop creates 2 new clone points (Branch 11 fires twice) and the polygon_index_replacement sub-pass (Branch 12) updates 2 triangle references. The fixture stresses the multi-duplication path in a fully 3D configuration.

Reproducer recipe

v0=(0,0,0); fan A at z=0 (v1,v2); fan B at z=2 (v3,v4); fan C at z=4 (v5,v6); 3 triangles total, no shared edges.

Expected kernel behavior

split v0 into 3 copies; fan A retains original; fans B and C receive the 2 new clones; vertex count increases by 2.
