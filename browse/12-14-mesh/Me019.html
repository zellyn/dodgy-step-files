Me019 — SI region with degenerate zero-area faces: faces_to_treat empties after removal

§12.14 mesh defects (sub-class: self-intersection/degenerate-cluster)

topology

Sources

  • CGAL `PMP.remove_self_intersections` Branch 5 @ line 2463 (*face-selection-emptiness-detection*)
  • `MESH_HEAL_COVERAGE.md`.

Description

the mesh contains both valid triangles (0 and 2) and zero-area collinear-vertex triangles (1 and 3). The degenerate triangles represent the "blocking" elements left after a partial SI-heal pass. When a healer removes the zero-area faces first, the faces_to_treat set becomes empty, triggering the early-exit branch rather than an SI recomputation.

Reproducer recipe

4 triangles; tri 0 valid in z=0 plane; tri 1 = three collinear points along X axis (area=0); tri 2 valid in x=0 plane; tri 3 = three collinear points along Z axis (area=0).

Expected kernel behavior

detect zero-area faces and remove them; after removal the candidate set is empty — exit the SI loop rather than recompute.
