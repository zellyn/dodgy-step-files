Me520 — iterativeEdgeSwaps selection_exists: partial selection of triangles; swaps restricted to IS_VISITED region (Branch 1)

§12.14 mesh defects (sub-class: mesh-optimization / iterative-edge-swaps / selection)

topology

Sources

  • MeshFix `Basic_TMesh.iterativeEdgeSwaps` Branch 1 (*selection_exists*: `if (IS_VISITED(t)) selection = 1
  • `)
  • `MESH_HEAL_COVERAGE.md`.

Description

Six-vertex, four-triangle mesh with two adjacent quads. The left quad (t0, t1) represents the "selected" region (IS_VISITED). When iterativeEdgeSwaps scans all triangles and finds at least one with IS_VISITED set, it sets `selection=1` (Branch 1 fires) and subsequent edge-swap candidates are restricted to the selected region only. The interior edge (v1,v2) is shared by t0 and t1 (within selection); (v1,v3) crosses the selection boundary. Three interior edges (n=2); six boundary edges (n=1).

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0.5,1,0), v3=(1.5,1,0), v4=(2,0,0), v5=(1,2,0); t0=(v0,v1,v2), t1=(v1,v3,v2) [selected], t2=(v1,v4,v3), t3=(v3,v5,v2); assert_edge_shared(v1,v2,2), (v1,v3,2), (v2,v3,2); boundary edges n=1.

Expected kernel behavior

Branch 1 fires; `selection` variable set to 1; subsequent edge swap candidates are only enqueued from triangles where IS_VISITED(t) is true.
