Description

Two completely disjoint triangle patches, both in the selection (IS_VISITED). BFS starts at Patch A (t0) and visits only t0 (nv=1). s->numels()=2 because t1 (Patch B) is also selected but unreachable. Branch 5 fires: nv(1) != numels(2) → return 0. All edges are boundary (n=1). t1 not reachable from t0. Euler: V=6, E=6, F=2, chi=2.
