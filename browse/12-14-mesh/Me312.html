Description

A 4-triangle fan with outer square v0-v3 and hub v4=(1,1,0). For t0=(v0,v1,v4), v4 occupies the 'v2 slot' (third argument). Branch 3 fires when v4 is first encountered as a cavity boundary vertex, appending it to 'bdr'.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(2,2,0), v3=(0,2,0), v4=(1,1,0); 4 fan triangles; assert hub edges n=2, outer edges n=1, hole_boundary [v0,v1,v2,v3].

Expected kernel behavior

Branch 3 fires when v4 (v2 slot of t0) is first appended to bdr; marked bit 5.
