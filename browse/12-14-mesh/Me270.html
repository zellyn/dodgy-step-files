Description

Two well-separated non-intersecting triangles. The bbox-based intersection query returns an empty si_pairs collection so Branch 1 is taken immediately and the function copies the input triangles verbatim without entering the refinement pipeline. The output triangle count equals the input triangle count (number_of_output_triangles == number_of_input_triangles).

Reproducer recipe

t0=(v0,v1,v2) and t1=(v3,v4,v5) separated by 5 units in X; all edges n=1; triangles_do_not_intersect([0,1]).
