Me1001 — remove_connected_components.by_face_range Logic_guard: unconstrained vertices (!get(is_cst,v)) in face_range; 4-tri component A + 2-tri unconstrained component B (Branch 2)

Description

Two disconnected components. Component A is a 4-triangle closed fan around hub v0=(0,0,0) with rim vertices v1-v4 (all hub edges shared by 2 triangles). Component B is a 2-triangle rectangular patch at x=20 with vertices v5-v8; all of B's vertices are unconstrained. When the face_range covers B's faces (t4, t5), each incident vertex v satisfies !get(is_cst, v) == true, firing Branch 2 for unconditional face removal. B is unreachable from A. Shared diagonal v6-v7 in B is n=2; all other B edges are n=1. Euler: V=9, E=13, F=6, chi=2.

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(0,1,0), v3=(-1,0,0), v4=(0,-1,0); t0=(v0,v1,v2), t1=(v0,v2,v3), t2=(v0,v3,v4), t3=(v0,v4,v1); v5=(20,0,0), v6=(21,0,0), v7=(20,1,0), v8=(21,1,0); t4=(v5,v6,v7), t5=(v6,v8,v7); triangle_not_reachable_from(4,0); hub edges A n=2; diagonal v6-v7 n=2; euler V=9,E=13,F=6,chi=2.

Expected kernel behavior

Branch 2 fires; !get(is_cst, v) is true for every vertex in t4 and t5; faces removed unconditionally from the mesh.
