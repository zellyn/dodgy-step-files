Me281 — checkGeometry_coincident_vertices_edge_absent: two coincident vertices without connecting edge (Branch 2)

Sources

  • MeshFix `checkAndRepair::checkGeometry` Branch 2 (*COINCIDENT_VERTICES_EDGE_ABSENT*: `getEdge(v2) == null`)
  • `MESH_HEAL_COVERAGE.md`.

Description

Two vertices v0 and v3 both at (0,0,0) belong to separate triangles with no edge connecting them. In the half-edge structure, getEdge(v3) returns null when queried from v0 because no triangle contains both. checkGeometry detects this by sorting vertices by coordinate: consecutive entries have distance 0 but no half-edge link. It marks v0 as defective and continues.

Reproducer recipe

t0=(v0,v1,v2) with v0=(0,0,0); t1=(v3,v4,v5) with v3=(0,0,0); no triangle references both v0 and v3.

Expected kernel behavior

Branch 2 fires; defect flagged as 'detected coincident vertices, getEdge(v2) == null'; mesh marked as defective; scan continues.
