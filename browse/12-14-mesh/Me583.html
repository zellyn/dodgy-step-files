Description

Three triangles in a closed fan around hub v0 with rim vertices v1, v2, v3. All triangles are IS_VISITED. A seed (t0) is provided; BFS collects all 3 triangles. When keep_ref=true, Branch 4 fires for each vertex: the info pointer from the original mesh vertex is preserved in the sub-mesh vertex's info slot (rather than being cleared). Interior spoke edges (v0,v1),(v0,v2),(v0,v3) all n=2; outer rim edges n=1. Euler: V=4, E=6, F=3, chi=1.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,2,0), v3=(-1,2,0); t0=(v0,v1,v2), t1=(v0,v2,v3), t2=(v0,v3,v1); spoke edges (v0,v1),(v0,v2),(v0,v3) n=2; rim edges (v1,v2),(v2,v3),(v3,v1) n=1; euler V=4,E=6,F=3,chi=1.

Expected kernel behavior

Branch 4 fires for each of the 4 vertices during sub-mesh construction; `v_info = new void*; *v_info = (*v)->info` copies the original mesh's info pointer, preserving external references in the extracted sub-mesh.
