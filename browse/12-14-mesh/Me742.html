Description

Four collinear hole-boundary vertices h0=(0,0,0), h1=(1,0,0), h2=(2,0,0), h3=(3,0,0) all on the X-axis form a closed loop h0→h1→h2→h3→h0. A top fan (3 triangles sharing apex fa=(1.5,2,0)) and one bottom bridge triangle (apex fb=(1.5,-1,0)) frame the hole. The internal angles at h1 and h2 are 180° (collinear), so no valid triangulation vertex exists. gang stays at DBL_MAX → Branch 3 fires, vertices are unmarked, created triangles unlinked, and 0 is returned.

Reproducer recipe

h0=(0,0,0), h1=(1,0,0), h2=(2,0,0), h3=(3,0,0), fa=(1.5,2,0), fb=(1.5,-1,0); top fan t0=(h0,h1,fa), t1=(h1,h2,fa), t2=(h2,h3,fa); bridge t3=(h3,h0,fb); interior (h1,fa) and (h2,fa) n=2; hole loop boundary edges n=1; assert_hole_boundary([h0,h1,h2,h3]); euler V=6,E=10,F=4,chi=0.

Expected kernel behavior

Branch 3 fires; gang==DBL_MAX; hole vertices unmarked; newly linked triangles unlinked; function returns 0.
