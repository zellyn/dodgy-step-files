Me055 — sequential count-limit: 3 SI pairs; Count_and_throw_filter fires after pair 2

§12.14 mesh defects (sub-class: self-intersection/sequential-count-limit)

Sources

  • CGAL `PMP.self_intersections_impl` Branch 10 @ line 497 (*output-limit-in-sequential*)
  • `MESH_HEAL_COVERAGE.md`.

Description

three spatially separated crossing pairs at x=0, x=10, x=20. In sequential mode with `do_limit`, the callback is wrapped in a `Count_and_throw_filter`; after `maximum_number` pairs are recorded it throws. With limit=2, pair C (x=20) is never returned.

Reproducer recipe

three pairs of XY/XZ crossing triangles with apexes at x=0, 10, 20. Each shares an apex and crosses along the X-direction.

Expected kernel behavior

collect pairs A and B (limit=2); catch exception and return without pair C.
