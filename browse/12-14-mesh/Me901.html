Description

Three non-degenerate query triangles in a fan from hub=(0,0,0); three matching non-degenerate reference triangles at z=−1 with clear 1-to-1 spatial proximity. For each query triangle the centroid lies closest to the corresponding reference face; tree.closest_point_and_primitive returns a valid primitive → Branch 2 fires three times. Interior hub-spoke edges each n=2; three boundary outer edges n=1; Euler V=4, E=6, F=3, chi=1.

hub=(0,0,0), a=(2,0,0), b=(-1,1.732,0), c=(-1,-1.732,0); r_hub=(0,0,-1), r_a=(2,0,-1), r_b=(-1,1.732,-1), r_c=(-1,-1.732,-1); t0=(hub,a,b), t1=(hub,b,c), t2=(hub,c,a); ref_t0=(r_hub,r_a,r_b), ref_t1=(r_hub,r_b,r_c), ref_t2=(r_hub,r_c,r_a); assert_edge_shared(hub,a,2), (hub,b,2), (hub,c,2); boundary outer edges n=1; euler V=4,E=6,F=3,chi=1.

Expected kernel behavior

Branch 2 fires for each of the three query triangles; closest_point_and_primitive returns a valid primitive (non-empty AABB result) and the corresponding reference normal is extracted for orientation comparison.
