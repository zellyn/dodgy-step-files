Me107 — unlink_triangle_isolated_edge_pair_v2: v2's both incident edges isolated, v2 becomes orphan

§12.14 mesh defects (sub-class: triangle-unlink / isolated-edge-pair-v2)

topology

Sources

  • MeshFix `Basic_TMesh.unlinkTriangle` Branch 8 (*isolated_edge_pair_v2*: `if (e2->isIsolated() && e3->isIsolated())`)
  • `MESH_HEAL_COVERAGE.md`.

Description

v1 (second vertex of target t0) appears in exactly one triangle — the target. Both edges (v0,v1) and (v1,v2) are in t0 only. After t0 is unlinked, both edges become isolated and v1 loses all connectivity. Branch 8 sets v1->e0 = NULL. Mirror of Me106 but for the second vertex position.

Reproducer recipe

v0=(0,0,0), v1=(1,0,0), v2=(2,0,0), v3=(1,1,0), v4=(0,1,0), v5=(2,1,0). t0=(v0,v1,v2); t1=(v0,v3,v4); t2=(v0,v2,v3); t3=(v2,v5,v3).

Expected kernel behavior

after unlink of t0, set v1->e0 = NULL; mark v1 as fully disconnected.
