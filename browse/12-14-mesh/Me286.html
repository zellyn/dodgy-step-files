Me286 — checkGeometry_degenerate_triangle_flat_angle: interior angle = 180° (pi) at pivot vertex (Branch 7)

Description

Triangle t1=(q0,q1,q2) with q0=(0,-1,0), q1=(1,-1,0), q2=(2,-1,0) — all collinear along y=-1. The pivot vertex is q1 at the MIDDLE of the collinear triple. Vectors from q1 to q0=(-1,0,0) and from q1 to q2=(+1,0,0) are anti-parallel. The interior angle at q1 = arccos(-1) = π = 180°. Area is exactly zero. This distinguishes the "flat" (π) branch from the "zero" (0) branch (Me285).

Reproducer recipe

c0-c2 clean triangle (t0); q0=(0,-1,0), q1=(1,-1,0), q2=(2,-1,0) collinear with q1 in MIDDLE (t1); assert triangle_area_lt(1, 1e-12).

Expected kernel behavior

Branch 7 fires; defect logged as 'ang == M_PI'; function returns q1 as defect vertex.
