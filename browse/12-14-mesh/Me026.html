Description

every triangle in the mesh is collinear (area exactly 0). Four triangles at y=0,1,2,3 are each three points on a horizontal line in z=0. The degenerate face set equals the full face set, triggering CGAL's remove-all-elements early-exit path (`degenerate_face_set.size() == faces_size`).

Reproducer recipe

12 vertices on four parallel X-axis lines at y=0,1,2,3; four triangles each referencing three collinear points — every triangle has area=0.

Expected kernel behavior

detect the all-faces-degenerate condition; remove all elements without entering the main repair loop.
