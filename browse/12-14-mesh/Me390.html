Description

Two coplanar triangles sharing the full edge (v0,v1). The second triangle's apex v3=(1,1,0) lies strictly inside the first triangle's interior. Branch 1 fires when `faces_have_a_shared_edge` is true — routing to the coplanar + overlap test, which detects the interior overlap as a self-intersection. The shared edge (v0,v1) is incident on both triangles (n=2).
