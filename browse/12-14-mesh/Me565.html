Description

Four triangles (t0–t3) arranged around a swap-candidate diagonal (v2,v3). v2=(1,0.1,0) is a near-base midpoint vertex (the IS_VISITED2 newly-inserted vertex after split); v3=(1,2,0) is an original old vertex. Euler: V=5, E=8, F=4, chi=1.

Expected kernel behavior

Branch 6 fires on edge (v2,v3); IS_VISITED2(v2)=true (new midpoint), IS_VISITED2(v3)=false (original vertex); condition true → e->swap() called to improve aspect ratios.
