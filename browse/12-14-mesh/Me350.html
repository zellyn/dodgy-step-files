Me350 — CreateTriangle_e1_e2_orientation_check: e1->v2 is junction with e2, assign e1->t1 slot

§12.14 mesh defects (sub-class: Basic_TMesh.CreateTriangle / orientation-slot-assignment)

topology

Sources

  • MeshFix `Basic_TMesh.CreateTriangle` Branch 1 (*e1_e2_orientation_check*: `e1->commonVertex(e2)==e1->v2 && e1->t1==NULL`)
  • `MESH_HEAL_COVERAGE.md`.

Description

Four vertices forming two existing triangles plus a fill triangle. The fill triangle tf=(v0,v2,v3) is created by CreateTriangle with e1=(v0,v2). Edge e1's head (v2) is the junction with e2=(v2,v3), and e1->t1 is free, so Branch 1 sets at1=&(e1->t1). After creation edge (v0,v2) is interior (n=2), confirming the t1 slot was assigned.

Reproducer recipe

v0=(0,0,0), v1=(2,0,0), v2=(1,2,0), v3=(3,2,0); t0=(v0,v1,v2), t1=(v1,v3,v2); tf=(v0,v2,v3). Assert edge(v0,v2) n=2, edge(v1,v2) n=2, edge(v2,v3) n=2, boundary edges n=1.

Expected kernel behavior

Branch 1 fires; at1 set to &(e1->t1); edge (v0,v2) becomes interior after CreateTriangle completes.
