Gb002 — Surface tangent / normal undefined at a parameter (LProp_Status.Undefined)

Description

A surface property query (tangent in U, V, or normal) at a specific UV parameter returns "undefined" because the surface partial derivatives vanish there (a pole, a degenerate corner). Bug-reporter language: "surface tangent undefined", "normal not computable", "pole on surface".

Reproducer recipe

An `SPHERICAL_SURFACE`; query the U-tangent at `v = π/2` (the pole). The U-tangent is zero.

Expected kernel behavior

Reject with status: return the undefined status to the caller; do not return a NaN or arbitrary unit vector. Must not silently accept.

Notes

Common cause of NaN propagation when the caller assumes Defined. Bytes alone are insufficient to demonstrate this defect — needs sibling input fixture. Tagged provenance_tier: runtime-only. Synonyms: "surface tangent undefined", "normal not computable", "pole on surface returns LProp_Status.Undefined", "surface partial derivatives vanish at parameter", "U-tangent zero at sphere pole".
