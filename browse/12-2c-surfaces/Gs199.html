Description

A single `ADVANCED_FACE` on a `TOROIDAL_SURFACE` (major radius 6.0, minor radius 2.0) has a `VERTEX_LOOP` (one `VERTEX_POINT` on the outer equator) as its sole `FACE_OUTER_BOUND`. Per ISO 10303-42, a lone `VERTEX_LOOP` bound is meant to signal "the face is the surface's whole natural domain, with the point marking a degenerate apex/pole" — valid for a sphere (`Gs039`) or a plane (`Twi281`, with an explicit warning). A torus has no such degenerate point (it is doubly periodic with no pole), so the reader's face-building stage neither builds a natural-bound wire for it (unlike sphere/B-spline/revolution) NOR warns (unlike plane) — the bound is simply skipped mid-loop, silently.

Reproducer recipe

`TOROIDAL_SURFACE('name',#axis2placement3d,6.0,2.0)`; a `VERTEX_POINT` at `(8.0,0.0,0.0)` (on the outer equator, `major_radius+minor_radius` from the axis); `VERTEX_LOOP('name',#vertex_point)`; `FACE_OUTER_BOUND('',#vertex_loop,.T.)` as the SOLE bound of `ADVANCED_FACE`; `OPEN_SHELL` + `SHELL_BASED_SURFACE_MODEL`.

Expected kernel behavior

A conformant reader must either (a) treat a lone `VERTEX_LOOP` bound on a non-degenerate-pole surface (torus) as a malformed/inapplicable file and reject it with a diagnostic, or (b) explicitly document and warn when substituting the surface's natural bounds — silently dropping the bound with zero diagnostic (as OCCT's default pipeline does) leaves no trace that the original (malformed) boundary intent was discarded.

Notes

Live-verified directly against the fixture's own bytes through OCCT's DEFAULT reader pipeline (this mechanism is part of the ordinary reader's face-building transfer, unlike Gn177-Gn179's opt-in healers — no explicit extra API call is needed): the face reads as shape(1), 1 face, a toroidal surface, face area `473.7410112522892` — EXACTLY the full-torus surface-area formula `4·π²·R·r = 4·π²·6·2 = 473.7410112522892` (bit-for-bit), confirming the `VERTEX_LOOP` bound contributed nothing at all to the face's boundary and the face silently became the WHOLE torus. Distinct from Gs039 (sphere: explicit natural-bound wire is constructed, code path `:566-585`) and Twi281 (plane: explicit warning is logged, code path `:590-593`); this is the third, silent-and-unconditional branch. Fills `stp-vertexloop-bound-mismatch`'s previously-missing "bound on a toroidal surface -> silently discarded" subvariant.
