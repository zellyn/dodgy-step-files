Gs053 — Scaled sphere as B-spline approximation broken on export

§12.2c surfaces

P1 — silent data loss

Sources

  • OCCT MANTIS#0022492 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A sphere scaled non-uniformly by `MAPPED_ITEM` is exported as a `B_SPLINE_SURFACE` because the scaled sphere is no longer a sphere. The exporter writes the B-spline but with a parameter range mismatched to the underlying knot vector — re-import shows a partial / clipped sphere.

Reproducer recipe

Sphere radius 1.0, scaled by `(2.0, 1.0, 1.0)` (becomes an ellipsoid). Exported as `B_SPLINE_SURFACE`; parameter range declared `[0,1]×[0,1]` but knots span `[0,2π]×[0,π]`.

Expected kernel behavior

Heal and accept: B-spline parameter range matches the external knot vector; emit canonical knot ranges (`[0, 2π]` etc.) when approximating analytic surfaces.

Notes

**See also**: Gn014. Synonyms: "scaled sphere as B-spline approximation broken on export", "MAPPED_ITEM scale produces ellipsoid as BSpline", "B-spline parameter range mismatched with knot vector", "sphere scaled non-uniformly becomes partial sphere on re-import", "RECTANGULAR_TRIMMED_SURFACE parameter range wrong".
