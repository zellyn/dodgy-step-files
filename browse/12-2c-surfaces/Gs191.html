Gs191 — Slicer chord-deflection defect on small-radius `B_SPLINE_SURFACE_WITH_KNOTS`

§12.2c surfaces (sub-class: tessellation-parameter mis-scaling / small-radius faceting)

P1 — silent data loss

geometry

Sources

  • BambuStudio GitHub issue #3437 (`STEP translation poor quality, 44% fewer triangles`). B4 wave-7 DEF-HH (LGPL-clean — pattern only, no upstream bytes copied). Slicers built on top of OCCT's `BRepMesh` with a hard-coded `LinearDeflection = 0.1 mm` produce visibly faceted meshes on small-radius (R < 2 mm) B-spline surfaces, while readers with configurable chord deflection (0.01 mm) mesh the same surface smoothly.

Description

STEP file with a `SHELL_BASED_SURFACE_MODEL` containing two `ADVANCED_FACE` entities, each on a `B_SPLINE_SURFACE_WITH_KNOTS`. Face A approximates a cylindrical arc of radius R = 50 mm (large radius) subtending 60°; face B approximates a cylindrical arc of radius R = 1.5 mm (small radius) subtending 60°. Both B-spline surfaces are degree 2×1 with a 3×2 control-point net whose middle U-control point is placed at R/cos(30°) so the surface passes through the true cylindrical arc endpoints. The two surfaces are placed side-by-side in X (offset 200 mm) so a reader tessellating both at the same chord deflection produces qualitatively different mesh quality: OCCT with `LinearDeflection = 0.01 mm` yields ≈120 triangles per face (both smooth); a slicer with hard-coded `LinearDeflection = 0.1 mm` yields ≈120 triangles on the R=50 face but only ≈8 triangles on the R=1.5 face (visible faceting). OCCT loads shape(1) with 2 faces at either deflection.

Reproducer recipe

`SHELL_BASED_SURFACE_MODEL` containing `OPEN_SHELL` with two `ADVANCED_FACE` entities; each face_geometry is a `B_SPLINE_SURFACE_WITH_KNOTS(deg_u=2, deg_v=1, ctrl=3×2, knot_mults=(3,3)×(2,2), knots=(0,1)×(0,1))` approximating a 60° cylindrical arc — one at R=50 mm, one at R=1.5 mm.

Expected kernel behavior

derive tessellation `LinearDeflection` from the surface's local curvature (Chord × Radius scaling); emit `W_TESSELLATION_UNDER_SIZED_FOR_CURVATURE` diagnostic when a fixed deflection exceeds the target quality on small-radius faces; never silently produce a visibly-faceted small-radius mesh when the source B-spline is smooth.

Notes

Synonyms: "BambuStudio STEP small-radius facet", "slicer chord deflection hardcoded STEP", "B_SPLINE_SURFACE_WITH_KNOTS small radius facet slicer", "LinearDeflection fixed 0.1 mm slicer STEP", "OCCT BRepMesh small radius facet slicer".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(18) ifc=schema_n/a

  • count_entity_def(b'B_SPLINE_SURFACE_WITH_KNOTS') == 2
  • count_entity_def(b'ADVANCED_FACE') == 2

Tier-3 assertions

  • n_faces_total == 2
