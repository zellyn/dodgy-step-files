Gs057 — `RECTANGULAR_COMPOSITE_SURFACE` LoadONBrep stub (BRL-CAD step-g)

§12.2c (sub-class: composite quilt unimplemented)

P1 — silent data loss

geometry

View raw fixture (.stp) step-examples/12-2c-surfaces/Gs057.stp

Sources

  • BRL-CAD `src/conv/step/step-g/RectangularCompositeSurface.cpp` `Load` parses the segments grid into SurfacePatch objects, but `LoadONBrep` is a stub printing `"::LoadONBrep(..) not implemented for <entity>"`
  • bug-reporter language: "RECTANGULAR_COMPOSITE_SURFACE drops face on import", "step-g composite quilt unsupported", "patchwork quilt silently lost".

Sender

Producers that emit a quilt of analytically-defined patches (typical of CATIA's "Surface" workbench output and of legacy AP203 files from CAD systems whose internal representation is patch-based rather than NURBS-based).

Description

`RECTANGULAR_COMPOSITE_SURFACE` describes a piecewise-Bezier or piecewise-NURBS quilt with explicit per-patch transition codes. step-g's `Load` parses the segments grid (a `LIST_OF_LIST_OF_PATCHES`) into in-memory SurfacePatch objects, so the entity is recognised — but `LoadONBrep` is a stub that prints `"not implemented"` and returns false. Faces referencing the quilt are dropped without further diagnostic. Algebraically the entity could be promoted to a single `B_SPLINE_SURFACE_WITH_KNOTS` at multiplicity-(degree+1) internal knots, so the drop is doubly avoidable. Distinct from Gs041 (non-uniform patch grid — structural defect) and Tfa036 (face-on-quilt boundary crossing seams): this is the wholesale unimplemented dispatch.

Reproducer recipe

`#300=RECTANGULAR_COMPOSITE_SURFACE('quilt',((#101,#201)));` where `#101` and `#201` are SURFACE_PATCH wrappers around BEZIER patches. step-g LoadONBrep stub drops the face that references `#300`.

Expected kernel behavior

heal-and-accept — promote the patch grid to a single `B_SPLINE_SURFACE_WITH_KNOTS` (multiplicity = degree+1 at the internal patch boundaries) and feed the result to the existing BSpline importer; emit `W_RECTANGULAR_COMPOSITE_PROMOTED` so users know the conversion happened.
