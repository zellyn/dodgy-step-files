Reproducer recipe

Expected kernel behavior

Accept: a unit-radius CYLINDRICAL_SURFACE whose face boundary includes a short edge (about 5e-4mm) that is nonetheless within the file's own declared uncertainty/tolerance value. A kernel must compare edge length against the tolerance value the file itself declares (or a consistent model-scale-relative tolerance), not an independent hard-coded threshold -- an edge that is short but within the file's own stated tolerance is legitimate small-but-real geometry, not a degenerate edge to collapse.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(11) ifc=schema_n/a

Tier-3 assertions

  • load == "ok"
  • face[0].surface_type == "cylinder"
  • face[0].quadric.radius == 1.0
