Pmi145 — AP242 Ed.3 `BASIC_ROUND_HOLE` feature entity dropped by Ed.2/AP214 readers

§12.7 PMI/GD&T (sub-class: edition-boundary feature-semantic elision / drilled hole)

P1 — silent data loss

silent-loss pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi145.stp

Sources

  • steptools.com AP242 Ed.3 notes (`BASIC_ROUND_HOLE` + `BASIC_ROUND_HOLE_OCCURRENCE` §4.4 — Ed.3 machining-feature entities)
  • FreeCAD issue #19795 (AP242 Ed.1-4 feature-semantic gap). B4 wave-7 DEF-JJ (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit machining-feature entities for drilled round holes
  • earlier editions do not carry these entities and their readers produce Void transfer status while the hole B-rep geometry still loads.

Sender

AP242 Edition 3 STEP files from feature-aware CAD tools that emit both the B-rep geometry AND the machining-feature semantic; file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID).

Description

STEP AP242 Ed.3 file containing a prismatic 20×20×10 mm `MANIFOLD_SOLID_BREP` block (the carrier part) plus a co-present B-rep representation of a drilled through-hole encoded in TWO parallel ways. (a) Hole B-rep geometry: a `CYLINDRICAL_SURFACE` `ADVANCED_FACE` for the hole wall (radius=3.0, centered at (W/2, W/2), extruded z: 0→10) and two `PLANE` cap `ADVANCED_FACE` entities marking the ±Z ends of the drilled hole. (b) Feature semantic: `BASIC_ROUND_HOLE('brh_1','through_hole',#shape_aspect,POSITIVE_LENGTH_MEASURE(6.0))` with `internal_diameter = 6.0` mm (= wall radius × 2), plus `BASIC_ROUND_HOLE_OCCURRENCE` linking the feature entity to the B-rep hole face. Ed.3 readers expose the hole as `type=through, diameter=6.0` via the machining-feature API; Ed.2 / AP214 readers produce Void transfer status on both feature entities but the hole B-rep geometry (cylinder + caps) loads correctly, so downstream CAM must re-classify the geometry from scratch.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); prismatic `MANIFOLD_SOLID_BREP` block + hole B-rep (`CYLINDRICAL_SURFACE` wall + two `PLANE` cap faces); `BASIC_ROUND_HOLE('brh_1','through_hole',#sa,POSITIVE_LENGTH_MEASURE(6.0))` + `BASIC_ROUND_HOLE_OCCURRENCE('brh_occ_1',...,#sa,#brh,#wall_face)`.

Expected kernel behavior

AP242 Ed.3 readers must traverse `BASIC_ROUND_HOLE` / `BASIC_ROUND_HOLE_OCCURRENCE` and expose the drilled-hole parameters via the machining-feature API; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(BASIC_ROUND_HOLE)` rather than silently dropping the feature semantic.

Notes

steptools notes_ap242e3.html §4.4. FreeCAD #19795. B4 wave-7 DEF-JJ. Entity defined in AP242 Ed.3 §4.4 only. Synonyms: "BASIC_ROUND_HOLE AP242 Ed.3 dropped", "AP242 Ed.3 drilled hole feature entity", "hole feature semantic silent drop Ed.2", "internal_diameter 6.0 STEP AP242 Ed.3", "BASIC_ROUND_HOLE_OCCURRENCE feature-semantic gap".
