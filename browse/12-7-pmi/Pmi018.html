Pmi018 — Identical Graphic PMI duplicated across saved views

§12.7 (sub-class: saved-view)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi018.stp

Sources

  • 06-nist-sfa (S063)

Description

Two `draughting_model`s for different saved views contain exactly the same set of annotation occurrences, indicating either a copy-paste bug or an export that did not differentiate views.

Reproducer recipe

Two saved views written with identical annotation_occurrence lists.

Expected kernel behavior

Informational warning; accept.

Notes

Synonyms: "same Graphic PMI duplicated across saved views", "graphic PMI repeated when shared between views", "redundant copies of one annotation per view".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

  • count_entity_def(b'POLYLINE') == 2
