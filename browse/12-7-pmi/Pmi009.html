Pmi009 — Rounding mode unspecified (ASME banker's vs ISO half-up)

§12.7 (sub-class: precision_qualifier)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi009.stp

Sources

  • 02-caxif (PMI v4.1 §4.1.1)

Description

For 0.5625 displayed at 3 decimals, ASME rounds to 0.562 (banker's) and ISO rounds to 0.563 (half-up). Source and target may both be "correct" yet show different displayed values. STEP carries no flag indicating which rule was applied.

Reproducer recipe

Dimension nominal 0.5625 inch, default precision 3 decimals.

Expected kernel behavior

Heal and accept: accept either rounded form without flagging a roundtrip error; coerce the rounding-rule via UDA when the producer knows.

Notes

Synonyms: "rounding mode ambiguous (banker's vs half-up)", "ASME vs ISO rounding mismatch", "tolerance rounded differently between systems", "rounding rule unspecified causes value drift".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a
