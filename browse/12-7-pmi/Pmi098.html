Pmi098 — `SLOT` axis not perpendicular to host face

§12.7 (sub-class: AP242 feature definition)

P1 — silent data loss

spec-violation pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi098.stp

Sources

  • 16-iso-spec ISO 10303-242 §feature_definition_schema (slot placement)
  • CAx-IF Feature Information Recommended Practice §slot orientation
  • bug-reporter language: "SLOT axis parallel to face", "AP242 slot orientation wrong", "slot placement does not engrave host".

Description

AP242 `slot` carries an `AXIS2_PLACEMENT_3D` whose Z direction is the slot's cutting axis. For a planar host face, the slot's cutting axis must be parallel to the host face normal (i.e., perpendicular to the face). When the slot's axis is parallel to the host face (Z direction in-plane), the slot would not actually engrave the host. A producer that emits a slot with Z=(1,0,0) on a host face whose normal is (0,0,1) leaves a feature that cannot be physically realised. Receivers diverge: some silently re-orient, some accept and produce a malformed solid, some reject. Bug-reporter language: "SLOT axis parallel to host face", "slot would not cut the part", "AP242 slot orientation defect".

Reproducer recipe

a planar host face with normal (0,0,1); a `SHAPE_ASPECT('SLOT',..)` whose linked `AXIS2_PLACEMENT_3D` has Z direction (1,0,0) — parallel to the face.

Expected kernel behavior

validate slot axis vs host face normal; reject as inconsistent or auto-correct with a deterministic warning. Never accept silently.

Notes

**See also**: Pmi091, Pmi095, Pmi105. Synonyms: "SLOT axis parallel to host face", "slot placement orientation wrong", "AP242 slot Z direction mis-aligned".
