  • item-level companions to Pmi146's model-level `TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION` pair). B4 wave-8 DEF-YY (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit bidirectional linking between a shape's topological items (individual edges/faces) and their geometric-item counterparts, at the ITEM level rather than the model-root level
  • earlier editions (Ed.2, Ed.1, AP214) do not carry these entities in their schemas and their readers produce Void transfer status.

Sender

AP242 Edition 3 STEP files from tools that emit item-level topology↔geometry linking (typical for PMI-aware CAD tools that need precise per-item associations for tolerance targeting); file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID).

Description

STEP AP242 Ed.3 file containing a minimal single-face planar 10×10 mm patch (`SHELL_BASED_SURFACE_MODEL` with one `OPEN_SHELL` containing one `ADVANCED_FACE` on a `PLANE`) plus a co-present explicit `EDGE_CURVE('pmi154_bottom_edge',...)` on a straight `LINE` (the bottom edge of the face, from (0,0,0) to (10,0,0)). A PMI `ANNOTATION_OCCURRENCE` (`FLATNESS 0.02`) references the face via a `SHAPE_ASPECT` anchor. The two Ed.3 item-level association entities: `TOPOLOGY_TO_GEOMETRY_ITEM_ASSOCIATION('t2g_item',...,#edge_curve,#face)` links a specific topological item (the `EDGE_CURVE`) to its geometric-item counterpart (the `ADVANCED_FACE` it lies on); `GEOMETRY_TO_TOPOLOGY_ITEM_ASSOCIATION('g2t_item',...,#face,#edge_curve)` is the inverse. Ed.3 readers use the pair to validate item-level consistency; Ed.2 / AP214 readers produce Void transfer status on both entities and silently drop the explicit item-level topology↔geometry link — the face + edge + annotation still load but the bidirectional item-level association is absent. Distinct from `Pmi147`'s `GEOMETRY_BASED_ITEM_WITHIN_REPRESENTATION` (a locator entity); this is a bidirectional item-level link.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); single planar `ADVANCED_FACE` + `EDGE_CURVE`; `SHAPE_ASPECT` + `ANNOTATION_OCCURRENCE`; `TOPOLOGY_TO_GEOMETRY_ITEM_ASSOCIATION('t2g_item',...,#edge,#face)` + `GEOMETRY_TO_TOPOLOGY_ITEM_ASSOCIATION('g2t_item',...,#face,#edge)`.

Expected kernel behavior

AP242 Ed.3 readers must resolve `TOPOLOGY_TO_GEOMETRY_ITEM_ASSOCIATION` and `GEOMETRY_TO_TOPOLOGY_ITEM_ASSOCIATION` and expose the bidirectional item-level link; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(TOPOLOGY_TO_GEOMETRY_ITEM_ASSOCIATION)` rather than silently discarding the associations.
