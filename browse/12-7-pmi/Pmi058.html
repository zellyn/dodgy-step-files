Pmi058 — PMI visibility / configuration loss across saved views

§12.7 (sub-class: saved-view)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi058.stp

Sources

  • 11-translator-vendors (W027 SDHE-21917, SDHE-21787)

Description

PMI annotations defined in one configuration become invisible (or universally visible) when exported, because the configuration-association is dropped.

Reproducer recipe

STEP file with `draughting_pre_defined_colour` and `annotation_plane` linked to a representation referenced from one of two `configuration_item`s.

Expected kernel behavior

Heal and accept: preserve configuration scope across round-trip; if unsupported, warn and accept rather than silently universalize visibility.

Notes

**See also**: A002. Synonyms: "PMI visibility lost across saved views", "saved-view PMI configuration missing", "annotation visibility per-view not preserved".
