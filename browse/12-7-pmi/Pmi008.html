Pmi008 — Tolerance precision: missing decimal-place qualifier fallback chain

§12.7 (sub-class: precision_qualifier)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi008.stp

Sources

  • 02-caxif (PMI v4.1 §4.1)

Description

Some CAD systems ignore tolerance values that lack an explicit decimal-place qualifier even when a default precision is set globally. The fallback hierarchy is: precision at tolerance value → precision at nominal value → global default.

Reproducer recipe

Dimension nominal `5.0`, tolerance `+0.01/-0.01`, no `precision_qualifier` on either value, no global default.

Expected kernel behavior

Fall through the precision hierarchy correctly; emit warning if the global default is also missing.

Notes

**See also**: N035. Synonyms: "tolerance value precision missing decimal-place qualifier", "no precision qualifier on tolerance", "rounding precision unset for dimension", "tolerance display digits unspecified".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'TOLERANCE_VALUE')
  • count_entity_def(b'PRECISION_QUALIFIER') == 0
