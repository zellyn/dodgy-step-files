Pmi120 — `PROFILE_FEATURE` with self-intersecting profile (figure-eight loop)

§12.7 (sub-class: AP242 feature definition / profile)

P1 — silent data loss

spec-violation pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi120.stp

Sources

  • 16-iso-spec AP242 §profile_feature
  • CAx-IF Feature-Information Recommended Practices §profile topology

Description

AP242 profile_feature requires a simple (non-self-intersecting) closed loop. A profile that crosses itself — a figure-eight — has multi-valued bounded regions: the interior orientation flips at the crossing. Sweeping a figure-eight produces a self-intersecting solid whose volume calculation is ill-defined (orientation-dependent, kernel-specific). A producer that emits four diagonal segments forming an X-crossing leaves a non-simple profile. Receivers either reject (non-simple curve), split into two simple loops at the crossing (silent topological change), or accept and produce a kernel-specific solid. Bug-reporter language: "PROFILE_FEATURE self-intersect", "AP242 profile figure-eight", "profile loop crosses itself".

Reproducer recipe

A `SHAPE_ASPECT('profile_feature')` whose four `EDGE_CURVE` segments form a figure-eight: vertices at (5,5), (15,15), (5,15), (15,5) connected p0→p1→p2→p3→p0; the diagonals p0p1 and p2p3 cross at (10,10).

Expected kernel behavior

reject (`E_PROFILE_SELF_INTERSECT`); never silently split.

Notes

Sister to Pmi119 (open profile); Pmi120 is closed-but-non-simple. **See also**: Pmi119, Pmi121, Pmi122, Pmi123. Synonyms: "PROFILE_FEATURE figure-eight", "AP242 profile self-intersects", "profile loop crosses itself", "non-simple profile boundary".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Tier-3 assertions

  • n_faces_total == 1
  • face[0].surface_type == "plane"
  • face[0].edge_count == 4
  • face[0].area > 2499
  • face[0].area < 2501
