Pmi144 — AP242 Ed.3 `ANNOTATION_TO_ANNOTATION_LEADER_LINE` entity dropped by Ed.2/AP214 readers

§12.7 PMI/GD&T (sub-class: edition-boundary entity elision / annotation link)

P1 — silent data loss

silent-loss pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi144.stp

Sources

  • steptools.com AP242 Ed.3 notes (`ANNOTATION_TO_ANNOTATION_LEADER_LINE` §4.4 — one of 21 new Ed.3 entities). B4 wave-7 DEF-II (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit leader-line linking between two annotation callouts
  • earlier editions (Ed.2, Ed.1, AP214) do not carry this entity in their schema and their readers produce Void transfer status.

Sender

AP242 Edition 3 STEP files from tools that emit the new Ed.3 leader-line linking entity; file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID with hybrid AUTOMOTIVE_DESIGN name — as observed in Ed.2 writers upgraded to the Ed.3 OID).

Description

STEP AP242 Ed.3 file containing a minimal cube `MANIFOLD_SOLID_BREP` (6-face 10×10×10 mm) and two PMI callouts: a position tolerance frame `ANNOTATION_OCCURRENCE('pos_tol_frame',$,#dri_a)` (with `DESCRIPTIVE_REPRESENTATION_ITEM('position_tol','POS 0.05 A B C')`) anchored to the top face's `SHAPE_ASPECT`, and a datum feature label `ANNOTATION_OCCURRENCE('datum_label',$,#dri_b)` (with `DESCRIPTIVE_REPRESENTATION_ITEM('datum_feature','DATUM A')`) anchored to the +X face. The two annotations are linked by `ANNOTATION_TO_ANNOTATION_LEADER_LINE('pos_tol_to_datum_leader',#annot_a,#annot_b,$)` — the Ed.3 entity that carries source→target leader-line semantics. Ed.3 readers resolve the leader link and expose both callouts as connected; Ed.2 / AP214 readers produce Void transfer status on the linking entity and silently drop the leader connection; both individual annotations still load.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); cube `MANIFOLD_SOLID_BREP`; two `ANNOTATION_OCCURRENCE` entities linked by `ANNOTATION_TO_ANNOTATION_LEADER_LINE('...',#annot_a,#annot_b,$)`.

Expected kernel behavior

AP242 Ed.3 readers must resolve `ANNOTATION_TO_ANNOTATION_LEADER_LINE` and populate the annotation-link API; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(ANNOTATION_TO_ANNOTATION_LEADER_LINE)` rather than silently discarding the leader-line link.

Notes

steptools notes_ap242e3.html (21 new Ed.3 entities). B4 wave-7 DEF-II. Edition boundary: Ed.3 entity absent from Ed.2, Ed.1, AP214 schemas.
