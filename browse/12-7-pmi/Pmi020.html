Pmi020 — Saved view missing required mapped_item

§12.7 (sub-class: saved-view)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi020.stp

Sources

  • 06-nist-sfa (S028)

Description

For Saved Views, the `draughting_model.items` list must include a `mapped_item` linking to the underlying draughting model. Files lacking it are interpreted as "all PMI visible" by the SFA validator.

Reproducer recipe

`draughting_model` for a saved view containing only annotation_occurrences, no `mapped_item`.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; coerce all PMI to visible.

Notes

Synonyms: "saved view missing required mapped_item", "mapped_item absent from saved view", "saved-view structure incomplete (no mapping)".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'DRAUGHTING_MODEL') == 2
  • contains(b'ANNOTATION_CURVE_OCCURRENCE')
  • count_entity_def(b'MAPPED_ITEM') == 0
