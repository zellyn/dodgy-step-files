Pmi069 — `DIMENSIONAL_LOCATION_WITH_PATH` whose path connects unrelated shape aspects

§12.7 (sub-class: dimensional location)

P1 — silent data loss

spec-violation pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi069.stp

Sources

  • 16-iso-spec AP242 §DIMENSIONAL_LOCATION_WITH_PATH

Description

AP242 DIMENSIONAL_LOCATION_WITH_PATH carries an extra 'path' attribute (a SHAPE_ASPECT_RELATIONSHIP chain) describing the route through the model along which a dimension is to be measured. The spec assumes the path is a connected sequence of shape_aspects. A producer that emits a path whose endpoints are unrelated shape_aspects on disconnected components leaves the dimension's interpretation ambiguous.

Reproducer recipe

two SHAPE_ASPECTs `'feature_on_A'` and `'feature_on_B'` on disjoint topology; SHAPE_ASPECT_RELATIONSHIP between them named `'no path'`; DIMENSIONAL_LOCATION_WITH_PATH referencing both.

Expected kernel behavior

validate that the SHAPE_ASPECT_RELATIONSHIP path is a connected chain through the model topology; reject or warn when the path is disconnected.

Notes

First entry exercising DIMENSIONAL_LOCATION_WITH_PATH. Synonyms: "DIMENSIONAL_LOCATION_WITH_PATH connects unrelated shape aspects", "tolerance path links unrelated features", "dimensional path crosses unrelated entities".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'DIMENSIONAL_LOCATION_WITH_PATH')
  • contains(b'SHAPE_ASPECT_RELATIONSHIP')
  • count_entity_def(b'SHAPE_ASPECT') == 2

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
