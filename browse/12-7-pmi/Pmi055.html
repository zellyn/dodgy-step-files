Pmi055 — AP242 hole feature missing required attribute / inconsistent dims

§12.7 (sub-class: hole-feature)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi055.stp

Sources

  • 06-nist-sfa (S054)

Description

`round_hole` / `counterbore` / `countersink` is missing `depth` / `diameter` / `tip_angle`, OR counterbore/countersink diameter ≤ drill diameter, OR counterbore depth ≥ drill depth.

Reproducer recipe

`counterbore` with counterbore_diameter < drill_diameter.

Expected kernel behavior

Reject or warn.

Notes

**See also**: Pmi013, Pmi041. Synonyms: "AP242 hole feature missing required attribute", "hole feature has inconsistent dimensions", "hole entity attribute missing or wrong".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'DIMENSIONAL_SIZE') == 4
  • count_entity_def(b'SHAPE_ASPECT') == 3
  • contains(b'PLUS_MINUS_TOLERANCE')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1

Cross-references
