Pmi123 — `PROFILE_FEATURE` used for sweep with no path

§12.7 (sub-class: AP242 feature definition / profile)

P1 — silent data loss

round-trip spec-violation pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi123.stp

Sources

  • 16-iso-spec AP242 §profile_feature, §swept_face_solid
  • CAx-IF Feature-Information Recommended Practices §sweep

Description

AP242 profile_feature can be classified by sweep operation: extrude (depth + direction), revolve (axis + angle), or sweep-along-path (path curve). A profile_feature classified as "sweep" without a `sweep_path` attribute leaves a feature definition that cannot resolve to a swept surface; the path along which to sweep is missing. Producers sometimes emit this when a path curve is present in the source CAD but is dropped on export (writer coverage gap). Receivers either degrade to a zero-thickness profile (silent), reject (missing required attribute), or accept and produce empty geometry. Bug-reporter language: "PROFILE_FEATURE sweep no path", "AP242 swept feature missing path", "sweep classified but no path curve".

Reproducer recipe

A `SHAPE_ASPECT('profile_feature')` with descriptive property `feature_op = 'sweep'` but no SHAPE_ASPECT or geometric record naming the sweep path.

Expected kernel behavior

reject (`E_SWEEP_MISSING_PATH`); or downgrade to extrude with default direction and emit `W_SWEEP_PATH_MISSING`.

Notes

Sister to Pmi055 (missing required attribute) but specific to sweep operations. **See also**: Pmi055, Pmi119, Pmi120, Pmi121, Pmi122. Synonyms: "PROFILE_FEATURE sweep without path", "AP242 swept feature missing path curve", "sweep classified but no path provided", "profile feature sweep operation incomplete".
