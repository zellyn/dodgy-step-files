Pmi076 — Composite-property layer stack with contradictory material attributes

§12.7 (sub-class: composite property)

silent-loss pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi076.stp

Sources

  • 16-iso-spec AP242 ED4 §COMPOSITE_PROPERTY family

Description

AP242 ED4 introduces composite-property entities to describe layered or fibre-reinforced materials, with one property record per layer. A producer that re-uses a layer-stack template across products without updating layer-specific material references emits a stack where two adjacent layers claim the same fibre angle but reference different material grades; downstream FEA pre-processors silently take the first match.

Reproducer recipe

two PROPERTY_DEFINITIONs `'layer1','0deg orientation, T300'` and `'layer2','0deg orientation, M55J'` linked by PROPERTY_DEFINITION_RELATIONSHIP claiming a single stack.

Expected kernel behavior

surface contradictory layer-property combinations; do not silently accept the first material as authoritative.

Notes

First entry exercising AP242 ED4 composite-property semantics. **OCC behavior**: silently accepts the contradictory composite layer stack with no diagnostic; kernel mishandling — the catalog above forbids silent first-wins acceptance. Synonyms: "composite-property layer stack with contradictory materials", "layered material attributes conflict", "composite layer materials inconsistent".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'PROPERTY_DEFINITION') == 2
  • contains(b'PROPERTY_DEFINITION_RELATIONSHIP')
