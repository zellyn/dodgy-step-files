Description

Older AP242 / AP203+G&DT files attach the toleranced item indirectly through a `property_definition` chain rather than the modern direct association.

Reproducer recipe

AP203+GDT file where `dimensional_size` / `geometric_tolerance` is reachable from a face only via `property_definition_representation`.

Expected kernel behavior

Heal and accept: coerce the translation via the indirect path; do not require the modern direct linkage.

Notes

Synonyms: "DimensionalSize attached only via PropertyDefinition", "legacy AP203 G&DT tolerance attachment pattern", "old PropertyDefinition link instead of direct association".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Tier-3 assertions

  • face[0].sliver_aspect_max_min > 1e6
  • face[0].surface_type == "plane"
  • brepcheck.valid == True
