Pmi061 — DATUM→ADVANCED_FACE chain not resolved for some link patterns

§12.7 (sub-class: datum-frame / datum-targets)

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi061.stp

Sources

  • 18-other-issues (I014 OCCT #1138)

Sender

NIST PMI test cases (ctc_01.stc_10)

Description

Four chain patterns are unresolved by `XCAFDoc_DimTolTool::GetRefShapeLabel`: (1) DATUM-SAR-DATUM_FEATURE-IIRU/SRI-AF, (2) DATUM-SAR-PLACED_DATUM_TARGET_FEATURE-PD-GISU-EC, (3) chain via SHAPE_ASPECT, (4) chain via COMPOSITE_GROUP_SHAPE_ASPECT.

Reproducer recipe

Any NIST CTC/STC `.stp` file that exercises one of the four chains; query `gdtTool->GetRefShapeLabel(datumLabel,..)`.

Expected kernel behavior

Heal and accept: all four chain patterns should resolve via normalization; only one currently does.

Notes

Synonyms: "DATUM to ADVANCED_FACE chain not resolved", "datum target not linkable to face", "tolerance can't find its datum", "DATUM-SAR-DATUM_FEATURE chain broken".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Tier-3 assertions

  • face[0].sliver_aspect_max_min > 1e6
  • face[0].surface_type == "plane"
  • brepcheck.valid == True
