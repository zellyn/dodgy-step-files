Pmi015 — Annotation geometry must be in plane PARALLEL to annotation_plane (small offset)

§12.7 (sub-class: annotation-plane)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi015.stp

Sources

  • 02-caxif (PMI v4.1 §9.1)

Description

CAD systems offset annotation geometry slightly above the underlying `annotation_plane`. RP says elements must lie in a plane *parallel* to the `annotation_plane`, not necessarily on it. Strict-on-plane checks reject valid files.

Reproducer recipe

`annotation_plane` at z=0; polyline points all at z=0.05.

Expected kernel behavior

Heal and accept: coerce any plane parallel to the annotation_plane within `representation_context` tolerance; do not require strict on-plane coincidence.

Notes

**See also**: Pmi047. Synonyms: "annotation geometry slightly offset from annotation_plane", "PMI text not exactly in declared plane", "small-offset PMI parallelism violation".- **Byte assertion**: contains(b'ANNOTATION_CURVE_OCCURRENCE')

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'ANNOTATION_PLANE')
  • contains(b'POLYLINE')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
