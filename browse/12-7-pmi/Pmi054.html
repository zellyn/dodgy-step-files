Pmi054 — basis_curve for leader/annotation not on allowed list

§12.7 (sub-class: semantic-vs-graphic)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi054.stp

Sources

  • 06-nist-sfa (S066)

Description

Annotation `polyline` / `trimmed_curve` references a basis curve not on the allowed list (lines, circles, polylines).

Reproducer recipe

Annotation polyline whose basis curve is a `b_spline_curve_with_knots`.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; coerce to a best-effort render. Must not crash on the rendering path.

Notes

Synonyms: "basis_curve for leader not on allowed list", "PMI leader uses unsupported basis curve type", "leader basis curve type rejected".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'B_SPLINE_CURVE_WITH_KNOTS')
  • contains(b'ANNOTATION_CURVE_OCCURRENCE')
  • contains(b'PRESENTATION_STYLE_ASSIGNMENT')
