Pmi048 — Graphic PMI annotation missing color

§12.7 (sub-class: semantic-vs-graphic)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi048.stp

Sources

  • 06-nist-sfa (S026)

Description

An `annotation_*_occurrence` carries no `presentation_style_assignment` color, so receivers must default.

Reproducer recipe

`annotation_curve_occurrence` with no `styled_item` chain.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; coerce to a documented default colour (e.g., black).

Notes

Synonyms: "graphic PMI annotation missing color", "annotation has no color assigned", "graphic PMI no styled_item color binding".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'ANNOTATION_CURVE_OCCURRENCE')
  • count_entity_def(b'COLOUR_RGB') == 0
  • count_entity_def(b'STYLED_ITEM') == 0
