Pmi085 — Dimension names dropped on round-trip

§12.7 PMI/GD&T

P1 — silent data loss

round-trip pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi085.stp

Sources

  • OCCT MANTIS#0029525 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A PMI dimension's `name` attribute (an identifier used by downstream design-of-experiments tools) is read but never written back on export. Round-trip files have anonymous dimensions.

Reproducer recipe

PMI dimension with `name = "OD_critical"`. Read, export. Output dimension has empty name.

Expected kernel behavior

Heal and accept: every named entity round-trips via the schema's name attribute; dimensions are no exception.

Notes

**See also**: A076. Synonyms: "dimension names dropped on round-trip", "tolerance label disappears", "dimension name not preserved".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'DIMENSIONAL_LOCATION')
  • count_entity_def(b'SHAPE_ASPECT') == 2
