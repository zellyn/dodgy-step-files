Pmi056 — Tessellated alongside curve annotations for the same callout (AP242 ed2 conflict)

§12.7 (sub-class: semantic-vs-graphic)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi056.stp

Sources

  • 06-nist-sfa (S068)

Description

A `draughting_model` mixes `tessellated_annotation_occurrence` and curve-style `annotation_*_occurrence` for the same callout. Even within one PMI item this duplication breaks counting and association.

Reproducer recipe

One `draughting_callout` referencing both tessellated and polyline forms of the same FCF.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; normalize one form as canonical.

Notes

Synonyms: "tessellated and curve annotations both for same callout", "AP242 ed2 conflict: two annotation styles for one PMI", "duplicate annotation styles for one tolerance".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'TESSELLATED_ANNOTATION_OCCURRENCE')
  • contains(b'ANNOTATION_CURVE_OCCURRENCE')
  • contains(b'COMPLEX_TRIANGULATED_SURFACE_SET')
