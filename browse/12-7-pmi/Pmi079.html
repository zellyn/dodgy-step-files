Pmi079 — Dimension lost after STEP export round-trip

§12.7 PMI/GD&T

round-trip pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi079.stp

Sources

  • OCCT MANTIS#0032681
  • OCCT MANTIS#0027313 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A dimension PMI is created in the source CAD tool, imported correctly, but lost on a subsequent export; the writer's GD&T emitter does not iterate the document's full attribute tree.

Reproducer recipe

Document with two PMI dimensions; only one attached to a face directly, the other attached via `SHAPE_ASPECT`. Write STEP. Output has only the face-attached dimension.

Expected kernel behavior

Heal and accept: writer emits every PMI attached anywhere in the assembly tree, regardless of attachment style.

Notes

**See also**: A077, Pmi076. Synonyms: "dimension lost after STEP export round-trip", "tolerance gone after round-trip", "dimension entity dropped on re-export".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Tier-3 assertions

  • face[0].surface_type == "plane"
  • face[1].surface_type == "plane"
