Pmi099 — Three coaxial `SLOT` features instead of a `RECTANGULAR_PATTERN`

§12.7 (sub-class: AP242 feature definition)

round-trip pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi099.stp

Sources

  • 16-iso-spec ISO 10303-242 §feature_definition_schema (slot, rectangular_pattern)
  • CAx-IF Feature Information Recommended Practice §pattern
  • bug-reporter language: "three identical slots, no pattern emitted", "AP242 lost pattern relationship", "feature pattern decomposed to instances".

Description

AP242 supports parametric patterns (`rectangular_pattern`, `circular_pattern`) that capture the relationship between a primary feature and its copies. The canonical form for three identical SLOTs sharing a direction with even spacing is one SLOT plus a 3-instance RECTANGULAR_PATTERN. A producer that decomposes the pattern at export and emits three independent SLOT features — same orientation, same dimensions, evenly spaced — loses the parametric relationship. Receivers cannot reconstruct downstream pattern PMI from this form: each SLOT is treated as an independent feature, and modifying the pattern (changing instance count, spacing) becomes impossible. Bug-reporter language: "AP242 pattern lost on export", "three identical slots emitted as instances", "pattern decomposition at export".

Reproducer recipe

three `SHAPE_ASPECT('SLOT',..)` records sharing the same dimensions (length=15, width=5, depth=2), evenly spaced 25 mm apart along X, no `RECTANGULAR_PATTERN` linking them.

Expected kernel behavior

Warn and accept: writer should detect identical co-axial features and heal by emitting one feature plus a pattern record; reader should emit a warning `W_FEATURE_PATTERN_LOST` when it observes the decomposed form. Accepting the decomposed form without surfacing the lost pattern relationship is a coverage gap.

Notes

**See also**: Pmi093, Pmi095. Synonyms: "coaxial SLOTs not patterned", "AP242 pattern decomposed to instances", "three slots no pattern", "feature pattern relationship lost".
