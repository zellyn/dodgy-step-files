Pmi046 — characterized_object with non-PMI draughting subtypes for graphic PMI

§12.7 (sub-class: semantic-vs-graphic)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi046.stp

Sources

  • 06-nist-sfa (S029)

Description

Producer used `(characterized_object)(draughting_callout)` or `draughting_annotation_*_occurrence` instead of the AP242 RP-prescribed `annotation_curve_occurrence`.

Reproducer recipe

Annotation written as complex `(characterized_object)(draughting_callout)`.

Expected kernel behavior

Read; warn for non-conformance; do not reject.

Notes

Synonyms: "characterized_object with non-PMI draughting subtype", "draughting subtype invalid for graphic PMI", "wrong characterized_object subtype on annotation".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'DRAUGHTING_ANNOTATION_OCCURRENCE')
  • contains(b'PRESENTATION_STYLE_ASSIGNMENT')
  • contains(b'COLOUR_RGB')

  • shape_null == False
  • n_vertices_total == 1
