Pmi067 — `'INCH'` named differently on conversion_based_unit

§12.7 (sub-class: semantic-vs-graphic)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi067.stp

Sources

  • 06-nist-sfa (S032)

Description

The conventional name for inches in PMI dimensional measurements is `'INCH'`; producers sometimes write `'inch'`, `'IN'`, or `'inches'`, breaking PMI value display.

Reproducer recipe

`conversion_based_unit('inches', length_measure_with_unit(length_measure(25.4), millimetre))`.

Expected kernel behavior

Warn and accept: case-insensitive normalize the match; emit a warning on case-form mismatch.

Notes

**See also**: U022. Synonyms: "INCH spelled differently on conversion_based_unit", "inch unit name not normalized", "various INCH spellings break unit recognition".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONVERSION_BASED_UNIT') or contains(b'INCH')
  • contains(b'DIMENSIONAL_EXPONENTS')
  • contains(b'PLUS_MINUS_TOLERANCE')
