Pmi037 — shape_aspect.product_definitional flag wrong polarity

§12.7 (sub-class: semantic-vs-graphic)

silent-loss pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi037.stp

Sources

  • 06-nist-sfa (S051)

Description

`shape_aspect.product_definitional` flag is `FALSE` where it must be `TRUE` (e.g. for a feature carrying a `dimensional_size`) or vice-versa for datum-target placement.

Reproducer recipe

`shape_aspect` carrying a `dimensional_size` with `product_definitional = .F.`.

Expected kernel behavior

Warn; do not silently rewrite the flag.

Notes

**OCC behavior**: silently accepts the wrong-polarity `product_definitional` flag without warning; kernel mishandling; the catalog above forbids silent rewrite (or silent acceptance). Synonyms: "shape_aspect product_definitional flag wrong polarity", "product_definitional flag inverted", "shape_aspect flag set true when should be false".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'SHAPE_ASPECT')
  • contains(b'DIMENSIONAL_SIZE')
  • contains(b'PLUS_MINUS_TOLERANCE')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
