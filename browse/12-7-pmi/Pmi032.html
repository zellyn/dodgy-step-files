Pmi032 — Datum target dimension equals zero

§12.7 (sub-class: datum-targets)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi032.stp

Sources

  • 06-nist-sfa (S048)

Description

A point/line/circle/rectangular `placed_datum_target_feature` carries `target diameter` / `target length` of 0.

Reproducer recipe

`placed_datum_target_feature` with `target_diameter = LENGTH_MEASURE(0.0)`.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; do not emit a degenerate target.

Notes

Synonyms: "datum target dimension equals zero", "zero-size datum target", "datum target with no extent".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'DATUM')
  • contains(b'MEASURE_REPRESENTATION_ITEM')
