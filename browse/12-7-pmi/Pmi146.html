Pmi146 — AP242 Ed.3 `TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION` bidirectional link dropped by Ed.2/AP214 readers

§12.7 PMI/GD&T (sub-class: edition-boundary entity elision / topology-geometry model link)

P1 — silent data loss

silent-loss pmi

Sources

  • steptools.com AP242 Ed.3 notes (`TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION` / inverse `GEOMETRY_TO_TOPOLOGY_MODEL_ASSOCIATION` §4.4 — two of the 21 new Ed.3 entities). B4 wave-7 DEF-KK (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit bidirectional linking between a shape's topological model root and its geometric model root
  • earlier editions (Ed.2, Ed.1, AP214) do not carry these entities in their schema and their readers produce Void transfer status.

Sender

AP242 Edition 3 STEP files from tools that emit the new Ed.3 topology↔geometry linking entities; file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID with hybrid AUTOMOTIVE_DESIGN name).

Description

STEP AP242 Ed.3 file containing a minimal single-face planar 10×10 mm patch (`SHELL_BASED_SURFACE_MODEL` with one `OPEN_SHELL` containing one `ADVANCED_FACE` on a `PLANE`) plus a PMI `ANNOTATION_OCCURRENCE` (`FLATNESS 0.02`) referencing the face via a `SHAPE_ASPECT` anchor. The two Ed.3 association entities: `TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION('t2g_assoc',...,#edge_loop,#sbsm)` links the topological model root (the face's `EDGE_LOOP`) to the geometric model root (the `SHELL_BASED_SURFACE_MODEL`); `GEOMETRY_TO_TOPOLOGY_MODEL_ASSOCIATION('g2t_assoc',...,#sbsm,#edge_loop)` is the inverse. Ed.3 readers use the pair to validate model-root consistency; Ed.2 / AP214 readers produce Void transfer status on both entities and silently drop the explicit topology↔geometry link — the face + annotation still load but the bidirectional association is absent.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); single planar `ADVANCED_FACE` in `OPEN_SHELL` / `SHELL_BASED_SURFACE_MODEL`; `SHAPE_ASPECT` + `ANNOTATION_OCCURRENCE` referencing the face; `TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION('...',...,#edge_loop,#sbsm)` + `GEOMETRY_TO_TOPOLOGY_MODEL_ASSOCIATION('...',...,#sbsm,#edge_loop)`.

Expected kernel behavior

AP242 Ed.3 readers must resolve `TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION` and `GEOMETRY_TO_TOPOLOGY_MODEL_ASSOCIATION` and expose the bidirectional model-root link; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(TOPOLOGY_TO_GEOMETRY_MODEL_ASSOCIATION)` rather than silently discarding the associations.
