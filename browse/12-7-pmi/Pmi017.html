Pmi017 — Saved-view supplemental geometry split via "supplemental geometry subset"

§12.7 (sub-class: saved-view)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi017.stp

Sources

  • 02-caxif (PMI v4.1 §9.4.2.2
  • Supplemental Geometry §5.5)

Description

A part may have many supplemental elements but only some belong in a particular Saved View. The recommended pattern is one global CGR with all elements, plus additional `shape_representation` instances tagged with `description_attribute = 'supplemental geometry subset'`.

Reproducer recipe

Two saved views; ten supplemental planes total; views 1 and 2 each show a different subset of three planes via two `shape_representation`s tagged with the magic description.

Expected kernel behavior

Heal and accept: normalize the magic description and treat those `shape_representation`s as supplemental subsets per view.

Notes

**See also**: M013. Synonyms: "saved-view supplemental geometry split via subset", "supplemental geometry separated from saved view", "supplemental subset entity used to split geometry".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'DRAUGHTING_MODEL') == 2
  • count_entity_def(b'DESCRIPTION_ATTRIBUTE') == 2
  • count_entity_def(b'PLANE') == 5

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
