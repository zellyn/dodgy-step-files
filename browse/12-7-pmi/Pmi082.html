Pmi082 — Saved-views and clipping planes lost on STEP read

§12.7 PMI/GD&T

P1 — silent data loss

Description

A STEP file containing AP242 saved-view entities (`PRESENTATION_VIEW`) and clipping-plane references is imported; saved views are silently discarded by readers unaware of these AP242 subtypes.

Reproducer recipe

STEP file with one `PRESENTATION_VIEW` linking three PMI annotations to a "side view" and one clipping plane.

Expected kernel behavior

Heal and accept: AP242 saved views populate the XCAF document view list; clipping-plane references are retained across round-trip.

Notes

**See also**: A076. Synonyms: "saved-views and clipping planes lost on STEP read", "section-plane data dropped on import", "saved-view clipping planes vanish".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CLIPPING_PLANE')
  • count_entity_def(b'DRAUGHTING_CALLOUT') == 3
  • contains(b'PRESENTATION_VIEW')
