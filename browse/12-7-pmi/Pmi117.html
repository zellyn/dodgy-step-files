Pmi117 — `FLAT_PATTERN` reference to non-sheet host (host is solid, not surface)

§12.7 (sub-class: AP242 feature definition / sheet-metal)

P1 — silent data loss

spec-violation pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi117.stp

Sources

  • 16-iso-spec AP242 §flat_pattern
  • CAx-IF Sheet-Metal Recommended Practices §host classification

Description

AP242 flat_pattern is defined for sheet-metal hosts: 2-D surface bodies whose thickness is a property, not a geometric extent (a `SHELL_BASED_SURFACE_MODEL` plus thickness attribute, or a `MANIFOLD_SURFACE_SHAPE_REPRESENTATION`). A producer that emits a flat_pattern referencing a thick `MANIFOLD_SOLID_BREP` creates a host-type contradiction: the host is not a sheet, so the flat layout has no meaning. Receivers either reject (host-type mismatch), heuristically extract a mid-surface (silent geometry change), or accept and produce a flat layout that does not match the host. Bug-reporter language: "flat pattern on solid not sheet", "AP242 flat pattern host type wrong", "FLAT_PATTERN expects surface body".

Reproducer recipe

A `SHAPE_ASPECT('flat_pattern')` whose `GEOMETRIC_ITEM_SPECIFIC_USAGE` references a host shape declared as solid (descriptive property `host_kind = 'solid'`) rather than a surface model.

Expected kernel behavior

reject (`E_FLAT_PATTERN_HOST_TYPE`); or extract mid-surface and emit `W_FLAT_PATTERN_HOST_DEMOTED` documenting the silent re-interpretation.

Notes

Sister to Pmi091 (feature attribute vs host extent); Pmi117 is host-type rather than host-extent. **See also**: Pmi091, Pmi114, Pmi115, Pmi116, Pmi118. Synonyms: "FLAT_PATTERN host is solid not sheet", "AP242 flat pattern non-surface host", "flat pattern references solid body", "sheet-metal layout on solid host".
