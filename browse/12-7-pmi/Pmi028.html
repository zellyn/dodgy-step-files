Pmi028 — common_datum vs common_datum_list (multi-feature datum)

§12.7 (sub-class: datum-frame)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi028.stp

Sources

  • 06-nist-sfa (S044)

Description

For ASME multiple-feature datums or ISO common datums, RP requires `datum_reference_element` with `common_datum_list`; some senders use the older `common_datum` instead.

Reproducer recipe

A multi-feature datum encoded with `common_datum(d1, d2)` rather than `common_datum_list((d1, d2))`.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; coerce the two forms to equivalent.

Notes

**See also**: Pmi027. Synonyms: "common_datum vs common_datum_list confusion", "multi-feature datum encoded with wrong entity", "common-datum multi-feature pattern misused".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'COMMON_DATUM')
  • count_entity_def(b'DATUM') == 2
  • contains(b'DATUM_SYSTEM')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
