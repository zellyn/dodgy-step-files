Pmi102 — `GROOVE` radial depth exceeds cylindrical host radius (depth wraps past axis)

§12.7 (sub-class: AP242 feature definition)

P1 — silent data loss

spec-violation pmi

Sources

  • 16-iso-spec ISO 10303-242 §feature_definition_schema (groove)
  • CAx-IF Feature Information Recommended Practice §groove on cylindrical host
  • bug-reporter language: "AP242 groove cuts through cylinder centerline", "groove depth wraps around axis", "circumferential groove depth too deep".

Description

AP242 `groove` on a cylindrical host has a radial depth that must be strictly less than the cylinder radius (otherwise the groove cuts through the cylinder centerline and "wraps" past the axis to reappear on the other side, leaving a self-intersecting feature definition). A producer that emits a groove with `radial_depth=15 mm` on a cylinder of radius 10 mm leaves a feature whose constructive evaluation is non-manifold. Receivers diverge: some clamp the depth to the radius, some accept and produce a self-intersecting solid, some reject. Bug-reporter language: "groove depth exceeds host radius", "GROOVE cuts past cylinder centreline", "AP242 groove wrap-around".

Reproducer recipe

a cylindrical host face with radius 10; a `SHAPE_ASPECT('GROOVE',..)` with `groove_radial_depth=15.0 mm` and `host_cylinder_radius=10.0 mm`.

Expected kernel behavior

validate radial depth < host radius for circumferential grooves; reject as inconsistent or clamp with a deterministic warning. Never accept silently.

Notes

**See also**: Pmi091, Pmi100, Pmi101. Synonyms: "GROOVE depth wrap-around", "groove cuts through cylinder centerline", "AP242 circumferential groove too deep", "radial depth exceeds host radius".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(6) ifc=schema_n/a

Closure intent

sheet — the open shell is the intended final geometry; a solid-only kernel should cleanly refuse.

Byte assertions

  • contains(b'GROOVE')
  • contains(b'CYLINDRICAL_SURFACE')
  • contains(b'depth_DEFECT_exceeds_radius')

Tier-3 assertions

  • n_faces_total == 1
  • face[0].surface_type == "cylinder"
  • face[0].quadric.radius == 10.0
