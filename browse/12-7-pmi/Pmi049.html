Pmi049 — Tessellated geometry with no styled_item / color

§12.7 (sub-class: semantic-vs-graphic)

P0 — receiver crash / hang / OOM

crash pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi049.stp

Sources

  • 06-nist-sfa (S025)

Description

A tessellated shape entity has no `styled_item` referencing it, so no color/style is set.

Reproducer recipe

`tessellated_solid` with no `styled_item`.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; coerce to a neutral default material.

Notes

Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT crashes (`signal(11)`). The crash is on the kernel side; the file is spec-conformant Part-21. **See also**: M017, M020.

Expected validation

occt=signal(11)/signal(11) gmsh=signal(11) ifc=schema_n/a

Byte assertions

  • contains(b'TESSELLATED_SHELL') or contains(b'TESSELLATED_SOLID')
  • contains(b'TRIANGULATED_FACE')
  • count_entity_def(b'STYLED_ITEM') == 0
