Pmi080 — GD&T tolerance frame missing tolerance-zone plane reference

§12.7 PMI/GD&T

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi080.stp

Sources

  • OCCT MANTIS#0029338 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A geometric tolerance specifies a tolerance zone (e.g., perpendicularity within 0.1 mm). AP242 requires the zone be expressed with a plane reference; older AP203 emissions drop the plane reference, leaving the zone direction ambiguous. Reader silently picks an arbitrary plane.

Reproducer recipe

Geometric tolerance with `tolerance_zone_form = unbounded` and no `tolerance_zone_plane` reference. Reader assigns `+Z` plane silently.

Expected kernel behavior

missing tolerance-zone plane is a hard error; readers reject or emit an explicit "ambiguous zone" diagnostic.

Notes

**See also**: Pmi077. Synonyms: "GD&T tolerance frame missing tolerance-zone plane reference", "tolerance zone plane reference absent", "FCF lacks zone plane".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • contains(b'GEOMETRIC_TOLERANCE')
  • contains(b'TOLERANCE_ZONE_FORM')
  • contains(b'SHAPE_ASPECT')
