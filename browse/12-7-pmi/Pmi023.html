Pmi023 — Multiple UUIDs for the same identified_item

§12.7 (sub-class: persistent-id)

P1 — silent data loss

round-trip pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi023.stp

Sources

  • 06-nist-sfa (S018)

Description

Two `uuid_attribute` entries reference the same item with different UUID values, creating ambiguity for round-trip.

Reproducer recipe

Two `UUID_ATTRIBUTE` entries pointing to the same shape with different values.

Expected kernel behavior

Warn and accept: emit a warning diagnostic; normalize the choice deterministically (lex-sort first).

Notes

**See also**: Pmi022. Synonyms: "single identified_item has multiple UUIDs", "PMI element tagged with several UUIDs", "more than one UUID assigned to one annotation".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'UUID_ATTRIBUTE') == 2
  • contains(b'4ce0acf8-1a2b-4c3d-9e8f-7a6b5c4d3e2f')
  • contains(b'a1b2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d')
