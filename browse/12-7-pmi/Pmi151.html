Pmi151 — AP242 Ed.3 `ANNOTATION_TO_MODEL_LEADER_LINE` (2D annotation → 3D face) dropped by Ed.2/AP214 readers

§12.7 PMI/GD&T (sub-class: edition-boundary entity elision / 2D-annotation-to-3D-face leader binding)

P1 — silent data loss

silent-loss pmi

View raw fixture (.stp) step-examples/12-7-pmi/Pmi151.stp

Sources

  • steptools.com AP242 Ed.3 notes (`ANNOTATION_TO_MODEL_LEADER_LINE` §4.5 — one of 21 new Ed.3 entities in the leader-line family
  • the Ed.3 entity that binds a 2D annotation directly to a specific 3D model `ADVANCED_FACE` rather than to an anchoring `SHAPE_ASPECT`). B4 wave-8 DEF-RR (LGPL-clean — pattern only, no upstream bytes copied). AP242 Ed.3 introduced explicit annotation-to-model-face leader lines so a 2D callout (position tolerance, GD&T frame, etc.) can carry a direct reference to the exact 3D face it applies to
  • earlier editions require an intervening `SHAPE_ASPECT` and their readers produce Void transfer status on the Ed.3-direct entity.

Sender

AP242 Edition 3 STEP files from PMI-authoring tools that emit direct annotation→3D-face leader bindings (typical for position tolerances applied to a specific face in an MBD model); file header declares `AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }` (Ed.3 OID with hybrid AUTOMOTIVE_DESIGN name).

Description

STEP AP242 Ed.3 file containing a minimal cube `MANIFOLD_SOLID_BREP` (six planar 10×10×10 mm faces) plus one PMI position tolerance callout `DRAUGHTING_ANNOTATION_OCCURRENCE('pos_tol_callout',(#callout_geom),#styled_item)` (with backing `POSITION_TOLERANCE('pos_tol_face_top','true position 0.1 to top face',LENGTH_MEASURE(0.1),#9055)`) linked to the top face's `ADVANCED_FACE` (a direct 3D-face reference) via `ANNOTATION_TO_MODEL_LEADER_LINE('atml_1',#pos_tol_annot,#face_zp,$)` — the Ed.3 entity that carries the 2D-annotation-to-3D-face leader binding directly (as opposed to Pmi148's binding to a `SHAPE_ASPECT`). Ed.3 readers resolve the leader line and expose the annotation→3D-face link through the PMI API, so downstream inspection tools can determine exactly which face the leader points at; Ed.2 / AP214 readers produce Void transfer status on the leader-line entity and silently drop the annotation→face link — the position tolerance annotation may still load individually but downstream inspection tools cannot recover which face is the target of the tolerance.

Reproducer recipe

AP242 Ed.3 header (`AUTOMOTIVE_DESIGN { 1 0 10303 442 4 1 4 }`); cube `MANIFOLD_SOLID_BREP`; `DRAUGHTING_ANNOTATION_OCCURRENCE` for a position tolerance callout; `POSITION_TOLERANCE('pos_tol_face_top','true position 0.1 to top face',LENGTH_MEASURE(0.1),#9055)`; `ANNOTATION_TO_MODEL_LEADER_LINE('atml_1',#pos_tol_annot,#face_zp,$)` — the target is the top-face `ADVANCED_FACE` directly.

Expected kernel behavior

AP242 Ed.3 readers must resolve `ANNOTATION_TO_MODEL_LEADER_LINE` and populate the annotation→target-3D-face link; Ed.2 / AP214 readers must emit `W_SCHEMA_ENTITY_UNSUPPORTED(ANNOTATION_TO_MODEL_LEADER_LINE)` rather than silently discarding the leader-line entity.

Notes

OCCT drops the Ed.3 entity and loads the geometry as if AP214 (cube + position-tolerance annotation load, direct face-target leader absent) — that IS the defect. Expected validation captured from OCCT live behavior. Edition boundary: Ed.3 entity absent from Ed.2, Ed.1, AP214 schemas. Sibling to Pmi148 (placeholder→SHAPE_ASPECT variant).
