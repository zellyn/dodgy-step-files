Lh043 — Header `FILE_DESCRIPTION` with comments inside string

§12.1b header structure

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh043.stp

Sources

  • OCCT MANTIS#0030397 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A `FILE_DESCRIPTION` record's strings contain `/* */` sequences that legacy readers strip as comments. The result is corrupted description content and possibly truncated header records.

Reproducer recipe

`FILE_DESCRIPTION(('Test /* note */ part'),'2;1');` — reader strips `/* note */` from inside the description string.

Expected kernel behavior

Heal and accept: comment-stripping never applies inside string literals; bracket comment characters with string-context state.

Notes

Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT rejects (`reject`). OCC enforces stricter framing than the spec text requires. Synonyms: "FILE_DESCRIPTION string contains comment", "/* inside FILE_DESCRIPTION string", "embedded comment in header literal", "STEP comment inside string", "header description with comment characters".
