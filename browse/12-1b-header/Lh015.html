Lh015 — User-defined HEADER entity not prefixed with `!`

§12.1b header/numbering

P1 — silent data loss

spec-violation syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh015.stp

Sources

  • 16-iso-spec N027

Description

ISO 10303-21 reserves header keywords without `!` for the standard. Vendor-specific HEADER entities must begin with `!` to avoid collision with future spec entities. Files appear with bare `VENDOR_INFO(..)` or similar.

Reproducer recipe

`HEADER; FILE_DESCRIPTION((''),'2;1'); FILE_NAME(..); FILE_SCHEMA(('AUTOMOTIVE_DESIGN')); VENDOR_INFO('SolidWorks 2024'); ENDSEC;`

Expected kernel behavior

reject the bare keyword; lenient mode may treat unknown header keywords as ignorable with a warning.

Notes

**See also**: Lh017. Synonyms: "vendor HEADER entity without bang prefix", "user-defined header missing exclamation mark", "VENDOR_INFO bare without !", "non-spec header entity collides with future spec", "custom HEADER record name not prefixed".
