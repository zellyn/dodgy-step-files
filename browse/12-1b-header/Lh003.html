Lh003 — Missing `ENDSEC;` between sections

§12.1b header/numbering

spec-violation syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh003.stp

Sources

  • 07-stepcode-ifcopenshell T039, 16-iso-spec N049

Description

A `HEADER`/`DATA`/`ANCHOR`/`REFERENCE`/`SIGNATURE` section runs into the next section keyword without an intervening `ENDSEC;` (or an `ENDSEC` token without trailing semicolon). Confuses parsers expecting strict bracketing.

Reproducer recipe

`HEADER;..FILE_SCHEMA(('IFC4'));DATA;#1=A();END-ISO-10303-21;` (no `ENDSEC;` before `DATA;`); or `HEADER;..ENDSEC<newline>DATA;` (semicolon missing).

Expected kernel behavior

reject with line-numbered diagnostic naming the offending section.

Notes

Synonyms: "missing ENDSEC between sections", "STEP HEADER runs into DATA", "ENDSEC token without semicolon", "section keyword without ENDSEC", "STEP section terminator missing".

Expected validation

occt=reject/reject gmsh=reject ifc=schema_n/a

Byte assertions

  • matches(rb'FILE_SCHEMA[^;]+;\s*DATA;')
  • not matches(rb'FILE_SCHEMA.*\)\)\s*;\s*ENDSEC;')

Tier-3 assertions

  • load != "ok"
