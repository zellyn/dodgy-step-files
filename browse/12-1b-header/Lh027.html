Lh027 — Malformed entity ID inside an ANCHOR entry (non-numeric `#`)

§12.1b header/numbering

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh027.stp

Sources

  • 06-nist-sfa S016

Description

ANCHOR entries reference `#NNN` form; entries using non-numeric tokens after `#` (e.g. `<#42@x>='product';`) violate the grammar.

Reproducer recipe

`ANCHOR; <part_anchor>=#42@x; ENDSEC;`

Expected kernel behavior

reject the entry with a precise diagnostic; do not abort the whole file.

Notes

**See also**: Lh026, Lh028. Synonyms: "non-numeric # in ANCHOR entry", "ANCHOR with bad instance ID syntax", "malformed entity reference in ANCHOR", "ANCHOR section grammar violation", "anchor target ID not a number".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'#42@x')

  • load == "ok"
