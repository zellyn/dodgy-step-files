Lh016 — Edition-3 extra header entities (`FILE_INFO`, `FILE_POPULATION`, `SECTION_LANGUAGE`, …)

Description

Edition 3 allows additional header entities beyond the required three (`FILE_POPULATION`, `SECTION_LANGUAGE`, implementation-private entries). Strict Edition-1/2 readers reject any header entity beyond the canonical three; tolerant Edition-3 readers must accept them.

Reproducer recipe

append `FILE_INFO('Report Date','2025-04-21 18:16:37', ..);` between FILE_SCHEMA and ENDSEC.

Expected kernel behavior

accept any number of extra header entities under Edition 3; warn for unknown names; reject under strict Edition-2.

Notes

Synonyms: "FILE_POPULATION header record", "Edition 3 extra header entities", "SECTION_LANGUAGE in HEADER", "Ed.2 reader rejects FILE_INFO", "Edition 3 header beyond required three".
