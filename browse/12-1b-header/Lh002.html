Lh002 — Missing or malformed closing marker `END-ISO-10303-21;`

§12.1b header/numbering

spec-violation syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh002.stp

Sources

  • 07-stepcode-ifcopenshell T028, 16-iso-spec N002

Description

Truncated downloads omit the closing `END-ISO-10303-21;`; concatenated dumps emit it twice; some generators substitute `END_ISO_10303_21;` (underscores), `END-ISO-10303;` (drops part number), or append trailing garbage after the marker.

Reproducer recipe

file ending with `ENDSEC;` and no `END-ISO-10303-21;`; or two `END-ISO-10303-21;` lines; or `END_ISO_10303_21;` substitution.

Expected kernel behavior

reject missing/duplicated end marker; tolerant mode may accept the underscore variant with a warning. Trailing bytes after the marker must be ignored, never appended to the previous entity.

Notes

**See also**: Ad038. Synonyms: "missing END-ISO-10303-21 marker", "truncated STEP file no end marker", "STEP closes with END_ISO_10303_21 underscores", "duplicate END marker in STEP", "trailing garbage after end marker".

Expected validation

occt=reject/reject gmsh=reject ifc=schema_n/a

Byte assertions

  • not bytes_ends_with(b'END-ISO-10303-21;')
  • contains(b'ENDSEC;')

Tier-3 assertions

  • load != "ok"
