Lh036 — SIGNATURE section with unknown signature algorithm

§12.1b header/numbering (sub-class: SIGNATURE)

P1 — silent data loss

syntax

View raw fixture (.stp) step-examples/12-1b-header/Lh036.stp

Sources

  • 16-iso-spec ISO 10303-21 Ed.3 §9 (SIGNATURE section)

Description

Edition-3 SIGNATURE sections are intended to carry cryptographic signatures over file content. The spec does not mandate a specific algorithm, so producers and consumers must agree out-of-band. A consumer that does not implement SIGNATURE must skip, warn, or reject; what it must NOT do is parse the signature payload as DATA and fault on the unknown record format.

Reproducer recipe

SIGNATURE section with an opaque payload `'algo=unknown-future-1; payload=00112233..EEFF;'`.

Expected kernel behavior

Warn and accept: skip SIGNATURE sections by default if the algorithm is unsupported; never let signature payload bytes enter the DATA-section parser.

Notes

Synonyms: "unknown SIGNATURE algorithm", "STEP SIGNATURE unrecognised", "SIGNATURE section algorithm unsupported", "STEP signature algorithm not known", "cryptographic signature in STEP unknown".
