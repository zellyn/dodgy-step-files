Description

`FILE_NAME.preprocessor_version` contains `'I-DEAS Master Series 11'`, which unconditionally sets `myNMTool.SetIDEASCase(True)`. The DATA section contains real shell topology behind that trigger: a unit cube's bottom+4 side faces form one `OPEN_SHELL` (missing its top face); the 6th (top) face forms a SECOND shell whose 4 boundary `EDGE_CURVE`s are the SAME entities already used by the 4 side faces' top edges — genuine cross-shell entity reuse, the exact structural precondition `IsPureNMShell`/`IsSuspectedAsClosing` require of a candidate closing shell for `computeIDEASClosings`/`closeIDEASShell` to merge it into the open shell and prune any now-redundant face.

Reproducer recipe

`FILE_NAME('...',...,'I-DEAS Master Series 11','','')`; a `SHELL_BASED_SURFACE_MODEL` with two `OPEN_SHELL`s — one missing a face, the other containing exactly that missing face and reusing the same boundary `EDGE_CURVE` entities as the first shell's adjacent faces.

Expected kernel behavior

detect non-manifold/closable structure from the entity graph itself (shared-edge adjacency between shells), not from a header substring; merge genuinely-closing adjacent shells by default rather than gating the repair behind both a brittle header heuristic AND an opt-in reader flag.

Notes

Fixes Lh031's gap: Lh031 triggers the substring auto-detect but its DATA section is only a two-point `GEOMETRIC_CURVE_SET` — no open shells, no closing shells, no real topology for `computeIDEASClosings`/`closeIDEASShell` to act on at all. This fixture supplies that missing topology. Live-verified (2026-07-12, OCP 7.8.1, direct probing — not mirrored/guessed): under this corpus's own default `validate2` oracle settings, the reader loads the two shells VERBATIM (`shape_null=False`, 6 faces, 2 shells, 0 solids — not merged), matching Lh031's own established finding that OCCT's default transfer never engages non-manifold-specific processing. Explicitly driving `read.step.nonmanifold=1` and `read.step.ideas=1` through `Interface_Static` before `ReadFile`/`TransferRoots` on this exact construction was ALSO checked and did not observably merge the shells either (still 2 shells / 0 solids) — recorded honestly (cf. N173's identical finding pattern for a different opt-in mechanism) rather than mirroring an unverified auto-merge claim; what this fixture delivers and live-verifies is the concrete structural precondition (real, adjacent, genuinely edge-sharing open/closing shell topology behind the header trigger) that Lh031 lacked, plus the exact OCCT source call sites a correctly-wired non-manifold transfer path would invoke against this precise topology. Provenance tier: bytes-sufficient. **See also**: Lh031 (header-only precedent this fixture adds real topology behind).
