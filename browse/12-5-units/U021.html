U021 — KILO prefix REQUIRED on `mass_unit` referenced from a derived SI unit (Newton)

§12.5 (sub-class: dimensional-exponents / mass prefix)

P1 — silent data loss

units

Description

Newton is `[kg·m·s⁻²]`. Each `si_unit` referenced by `derived_unit_element` for a derived SI unit must NOT carry a prefix, except when the referenced si_unit is a `mass_unit`, which MUST carry `.KILO.`. Forgetting the prefix makes Newton numerically equivalent to gram·m·s⁻², off by 1000. For SI mass overall, only `kilogram` (prefix `kilo` on base `gram`) is allowed.

Reproducer recipe

define a `force_unit` (Newton) whose `derived_unit_element` references a `mass_unit` with no prefix; or a free-standing mass unit with prefix other than `.KILO.`.

Expected kernel behavior

validate; when a derived SI unit pulls in `mass_unit`, ensure prefix is `.KILO.`; reject or auto-convert otherwise.

Notes

**See also**: U026. Synonyms: "KILO prefix missing on mass_unit", "Newton built without kilo prefix", "force_unit derived from gram instead of kg", "STEP Newton off by 1000", "mass_unit prefix wrong in derived SI".
