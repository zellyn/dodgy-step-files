U033 — Unit-default flag silently overridden by file's first unit-record

§12.5 units

P1 — silent data loss

Description

A reader is configured with a default unit (`xstep.cascade.unit`). The file emits an explicit `LENGTH_UNIT` record. Reader assumes the configured default but the file's record overrides without warning; conversely, when the configured unit and the file's unit disagree, the reader may apply the conversion factor twice.

Reproducer recipe

STEP file with explicit `LENGTH_UNIT` of inches; reader configured with default `xstep.cascade.unit = MM`. Behaviour varies across versions (some apply file unit, some apply default, some apply both as conversion).

Expected kernel behavior

Warn and accept: file-declared units take precedence; the configured default applies only when the file omits the unit record; emit a diagnostic when the two disagree.

Notes

**See also**: U025, U028. Synonyms: "xstep.cascade.unit overridden by file unit", "default unit ignored when file declares unit", "configured default conflicts with STEP unit", "reader applies conversion twice", "STEP unit default vs file divergence".
