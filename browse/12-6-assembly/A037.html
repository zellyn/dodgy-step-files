Description

STEP file with `MANIFOLD_SOLID_BREP` data but no `PRODUCT`, `PRODUCT_DEFINITION`, or `SHAPE_DEFINITION_REPRESENTATION`; common in minimalist exporters and many open-source / hobbyist tools.

Reproducer recipe

Expected kernel behavior

synthesize default product wrapper; warn.
