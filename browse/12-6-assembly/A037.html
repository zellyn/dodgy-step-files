A037 — Implicit / minimalist product structure missing entirely

§12.6 (sub-class: missing PRODUCT_DEFINITION)

assembly

Sources

  • W033 (CAD Exchanger CHANGES v3.24.13).

Description

STEP file with `MANIFOLD_SOLID_BREP` data but no `PRODUCT`, `PRODUCT_DEFINITION`, or `SHAPE_DEFINITION_REPRESENTATION`; common in minimalist exporters and many open-source / hobbyist tools.

Reproducer recipe

bare `ADVANCED_BREP_SHAPE_REPRESENTATION` with no `PRODUCT_DEFINITION_SHAPE` reference.

Expected kernel behavior

synthesize default product wrapper; warn.

Notes

**See also**: A003. **OCC behavior**: emits a diagnostic but produces no shape (warn-and-proceed by oracle, but result is empty); outside catalog's allowed set ({heal}). Kernel-bug witnessed: catalog asks for healing; OCC neither heals nor rejects; the input is dropped on the floor without diagnostic. Synonyms: "minimal STEP has no PRODUCT entity", "implicit product structure missing", "file lacks any product definition", "geometry-only STEP without metadata".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'PRODUCT_DEFINITION_SHAPE') == 0
  • count_entity_def(b'NEXT_ASSEMBLY_USAGE_OCCURRENCE') == 0

Tier-3 assertions

  • shape_null == True
