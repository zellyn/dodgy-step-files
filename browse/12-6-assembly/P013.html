P013 — AP203-claimed file uses AP214/AP242-only entities

§12.1 schema-conformance

assembly

View raw fixture (.stp) step-examples/12-6-assembly/P013.stp

Sources

  • FreeCAD #11765

Sender

FreeCAD/OCCT itself (writer)

Description

AP203 output emits entities `SEAM_CURVE`, `SURFACE_CURVE`, `PCURVE` not in AP203's defined entity set. Strict AP203 readers reject. Implementor-detail of OCCT's "merged AP" approach.

Reproducer recipe

Closed cylinder/sphere face with seam, exported with AP203 selected, contains `SEAM_CURVE`/`PCURVE` entities.

Expected kernel behavior

AP203 output validates as AP203; or explicit warning that `AUTOMOTIVE_DESIGN` is the actual schema.

Notes

Synonyms: "AP203 file uses AP214-only entities", "schema claim doesn't match content", "AP203 header but AP242 entities inside", "schema-conformance violation in file body".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CONFIG_CONTROL_DESIGN')
  • contains(b'SEAM_CURVE')
  • contains(b'PCURVE')
