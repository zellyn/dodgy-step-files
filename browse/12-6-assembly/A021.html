A021 — CDORSI WR1 violated by per-component styling in Saved View

§12.6 (sub-class: CONTEXT_DEPENDENT_OVER_RIDING_STYLED_ITEM)

P0 — receiver crash / hang / OOM

crash assembly

View raw fixture (.stp) step-examples/12-6-assembly/A021.stp

Sources

  • CAx-IF PMI v4.1 §9.4.2.3 (entry from 02-caxif).

Description

Hiding or restyling a single assembly component within a Saved View uses `context_dependent_over_riding_styled_item` whose `style_context` mixes one `mapped_item` with one or more `representation_relationship`s. This violates CDORSI WR1 ("only one rep_item OR all are mapped_items OR all are representation_relationships"). The recommendation is to do it anyway.

Reproducer recipe

Two-level assembly; Saved View where one leaf component is hidden by a CDORSI whose `style_context` is `(mapped_item, representation_relationship_1, representation_relationship_2)`.

Expected kernel behavior

Warn and accept this pattern despite the WR1 violation; do not reject.

Notes

Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT crashes (`signal(11)`). The crash is on the kernel side; the file is spec-conformant Part-21.
