A076 — General attributes (AP242 GENERAL_PROPERTY) dropped on import

§12.6 assembly

P1 — silent data loss

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A076.stp

Sources

  • OCCT MANTIS#0033530
  • OCCT MANTIS#0033641 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

AP242 introduces `GENERAL_PROPERTY` as a generic attribute mechanism; arbitrary key/value pairs attached to products. A STEP reader configured for AP203 silently discards these; even an AP242-aware reader may discard them if its metadata flag is off by default.

Reproducer recipe

AP242 STEP file with `GENERAL_PROPERTY('density', '7.85')` and `GENERAL_PROPERTY('material', 'STEEL')` attached to one part. Read with default config.

Expected kernel behavior

Heal and accept: AP242 reader populates document-level property table from `GENERAL_PROPERTY` entities; default config preserves metadata. Must not silently drop properties.

Notes

Provenance tier: runtime-only; kernel drops GENERAL_PROPERTY on import; defect is reader behavior.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a
