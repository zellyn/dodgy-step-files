A084 — STEP exporter writes untrimmed curve where trimmed expected

§12.6 assembly

P1 — silent data loss

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A084.stp

Sources

  • OCCT MANTIS#0032817 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

An edge backed by a trimmed curve (e.g., a half-circle arc) is exported with the full underlying parent curve plus separate trim markers — but the exporter omits the trim markers entirely. The re-imported edge spans the full parent curve, giving wrong arc length.

Reproducer recipe

Edge on a circle from parameter `t=0` to `t=π`. After export, file emits `CIRCLE` plus `EDGE_CURVE` with full-parameter range `[0, 2π]` instead of `[0, π]`.

Expected kernel behavior

Heal and accept: every edge writes its trim parameters; receivers see the intended sub-arc. Must not silently drop trim parameters.

Notes

Provenance tier: writer-side — writer emits untrimmed where trimmed expected.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Provenance tier

writer-side — defect not fully embodied in fixture bytes.

Byte assertions

  • contains(b'CIRCLE')
  • contains(b'EDGE_CURVE')
  • contains(b'half_arc_full_curve') or contains(b'parent')
