P010 — Standalone AXIS2_PLACEMENT_3D entities silently dropped

§12.6 assembly / non-geometric annotations

silent-loss assembly

View raw fixture (.stp) step-examples/12-6-assembly/P010.stp

Sources

  • FreeCAD #5882

Sender

unspecified (multiple)

Description

Standalone `AXIS_PLACEMENT` / `AXIS2_PLACEMENT_3D` entities used as datum/feature axes (often referenced from `PRESENTATION_LAYER_ASSIGNMENT`) are silently dropped on import; no warning. Useful design-intent information is lost.

Reproducer recipe

STEP file with `AXIS2_PLACEMENT_3D('Axis_A', ..)` referenced from `PRESENTATION_LAYER_ASSIGNMENT`.

Expected kernel behavior

Either ignore-with-warning, or surface as construction objects.

Notes

Synonyms: "standalone AXIS2_PLACEMENT_3D entities silently dropped", "datum frame lost on import", "orphan axis placement disappears", "construction frames stripped by reader".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'PRESENTATION_LAYER_ASSIGNMENT') >= 1
  • count_entity_def(b'AXIS2_PLACEMENT_3D') >= 2

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
