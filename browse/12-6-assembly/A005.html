A005 — Lost assembly hierarchy on round-trip (flatten to single CATPart / single solid)

§12.6 (sub-class: instance-flattening on import)

P1 — silent data loss

round-trip assembly

View raw fixture (.stp) step-examples/12-6-assembly/A005.stp

Sources

  • V030 (CATIA→Inventor), V032 (CATIA import), V058 (Inventor multi-body), Y026 (CATIA), V031 (CATIA V5 import options), K021 (Rhino blocks).

Sender

any multi-product STEP assembly.

Description

A multi-level NAUO graph imports as a single flat part with N solid bodies, losing PRODUCT_DEFINITION nesting. CATIA needs "One CATProduct per product" option; Rhino has block vs nested-layer choice. Key signature: every leaf body shares one `PRODUCT_DEFINITION_FORMATION`.

Reproducer recipe

STEP with ≥3 levels of NAUO + MAPPED_ITEM referencing shared REPRESENTATION_MAP; import to CATIA V5 with default options.

Expected kernel behavior

Heal and accept via configurable mapping (block / nested-layer / flatten) with default that preserves hierarchy. Validators should reject silent flattening by checking shared PDF.

Notes

**See also**: P024. Synonyms: "subassembly hierarchy collapsed to one part", "assembly tree flattened on export", "round-trip loses subassemblies", "imported file has single CATPart instead of nested structure", "all components merged into one solid".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • count_entity_def(b'REPRESENTATION_MAP') == 3
  • count_entity_def(b'MAPPED_ITEM') == 3
