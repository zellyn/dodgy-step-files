A020 — Bare STYLED_ITEM at top level (no MDGPR / DRAUGHTING_MODEL parent)

§12.6 (sub-class: styled_item parenting)

P1 — silent data loss

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A020.stp

Sources

  • G003 (OCCT ec661e4 / Mantis 0024159), G027 (NULL STYLED_ITEM.item), G063 (PSA NULL handle).

Sender

Autodesk Inventor 2014.

Description

Inventor emits `STYLED_ITEM` entities not parented under `MECHANICAL_DESIGN_GEOMETRIC_PRESENTATION_REPRESENTATION` or `DRAUGHTING_MODEL`; older readers skipped them, dropping all colors. Variant: `STYLED_ITEM.item` is NULL or its `PRESENTATION_STYLE_ASSIGNMENT.styles` set has NULL elements.

Reproducer recipe

STEP file with bare STYLED_ITEM at top level; or `STYLED_ITEM(name,(..),#null)`.

Expected kernel behavior

Accept bare styled items with a warning; null-check PSA styles; skip NULL silently. Do not reject this pattern.

Notes

**See also**: A018, M039, M040. Synonyms: "STYLED_ITEM at top level has no parent draughting model", "bare style entity orphaned in file", "MDGPR / DRAUGHTING_MODEL parent missing for style", "color entity unbound from any view or model".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Tier-3 assertions

  • face[0].sliver_aspect_max_min > 1e6
  • face[0].surface_type == "plane"
  • brepcheck.valid == True
