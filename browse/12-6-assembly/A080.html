A080 — Hierarchy & colours lost on partial-document IGES/STEP write

§12.6 assembly

P1 — silent data loss

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A080.stp

Sources

  • OCCT MANTIS#0026657
  • OCCT MANTIS#0026500 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

Writing only a subset of an XCAF document (e.g., one branch) flattens the assembly tree and drops per-branch colours. The exported file contains only the selected geometry, no hierarchy, no styles; even though the source document has all three.

Reproducer recipe

Two-branch assembly; write only branch B. Branch B in source has colour and hierarchy; branch B in output has neither.

Expected kernel behavior

Heal and accept: partial-write preserves the structure of the written subtree fully; only contents *outside* the subtree are excluded. Must not silently lose colours/hierarchy.

Notes

**See also**: A077, A068. Synonyms: "partial-document IGES/STEP write loses hierarchy and colours", "exporting subset of XCAF doc strips colors", "selective export drops assembly tree".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'NEXT_ASSEMBLY_USAGE_OCCURRENCE') == 2
  • count_entity_def(b'STYLED_ITEM') >= 2
  • count_entity_def(b'COLOUR_RGB') >= 2
