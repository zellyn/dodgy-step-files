P015 — Non-manifold or open shell exported as `MANIFOLD_SOLID_BREP`

§12.3 topology

assembly

View raw fixture (.stp) step-examples/12-6-assembly/P015.stp

Sources

  • FreeCAD #25774, #16292, #26639

Sender

FreeCAD (PartDesign with SubShapeBinder offsets)

Description

A solid that is closed in the producer is wrapped as `MANIFOLD_SOLID_BREP` but at least one edge appears only once across the shell, or one face's `FACE_OUTER_BOUND` orientation is inverted; so the result is not actually manifold. Re-import yields zero solids; STL still works because tessellation ignores topology.

Reproducer recipe

STEP file with all faces individually valid but at least one edge appearing only once; or one face with inverted outer-bound orientation. Optionally drop `MANIFOLD_SOLID_BREP` wrapper and emit only `SHELL_BASED_SURFACE_MODEL`.

Expected kernel behavior

Either heal to solid, or expose explicitly as open shell with warning.

Notes

**See also**: M052. Synonyms: "open shell exported as MANIFOLD_SOLID_BREP", "non-manifold geometry mislabeled as solid", "writer claims solid but topology is open shell", "MANIFOLD_SOLID_BREP with missing faces".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Closure intent

solid (defect kind: missing_face) — authored as a closed solid; openness is the defect — heal it shut.

Byte assertions

  • count_entity_def(b'MANIFOLD_SOLID_BREP') >= 1
  • contains(b'FACE_OUTER_BOUND')

Tier-3 assertions

  • n_faces_total == 1
