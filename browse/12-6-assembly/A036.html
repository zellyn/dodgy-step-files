A036 — Hybrid AP203 (≤1998) using ShapeAspect-attached SDR

§12.6 (sub-class: hybrid product structure / legacy AP203)

P1 — silent data loss

assembly

Sources

  • Q039 (OCCT STEPControl_ActorRead.cxx:425-458,519-525).

Description

Older AP203 (≤1998) hybrid models linked SDRs to the main model via shape_aspect rather than directly via product_definition_shape. Modern readers expect direct linkage.

Reproducer recipe

AP203 ≤1998 file with PRODUCT linked through SHAPE_ASPECT to its SDR.

Expected kernel behavior

Heal and accept: detect legacy hybrid pattern; follow ShapeAspect-mediated SDR link.

Notes

**See also**: A035. Synonyms: "AP203 1998 ShapeAspect-attached SDR pattern", "hybrid AP203 file uses old ShapeAspect chain", "legacy AP203 product structure".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • contains(b'legacy_link') or contains(b'AP203 hybrid')
