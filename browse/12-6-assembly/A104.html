A104 — Exception raised during STEP write with `ExternalReferences` mode in XDE document

§12.6 assembly hierarchy (sub-class: writer crash on external-ref mode)

P1 — silent data loss

crash assembly

View raw fixture (.stp) step-examples/12-6-assembly/A104.stp

Sources

  • OCCT MANTIS#0013328
  • bug-reporter language: "exception is raised during writing with ExternalReferences mode in STEP XDE document", "writer throws on multi-file export", "STEP write mode crashes on assembly with external part files". (OCCT MANTIS tracker 502 as of 2026-05-02)

Sender

OCCT's STEP writer when the document uses `STEPControl_Writer::Transfer` with `mode = STEPCAFControl_ExternalFileReferences` and the document references unsaved external `.stp` peers.

Description

When the writer is asked to emit a multi-file assembly (one file per part, plus a top-level file with `EXTERNAL_REFERENCED_DOCUMENT` pointing to peers), an unhandled `Standard_DomainError` propagates out of the call when one of the peer documents has not been previously saved or when a label has no associated `TopoDS_Shape`. The writer aborts mid-stream, leaving partial output files on disk.

Reproducer recipe

XDE document with two assembly branches; branch A has shape, branch B is empty. Call `STEPCAFControl_Writer::Perform` with external-reference mode. Writer throws.

Expected kernel behavior

heal-and-accept; every writer entry point validates the document graph before opening output files; emit `W_EMPTY_BRANCH` and skip empty branches; never throw across the writer's public API.

Notes

**See also**: A082, A096. Synonyms: "STEP writer exception in ExternalReferences mode", "multi-file STEP export throws on empty branch", "writer crashes when peer document missing", "Standard_DomainError during STEP write".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

  • contains(b'EXTERNALLY_DEFINED_ITEM')
  • contains(b'PRODUCT_DEFINITION')
  • count_entity_def(b'PRODUCT_DEFINITION') >= 2

Tier-3 assertions

  • shape_null == False
  • n_faces_total == 1
  • n_edges_total == 4
  • n_vertices_total == 8
