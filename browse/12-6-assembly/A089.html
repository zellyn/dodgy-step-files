A089 — Sub-shape names lost in non-manifold STEP output

§12.6 assembly

P1 — silent data loss

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A089.stp

Sources

  • OCCT GitHub#284
  • OCCT MANTIS#0023384 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A document with named sub-shapes is exported in non-manifold mode (`write.step.nonmanifold`). The non-manifold writer collects topology but does not run the styled-item / name-emission code, losing all sub-shape names.

Reproducer recipe

Document with two named faces ("inlet" and "outlet"). Set `write.step.nonmanifold = true`; write. Output file has no `STYLED_ITEM` records carrying names.

Expected kernel behavior

Heal and accept: name-emission runs in both manifold and non-manifold modes; styled-item attachment to sub-shapes must follow the topology emitted. Must not silently lose sub-shape names.

Notes

**See also**: A064, A085. Synonyms: "subshape names lost in non-manifold STEP output", "non-manifold export drops face/edge labels", "names missing in non-manifold writer".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'STYLED_ITEM') >= 2
  • contains(b"'inlet'") and contains(b"'outlet'")
