A030 — Edition-mixed Part 21 file (header schema vs instance schema)

§12.6 (sub-class: schema migration / edition tag)

assembly

View raw fixture (.stp) step-examples/12-6-assembly/A030.stp

Sources

  • M029 (STEP Tools edition notes), W046 (Datakit), V043 (Creo 4 cannot import Creo 7+ STEP).

Description

`FILE_SCHEMA` declares one edition (e.g. AP242 Ed.2) but payload contains entities valid only under another edition (e.g. AP242e3 hole-feature entities, or AP242-only entities like `ROUND_HOLE` in a file declaring `AUTOMOTIVE_DESIGN`). Older readers parse newer entity flavors as fatal errors and crash.

Reproducer recipe

Hand-edit `FILE_SCHEMA` line to claim Ed.2 in an Ed.3 file; or declare AP214 with AP242-only entities.

Expected kernel behavior

Warn and accept: parse based on entity availability, not header schema name; warn on mismatch; forward-compatible reader; unknown entities should be ignored, not fatal. Do not reject on edition mismatch.

Notes

**See also**: A031, A032, Pmi010. Synonyms: "header schema differs from instance schema in Part 21", "AP203 header but AP242 entities inside", "edition-mixed STEP file confuses reader", "schema declared in HEADER doesn't match body".
