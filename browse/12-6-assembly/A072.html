A072 — Compound with single vertex written as compound-of-two-points

§12.6 assembly

P1 — silent data loss

assembly

Description

A document contains a single isolated vertex (e.g., a reference point). The STEP writer emits both a `CARTESIAN_POINT` and a redundant `VERTEX_POINT` at top level, producing a compound-of-two-points on re-import.

Reproducer recipe

XCAF document with one TopoDS_Vertex at coords `(0,0,0)`. Write to STEP. Reader sees two points.

Expected kernel behavior

Heal and accept: a single vertex is emitted as one `VERTEX_POINT` referenced from one shape representation; never duplicate.

Notes

Provenance tier: writer-side; writer emits compound-of-two-points instead of single vertex.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Provenance tier

writer-side — defect not fully embodied in fixture bytes.

Byte assertions

  • count_entity_def(b'CARTESIAN_POINT') == 1
  • count_entity_def(b'VERTEX_POINT') == 1
  • contains(b'emitted_twice')

Tier-3 assertions

  • shape_null == True
