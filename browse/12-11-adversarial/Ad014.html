Ad014 — Float literal with extreme exponent (`1E999999`) propagates as inf/NaN

Description

`strtod` returns inf/0 for very large/small exponents; downstream code converts to fixed-precision (tessellation grid index) → overflow. NaN propagates into unguarded `<`/`>` comparison, breaking sort invariants in an STL container → UAF.

Reproducer recipe

`#1=CARTESIAN_POINT('',(1.0E+999999,0.,0.));`

Expected kernel behavior

clamp magnitude; reject non-finite where geometry expects finite.
