Description

Applying an extreme non-uniform (general) transform to a face raises a construction-error exception across the API boundary, rather than returning a failure status. The user-visible symptom is "loading a model with very large scaling factors crashes".

Reproducer recipe

Expected kernel behavior

Reject and return a failure status or an empty result; do not let an unhandled exception escape across the API boundary. Must not crash.
