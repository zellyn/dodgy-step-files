Ad056 — General-transform constructor throws on extreme non-uniform face stretch

Sources

  • 18-other-issues.md I058 (OCCT #872)

Description

Applying an extreme non-uniform (general) transform to a face raises a construction-error exception across the API boundary, rather than returning a failure status. The user-visible symptom is "loading a model with very large scaling factors crashes".

Reproducer recipe

large general-transform scaling factor; instantiate transform.

Expected kernel behavior

Reject and return a failure status or an empty result; do not let an unhandled exception escape across the API boundary. Must not crash.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'CARTESIAN_TRANSFORMATION_OPERATOR_3D') and contains(b'1.0E+18')
  • contains(b'1.0E+18')
