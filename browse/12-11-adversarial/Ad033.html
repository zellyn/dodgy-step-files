Ad033 — Translator OOB write copying parsed string into packed C struct

§12.11 (sub-class: heap-overflow / OOB-write)

P2 — spec deviation (no data loss)

adversarial

Description

Vendor-specific translator copies parsed Part-21 strings into packed struct buffer; field lengths from input not bounds-checked against destination slot size.

Reproducer recipe

`PRODUCT('long_name','long_id','desc',(..));` where `long_name` exceeds the translator's struct field.

Expected kernel behavior

Reject with diagnostic: validate per-attribute lengths against destination size before copy. Must not crash via OOB write.

Notes

C.
