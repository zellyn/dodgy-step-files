Description

IGES Directory-Entry uses fixed 80-column records; record with non-space padding or off-by-one length crashes when directory parser indexes column 73.80 unconditionally. Relevant because translators commonly share code paths with STEP.

Reproducer recipe

IGES file whose terminator section reports record count one greater than physically present.

Expected kernel behavior

Heal and accept: bound all column indexes against actual line length. Must not crash on column-out-of-range.

Notes

Validation observed: silent-empty rather than the cited crash. The structural attack pattern (e.g., billion-laughs / cyclic-reference / very-large-string) is demonstrated; production-scale exploitation requires inflating the size factor as described. Kernel-mishandling-by-silent-acceptance is itself a defect signal at fixture scale.
