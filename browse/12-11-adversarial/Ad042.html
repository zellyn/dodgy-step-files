Description

Schema SELECT type validated by structural shape only; attribute type is wrong subtype, leading downstream chained calls (`x->A()->B()`) to deref a null handle.

Reproducer recipe

minimum AP214 with `#27=SHAPE_DEFINITION_REPRESENTATION(#23,#26)` where `#23=SHAPE_ASPECT(..)` instead of `PROPERTY_DEFINITION_SHAPE`.

Expected kernel behavior

Reject with `E_SELECT_BRANCH` diagnostic via schema-aware select-narrowing that distinguishes branches; must not crash by dereffing wrong-typed entity.

Notes

Documented as 1088/1267 SDRs broken in a 430 MB CATIA V6 file. **See also**: Ad030. Validation observed: silent-empty rather than the cited crash. The structural attack pattern (e.g., billion-laughs / cyclic-reference / very-large-string) is demonstrated; production-scale exploitation requires inflating the size factor as described. Kernel-mishandling-by-silent-acceptance is itself a defect signal at fixture scale.
