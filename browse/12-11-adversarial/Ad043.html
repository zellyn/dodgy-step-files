Description

Reader paths assume non-null entity references and throw an uncaught exception (access violation, out-of-range, or similar) when a STEP file references a non-existent entity, supplies a null `swept_curve`, has an empty edge loop, a `STYLED_ITEM` with a null `item` reference, a vertex with null name/id, etc. The exception escapes across the reader's API boundary and aborts the import.

Reproducer recipe

any of the above patterns; e.g. `STYLED_ITEM('',(..),#null);` where `#null` is unresolved.

Expected kernel behavior

Every reader path must be defensive against null and dangling references; warn-and-accept (skip the offending instance with diagnostic), return an empty/partial result, or reject and signal failure via a status flag. Never let an unhandled exception escape across the parser/importer ABI; must not crash.

Notes

Cross-oracle: pure-Python Part-21 validator rejects (reject(E_UNRESOLVED_REFS)); OCCT silently accepts (load is `empty`). OCC auto-heals a spec-level violation.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'#999')
  • contains(b'STYLED_ITEM') and contains(b'#999')

Tier-3 assertions

  • load == "ok"
