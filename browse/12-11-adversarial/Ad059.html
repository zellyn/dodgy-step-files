Description

STEP `RATIONAL_BSPLINE_CURVE` with weights array length ≠ poles array length; reader walks past end of weights vector.

Reproducer recipe

`RATIONAL_BSPLINE_CURVE` with weights `(1.,1.,1.)` and poles `(#1,#2,#3,#4)`.

Expected kernel behavior

validate equality; pad/truncate with warning; never read past either array.

Notes

**See also**: Gn002. **OCC behavior**: silently accepts (no diagnostic, empty result); outside catalog's allowed set ({warn-and-proceed}). Kernel-bug witnessed: catalog wants a warning to surface; OCC accepts without any diagnostic.
