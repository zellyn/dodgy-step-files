Ad055 — Stack overflow when meshing TBB pool from STEP import

§12.11 (sub-class: stack-overflow / resource-exhaustion)

P2 — spec deviation (no data loss)

adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad055.stp

Sources

  • 18-other-issues.md I064 (OCCT #688)
  • 20-general-forums.md J020 (huge-faces-per-shell stack overflow)

Description

Recursive traversal of `CLOSED_SHELL` with O(10⁵) faces overflows the C stack on Windows defaults; the parallel mesher then stack-overflows on a per-thread 1 MB stack default.

Reproducer recipe

STEP with single closed shell holding 10⁵ faces; mesh in parallel mode.

Expected kernel behavior

Heal and accept via iterative traversal; configurable per-thread stack; or fall back to single-thread on overflow. Must not crash via stack overflow.

Notes

**See also**: Ad032, Pf008, Pf009.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1296) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'ADVANCED_FACE') >= 10 or count(b'#') >= 100
  • count(b'#1') >= 5

Tier-3 assertions

  • load == "ok"
