Ad026 — Self-referencing complex-entity instance during construction

Description

`#1=(A() B(#1))` — sub-entity references outer instance during construction. Two-phase build that derefs `#1` while still constructing → half-initialised vtable use (UAF in C++).

Reproducer recipe

any complex entity whose attributes include `#self`.

Expected kernel behavior

Heal and accept: build attribute graph in two passes — allocate placeholder shells first, bind references after. Must not crash or infinite loop.

Notes

H; hard-to-reach UAF. **See also**: Ad004.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
