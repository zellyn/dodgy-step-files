Description

Composite curve whose segment list contains a reference back to the curve itself.

Reproducer recipe

`#1=COMPOSITE_CURVE('',(#2),.T.); #2=COMPOSITE_CURVE_SEGMENT(.CONTINUOUS.,.T.,#1);`

Expected kernel behavior

cycle-detect during composite-curve assembly; reject with `E_CURVE_CYCLE`.
