Ad053 — Cyclic / reference-to-reference chain of `SHAPE_REPRESENTATION_RELATIONSHIP`

§12.11 (sub-class: cyclic-reference / DoS)

P2 — spec deviation (no data loss)

adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad053.stp

Sources

  • 08-occt-gitlog.md G033 (Mantis 0031568)

Description

A `SHAPE_REPRESENTATION_RELATIONSHIP` (SRR) is used as the right-hand side (`rep_2`) of another SRR — a "reference to reference" chain — producing an invalid model. Common attack shape: three SRR entities forming a 3-cycle by each referencing the next in `rep_2` (#100→#101→#102→#100); deeper chains are quadratic or cyclic.

Reproducer recipe

`SHAPE_REPRESENTATION_RELATIONSHIP` whose `rep_2` is itself an SRR.

Expected kernel behavior

Heal and accept: resolve transitively; cap recursion depth and reject when cap exceeded. Must not infinite loop.

Notes

**See also**: Ad004.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'SHAPE_REPRESENTATION_RELATIONSHIP') >= 3
  • matches(rb'(?s)#100=SHAPE_REPRESENTATION_RELATIONSHIP[^;]+#101[^;]+;.*#101=SHAPE_REPRESENTATION_RELATIONSHIP[^;]+#102')

Tier-3 assertions

  • load == "ok"
