Description

Schema declares `LIST [1:?]`; producer emits empty list; downstream code dereferences `list[0]`. Or weight-array length mismatches pole-count.

Reproducer recipe

`#1=ADVANCED_FACE('',(),#42,.T.);` (empty bound list); `#1=TESSELLATED_SHELL('',(),$);`.

Expected kernel behavior

validate `LIST` bounds against schema lower bound at parse time; reject with `E_AGGREGATE_BOUNDS`.

Notes

Cross-oracle: pure-Python Part-21 validator accepts (`accept`); OCCT crashes (`signal(11)`). The crash is on the kernel side; the file is spec-conformant Part-21.

Expected validation

occt=signal(11)/signal(11) gmsh=signal(11) ifc=schema_n/a

  • matches(rb'ADVANCED_FACE\([^;]*,\(\),') or matches(rb'TESSELLATED_SHELL\([^;]*,\(\),')
