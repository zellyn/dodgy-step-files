Ad116 — Non-ASCII (Cyrillic / multi-byte) filename or path causes STEP import to fail

§12.11 adversarial / parser-robustness

P2 — spec deviation (no data loss)

adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad116.stp

Sources

  • FreeCAD #16886
  • bug-reporter language: "STEP import fails on file with Cyrillic name (Ножки.zip)", "fails for files with non-Western paths", "import error with Cyrillic filename".

Sender

Any user with non-Western locale who saves the STEP file under a Cyrillic / Chinese / Japanese filename.

Description

The file content is well-formed Part-21 ASCII; the failure is that the importer (or its OCCT path-handling layer) cannot open the file when the filename or the path contains non-ASCII bytes that the current process locale cannot map. The receiver-side diagnostic surfaces as "import error" with no specific guidance. Distinct from P002 (encoding *inside* the file); here the bytes inside the file are clean and the offending bytes are in the path the OS hands to the reader.

Reproducer recipe

well-formed minimal STEP file (`MANIFOLD_SOLID_BREP` cube). The fixture filename in this repo is plain ASCII (`Ad116.stp`); the catalog entry documents that some readers fail to open the *same content* when saved as `Ножки.stp` or `床.stp`. Provenance tier: bytes-sufficient as a structural representative; the OS-level filename-handling defect is path-side, not file-content-side.

Expected kernel behavior

Heal and accept: file-open path opens via UTF-16 / wide-string Win32 APIs on Windows or UTF-8 path APIs on POSIX; never passes path bytes through `mbstowcs` against the current locale. Reject with E_BAD_PATH_ENCODING if the byte sequence cannot be normalized; never crash.

Notes

**See also**: P002, Le001. Synonyms: "STEP file with Cyrillic filename fails import", "import fails on non-ASCII path", "Ножки.step refuses to open", "Cyrillic file name path encoding bug".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

  • contains(b'MANIFOLD_SOLID_BREP')
  • contains(b'ISO-10303-21')
