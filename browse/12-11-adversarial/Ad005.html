Description

Attribute slot references instance ID never declared, or whose ID exceeds reasonable bounds; resolver dereferences `nullptr` from lookup table.

Reproducer recipe

`#1=ADVANCED_FACE('',(#42),#43,.T.);` where `#42`,`#43` never declared.

Expected kernel behavior

Reject with `E_UNDEFINED_REF` diagnostic: two-pass parse (declare-all then resolve); tolerant mode may warn and accept treating as literal NULL for legacy compatibility.

Notes

Cross-oracle: pure-Python Part-21 validator rejects (reject(E_UNRESOLVED_REFS)); OCCT silently accepts (load is `empty`). OCC auto-heals a spec-level violation.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • matches(rb'ADVANCED_FACE\([^;]*#42[^;]*#43') or contains(b'#999999999')
