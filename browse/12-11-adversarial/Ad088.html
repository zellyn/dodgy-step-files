Ad088 — Crash on reading STEP with malformed parameter values

§12.11 adversarial

adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad088.stp

Sources

  • OCCT MANTIS#0030876
  • OCCT MANTIS#0029362
  • OCCT MANTIS#0029240
  • OCCT MANTIS#0033631 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A STEP entity's numeric parameter contains a malformed value; empty string where a number is expected, comma-separated triple where two are expected, scientific notation with non-digit exponent. Reader's parameter-conversion crashes via an out-of-range error or uncaught numeric-parse exception.

Reproducer recipe

`CARTESIAN_POINT('',(1.0, , 3.0))` (empty middle); `CARTESIAN_POINT('',(1.0,2.0,3.0,4.0))` (extra value); `LINE` with `VECTOR` magnitude `'1e+'` (incomplete exponent).

Expected kernel behavior

parameter parsing emits diagnostic with entity ID and offending parameter index; skip the entity, do not crash.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • matches(rb'CARTESIAN_POINT\([^;]*,\s*,') or matches(rb'CARTESIAN_POINT\([^;]*\([^)]*,\s*,[^)]*\)')
  • matches(rb'\(\s*\d+\.0\s*,\s*,')

Tier-3 assertions

  • load == "ok"
