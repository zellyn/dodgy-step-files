Ad098 — Infinite recursion during ShapeFix after Boolean cut

§12.11 adversarial

adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad098.stp

Sources

  • OCCT MANTIS#0030396 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A Boolean-cut result has a sliver face that, when removed by `ShapeFix`, exposes another sliver face; infinitely. The ShapeFix pipeline lacks a fixpoint guard and recurses until stack overflow.

Reproducer recipe

Boolean cut producing a result with three nested sliver faces, each exposing the next when removed.

Expected kernel behavior

ShapeFix uses a fixed iteration count or relative-change termination; never unbounded recursion.

Notes

**See also**: Tfa056.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'ADVANCED_FACE') >= 3 and contains(b'sliver')
  • count_entity_def(b'ADVANCED_FACE') >= 4
