Ad027 — STEP "zip bomb": 10⁷ tiny instances exhaust memory

Description

File declares N million `#i=CARTESIAN_POINT(..)`; parser allocates O(N) instance pointer table and O(N×K) reverse-reference map. Small input expands to many GB resident.

Reproducer recipe

50 MB file with 5M tiny entity declarations, each holding 100 references → ~40 GB resident.

Expected kernel behavior

streaming-friendly architecture; configurable `max_instances`; abort with `E_INSTANCE_LIMIT`.

Notes

M DoS. **See also**: Ad032, Ad057, Pf013. Validation observed: silent-empty rather than the cited crash. The structural attack pattern (e.g., billion-laughs / cyclic-reference / very-large-string) is demonstrated; production-scale exploitation requires inflating the size factor as described. Kernel-mishandling-by-silent-acceptance is itself a defect signal at fixture scale.
