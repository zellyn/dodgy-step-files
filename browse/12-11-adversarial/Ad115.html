Ad115 — Directory-entry race between `stat()` and `open()` on STEP fixture path

§12.11 adversarial (sub-class: TOCTOU / directory race)

  • CWE-367 (TOCTOU)

Sender

deduced — adversarial filesystem context where a directory entry is replaced between two filesystem operations on the same path

Description

A receiver that performs a path-based `stat()` on a fixture (to enforce a max-size budget, or a "regular file only" check, or a "this is the file we expected" hash check), then performs a separate path-based `open()`, races against any process that can swap the directory entry between the two syscalls. On a multi-tenant build host, an attacker replaces the directory entry (via `rename()`) so `stat()` sees a small benign file and `open()` returns a file descriptor on a much larger or hostile file. Distinct from Ad113 (sibling-pair race) and Ad114 (symlink-following): this entry is the directory-entry-swap vector even when no symlink is present. Bug-reporter language: "stat-vs-open race in STEP loader", "directory swap during validation", "rename() race on fixture path".

Reproducer recipe

a STEP fixture lives at a path whose containing directory is writable by an attacker; the attacker `rename()`s a small benign STEP file into place before the receiver's `stat()` and a hostile/oversized file into place before the receiver's `open()`. The bytes alone cannot demonstrate this; the demonstration requires a concurrent attacker process. The fixture in this catalog documents the scenario in a header comment.

Expected kernel behavior

Heal and accept: open the path once and `fstat()` the resulting file descriptor; never re-resolve the path for any check after the open; treat all path-based file metadata as untrusted. Must not crash on TOCTOU race.

Notes

Third TOCTOU vector after Ad113 (sibling-pair race) and Ad114 (symlink-following) — separate axis (directory-swap, not symlink-swap). Provenance tier: cross-file-state — bytes alone cannot demonstrate this defect; the symptom requires a concurrent attacker process. The static fixture is document-only. **See also**: Ad106, Ad113, Ad114.
