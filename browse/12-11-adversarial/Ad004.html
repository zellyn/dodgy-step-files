Ad004 — Cyclic complex-entity reference graph causes infinite recursion

Description

Complex entity `#A=(B(..) C(#A))` references itself, or longer cycle `#A→#B→…→#A`. Resolver recurses until stack exhausted. Variant: `APPLIED_EXTERNAL_IDENTIFICATION_ASSIGNMENT` whose target path resolves to the very file being read.

Reproducer recipe

`#1=(NAMED_UNIT(*) DERIVED_UNIT_ELEMENT(#1, 1.0));` or external-file reference whose canonical path equals the input file.

Expected kernel behavior

Reject with diagnostic via tarjan-style cycle detection; iterative graph traversal; canonical-path check before opening external refs. Must not infinite loop.

Notes

H DoS; XML billion-laughs analogue. **See also**: Ad026, Ad052, Ad053, Ad085.

occt=empty/empty gmsh=empty ifc=schema_n/a
