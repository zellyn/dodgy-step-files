Ad051 — Reference to non-existent entity number (negative or out-of-range)

§12.11 (sub-class: null-deref)

silent-loss adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad051.stp

Sources

  • 08-occt-gitlog.md G030 (Mantis 0031292)

Description

References to entity numbers beyond DATA section, or legacy negative numbers, yield literal NULL via lookup; older OCCT segfaulted.

Reproducer recipe

`ADVANCED_FACE` referencing `#NNN` where NNN > max_id, or `#-1`.

Expected kernel behavior

treat as literal NULL; substitute defaults; do not segfault. Negative entity numbers (legacy) need pass-correction.

Notes

Cross-oracle: pure-Python Part-21 validator rejects (reject(E_UNRESOLVED_REFS)); OCCT silently accepts (load is `empty`). OCC auto-heals a spec-level violation.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'#-1') or matches(rb'#-\d+')
  • matches(rb'#-\d+')

Tier-3 assertions

  • load == "ok"
