Ad104 — STEP-XML wrapper carries a DTD with external-entity reference (XXE)

Sender

Description

ISO 10303-28 specifies an XML transfer of STEP data. A STEP-XML file may include an internal DTD; XML 1.0 permits an internal DTD to declare a named entity that resolves to an external resource (`<!ENTITY xxe SYSTEM "file:///etc/passwd">`). A receiver that uses an XML parser with external-entity resolution enabled fetches the resource, expands it into the document, and either leaks the content (if the entity is referenced inside an attribute that is later echoed back) or hangs (if the URI points at a slow resource). This is the textbook XXE attack applied to the STEP-XML wrapper. Bug-reporter language: "STEP-XML triggers XXE", "DTD reads sensitive file", "external entity in STEP-XML".

Reproducer recipe

a `.stpx` (STEP-XML) file beginning with `<?xml version="1.0"?> <!DOCTYPE step [<!ENTITY xxe SYSTEM "file:///etc/passwd">]> <step ..>&xxe;</step>` — the entity reference `&xxe;` resolves to the file's contents on parsers with XXE enabled.

Expected kernel behavior

disable external-entity resolution by default in the XML parser used to load STEP-XML; reject documents that declare external-entity references with a precise diagnostic; treat as adversarial.
