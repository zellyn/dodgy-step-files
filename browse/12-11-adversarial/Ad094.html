Ad094 — Shell translator dereferences null on empty face list

§12.11 adversarial

Description

A `CONNECTED_FACE_SET` or `OPEN_SHELL` entity contains an empty face list (`(())`). The shell-translator iterates the face list expecting at least one element, dereferences a null pointer on the first iteration.

Reproducer recipe

STEP file with `OPEN_SHELL('',())` (zero-face shell).

Expected kernel behavior

empty face list is a malformed shell; diagnose and skip; never crash.

Notes

**See also**: Tsh023, Tsh024. **OCC behavior**: silently accepts (no diagnostic, empty result); outside catalog's allowed set ({reject}). Kernel-bug witnessed: receivers must reject this fixture per the catalog's stated invariant.
