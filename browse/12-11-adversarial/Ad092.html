Ad092 — Crash reading large STEP file: exception during transfer

P2 — spec deviation (no data loss)

Description

A STEP file containing several million entities exceeds internal buffer / map sizes. Reader processes most of the file then crashes near the end with an out-of-range exception in the entity-map rebuild. Rest of the document is lost.

Reproducer recipe

STEP file with ~10 million `CARTESIAN_POINT` entities (all anonymous, distinct IDs); minimal solid at the end. Reader crashes during transfer phase.

Expected kernel behavior

Heal and accept via dynamically-sized data structures; document size is bounded only by available memory; emit progress and diagnostics rather than aborting at fixed thresholds. Must not crash on large files.
