Ad032 — Schema-EXPRESS rule recursion bomb

§12.11 (sub-class: resource-exhaustion / DoS)

crash adversarial

View raw fixture (.stp) step-examples/12-11-adversarial/Ad032.stp

Sources

  • 12-adversarial.md A032

Description

WHERE rules invoke EXPRESS functions transitively; attacker references entities such that rule evaluation loops through entity graph repeatedly. Even O(n²) evaluation with cycles is weaponisable.

Reproducer recipe

graph of 10⁴ `EDGE_CURVE` entities each referencing two `VERTEX_POINT`s in star topology that triggers WHERE-rule re-checks.

Expected kernel behavior

per-file rule-evaluation budget; abort with `E_RULE_BUDGET`.

Notes

M DoS. **See also**: Ad027, Ad054, Ad055, Pf030. Validation observed: silent-empty rather than the cited crash. The structural attack pattern (e.g., billion-laughs / cyclic-reference / very-large-string) is demonstrated; production-scale exploitation requires inflating the size factor as described. Kernel-mishandling-by-silent-acceptance is itself a defect signal at fixture scale.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

  • count_entity_def(b'EDGE_CURVE') >= 10

  • load == "ok"
