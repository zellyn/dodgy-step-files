Description

Schema-driven late binding takes entity from instance table and casts without dynamic-type check; if upstream type-validation pass was skipped (perhaps because of an earlier parse error), downstream geometry code dereferences via wrong-type vtable.

Reproducer recipe

declare `#10=CARTESIAN_POINT(..)`; reference `#10` in slot whose schema-required type is `DIRECTION`.

Expected kernel behavior

every attribute bind must check dynamic type vs schema; reject with `E_TYPE_MISMATCH`.
