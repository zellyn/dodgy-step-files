Wr020 — Re-export drops feature labels and product names

§12.13 writer-pathology (sub-class: round-trip data loss)

P1 — silent data loss

round-trip writer

View raw fixture (.stp) step-examples/12-13-writer-pathology/Wr020.stp

Sources

  • OCCT name-round-trip tests
  • CAx-IF round-trip notes
  • bug-reporter language: "feature names disappeared"

Sender

Writers without a label/name propagation layer

Description

User-assigned feature labels — e.g. `PRODUCT.name = 'left_bracket'`, face labels via `PRESENTATION_LAYER_ASSIGNMENT`, descriptive `name` strings on `MANIFOLD_SOLID_BREP` — are replaced with empty strings or auto-generated identifiers (`'BREP_001'`, `''`). The geometry is preserved but the human-readable labelling is lost. Bug-reporter language: "feature names dropped", "names replaced with auto-IDs", "STEP file forgot the part name".

Reproducer recipe

a STEP fixture where every `name` attribute is `''` and `PRODUCT.name = 'BREP_001'` despite a comment indicating the input had named features.

Expected kernel behavior

Heal and accept: preserve `name` attributes and `PRESENTATION_LAYER_ASSIGNMENT` content end-to-end.

Notes

Subset of the broader "metadata stripped on re-export" pattern.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b"PRODUCT('BREP_")
  • count(b"BREP_001") >= 1 or contains(b'BREP_')
