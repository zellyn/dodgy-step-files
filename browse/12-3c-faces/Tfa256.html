Tfa256 — Face with two coincident-edge wires, multi-wire gate satisfied

Prior sole fixture Tfa074 encodes the identical reused-edge pattern but places it as the ONLY wire on its face — the `nbWires>=2` gate never opens, so the fix never fires and the sliver survives unmerged. This entry gives the same face a second, ordinary wire so the gate is genuinely satisfied.

Description

A single `PLANE` `ADVANCED_FACE` carries TWO wires: `FACE_OUTER_BOUND` is an ordinary valid 10×10 square, and `FACE_BOUND` is a 2-edge slit *inside* the square — the SAME `EDGE_CURVE` entity `E` (a 4-unit segment from (3,3,0) to (7,3,0)) referenced twice by two `ORIENTED_EDGE`s, both at `.T.` (FORWARD). Because the face now genuinely has 2 wires, coincident-edge wire merging's multi-wire precondition is live and reachable, unlike Tfa074.

Reproducer recipe

`ADVANCED_FACE` with a valid `FACE_OUTER_BOUND` wire plus a second `FACE_BOUND` wire whose `EDGE_LOOP` references one `EDGE_CURVE` twice via two FORWARD `ORIENTED_EDGE`s — on a live `OPEN_SHELL`/`SHELL_BASED_SURFACE_MODEL` path.

Expected kernel behavior

when a face has 2+ wires and one of them is a 2-edge loop reusing one edge entity at matching (FORWARD/FORWARD) orientation, that wire bounds no area and must be dropped from the face, leaving the other wire(s) intact.

Notes

**See also**: Tfa074 (identical reused-edge pattern, but single-wire — the gate this entry satisfies never opens there), Tfa232 (4-edge loop reusing a curve — a different, filter-probe pattern outside the `NbEdges()==2` gate), Tfa209 (5-edge wire with a duplicate pair — also outside the 2-edge gate). Live-verified (this worktree's OCP/OCCT 7.8.1, default import path, heal-on and heal-off identical): `occt=shape(1)/shape(1)`. The authored file has 2 wires and 5 `EDGE_CURVE` entities (4 square + 1 reused twice); the loaded shape carries only 1 wire and 4 edges — the entire coincident-edge inner wire (both its `ORIENTED_EDGE` references to `E`) is dropped outright, not merely left unmerged or flipped to a valid-but-degenerate orientation. `face[0].area==99.99999999999999`, matching the full 10×10 square with no trace of the slit subtracted. This is the opposite outcome from Tfa074, where the identical reused-edge pattern survives translation as a live 2-edge zero-area sliver (OCCT there just flips one `ORIENTED_EDGE` to REVERSED to keep the wire topologically valid, without recognizing it as a duplicate to remove) because that face has only one wire and the removal repair's `nbWires>=2` gate never opens. Synonyms: "two coincident edges wire multi-wire face", "coincident-edge wire merging nbWires gate", "slit wire dropped from multi-wire face", "reused edge wire removal second wire present", "coincident-edge hole wire genuinely fires".
