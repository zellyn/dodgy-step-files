Tfa043 — Single-face dispatcher: classify-and-heal small face

Sources

  • OCCT `ShapeFix_FixSmallFace::FixFace` (`ShapeFix_FixSmallFace.hxx:76`)

Description

A standalone ADVANCED_FACE supplied without context. The dispatcher must classify it as spot, strip, or pin (or none), and then call the specific fixer. The classification is the entry-point for any small-face workflow.

Reproducer recipe

A near-zero-area face supplied as the only face of a fixture.

Expected kernel behavior

classify, dispatch, return the modified face (or null if removed). A kernel may also choose to refuse to mutate single faces and require shell-level context.

Notes

Functional duplicate of Tfa040 at a different API layer; both must be documented because they're separately testable. Synonyms: "small spot face", "tiny 0.001 mm sliver face", "near-zero-area face needs classification", "single face below tolerance", "face dispatcher classify spot strip pin", "structurally identical to Tfa040 / Tfa041 small spot face".

  • face[0].sliver_aspect_max_min > 1e3
