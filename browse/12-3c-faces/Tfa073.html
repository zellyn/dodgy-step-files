Description

Strip-face shared-edge construction with asymmetric endpoint-pair merging. V1 merged to V3 (dev < tol), but V2 not merged to V4 (dev > tol), creating degenerate edge with one matched vertex and one unmatched. Asymmetry arises from sequential V1 vs V3 check followed by independent V2 vs V4 check.

Reproducer recipe

Two edges E1=(V1,V2) and E2=(V3,V4) where dev(V1,V3)=0.00005 (<tol), but dev(V2,V4)=1.5 (>>tol). V1 merged to V3; V2 remains unmerged; shared edge created with (V3, V4) semantics violated.

Expected kernel behavior

Kernel should either merge both endpoint pairs or neither. Asymmetric merging produces degenerate shared edge that breaks strip-face topology.
