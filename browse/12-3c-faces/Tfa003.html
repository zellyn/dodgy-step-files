Tfa003 — FaceOuterBound translation failed (face incomplete without outer wire)

§12.3c face-sliver-sewing

P1 — silent data loss

Sources

  • 04-occt-translation Q019 (StepToTopoDS_TranslateFace.cxx:725-737)

Description

The bound entity referenced from `FACE_OUTER_BOUND.bound` failed translation (e.g., empty `EDGE_LOOP`, all edges dropped). Without an outer bound the face is incomplete.

Reproducer recipe

`FACE_OUTER_BOUND` whose `bound` is an `EDGE_LOOP` with all `ORIENTED_EDGE`s referencing edges that themselves had null curves (Q006).

Expected kernel behavior

Warn and accept: drop the offending face; emit "TP fail: outer bound translation" diagnostic; coerce the shell to continue.

Notes

**See also**: Gp001, Tfa001. Synonyms: "outer boundary failed to translate", "face dropped because its outer wire was empty", "all edges in outer loop went missing", "face has no usable outer boundary after import".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
