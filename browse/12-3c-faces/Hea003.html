Description

A shell with one or more free bounds (open boundaries). The kernel's free-bound analyzer must compute, per bound, the area of the contour, perimeter, average length-to-width ratio, average width, and notch list — all derived from the same boundary representation in one pass to avoid recomputing.

Reproducer recipe

An open shell containing a single rectangular face; the analyzer reports a single free bound with width 10, length 10, area 100, no notches.

Expected kernel behavior

Heal and accept: produce a structured per-bound report; downstream tools filter by area/perimeter/ratio thresholds.

Notes

Replaces ad-hoc per-property queries with a unified pipeline. Synonyms: "free-bound metrics computed in one pass", "area perimeter notches in single analyzer", "shell free-bound properties computation", "free-bound analyzer single-pass".
