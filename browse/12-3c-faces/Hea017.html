Hea017 — Extrude of 2D Offset of Sketch fails STEP export as non-manifold (offset trace not closed)

Sources

  • FreeCAD #23694
  • bug-reporter language: "Extrude of 2D Offset of Sketch won't export properly as STEP", "the contents are invalid/empty", "Orca slicer says it's non-manifold", "STL is fine".

Sender

FreeCAD Part Workbench 2D-Offset feature applied to a sketch path that has self-intersecting offset traces (non-manifold offset).

Description

A Pad whose profile is a 2D Offset of an open path emits a STEP whose extruded sweep has a discontinuity in the side-wall shell where the offset trace self-intersected. The on-disk symptom is a `MANIFOLD_SOLID_BREP` whose side-wall sweep contains two `ADVANCED_FACE`s that share an edge whose `EDGE_CURVE` has a discontinuous parametric trace; at one point the curve doubles back on itself.

Reproducer recipe

STEP body with an `ADVANCED_FACE` whose `EDGE_LOOP` contains an `ORIENTED_EDGE` whose underlying `EDGE_CURVE` is a `B_SPLINE_CURVE_WITH_KNOTS` whose first and last control point are the same but with opposite tangents — a degenerate-loop edge.

Expected kernel behavior

writer detects self-intersecting offset traces and rejects with clear diagnostic; receivers should report non-manifold edges.

Notes

Synonyms: "Extrude of 2D Offset fails STEP export", "self-intersecting offset trace produces non-manifold", "step from 2d offset is invalid", "orca says offset extrude is non-manifold".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(3) ifc=schema_n/a

Byte assertions

  • contains(b'B_SPLINE_CURVE_WITH_KNOTS')
  • contains(b'EDGE_LOOP')

Tier-3 assertions

  • n_faces_total == 1
