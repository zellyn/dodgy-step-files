Description

Valid B-spline saddle-surface face loads intact; twisted-face checking is never invoked on an ordinary read

Reproducer recipe

Expected kernel behavior

Accept: a degree-3x3 B-spline saddle surface (negative Gaussian curvature) is ordinary, valid geometry whose normal legitimately flips sign across the saddle center, so a read must load all 6 companion faces with their encoded 4 edges each and orientation counts (forward/reversed) intact, without any twist classification.

Notes

**See also**: Tfa080, Tfa092. Corrected 2026-07-16 (truth-in-labeling audit): retitled/redescribed — original claimed twisted-face checking misclassifies saddle geometry; that method is never invoked on an ordinary read (per-face oracle check confirms clean load, all edges present). Part of the ~127-entry face-repair/small-face-check misnomer family — see `BACKLOG.md` Q14. Synonyms: "saddle B-spline face loads without twist check", "hyperbolic paraboloid face valid load".

  • face[0].edge_orientations.forward == 4
  • face[1].edge_orientations.reversed == 4
