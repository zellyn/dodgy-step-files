Hea008 — Transfer parameters using projection (not affine remapping)

§12.3 (sub-class: shape-healing) — parameter transfer

P1 — silent data loss

topology

Sources

  • OCCT `ShapeAnalysis_TransferParametersProj::Perform` (`ShapeAnalysis_TransferParametersProj.hxx:52`)

Description

An edge for which 3D-to-2D parameter transfer requires actual projection onto the host surface, not just affine remapping. Used when surface curvature varies along the edge — affine maps would produce wrong sample positions.

Reproducer recipe

An edge on a NURBS surface where the surface's metric varies by 10× along the edge length.

Expected kernel behavior

Heal and accept: per-sample, project the 3D-curve point onto the surface; build the U value from the projection; emit residual error per sample.

Notes

Specialized variant of Hea007 for projection-based transfer. Synonyms: "edge curve on B-spline surface with control points clustered at one end and spread far apart at the other", "metric varies along surface", "uniform pcurve in UV does not correspond to uniform 3D arc-length", "non-uniform parameter spacing", "projection-based parameter transfer needed", "control points clustered close-packed then far apart".
