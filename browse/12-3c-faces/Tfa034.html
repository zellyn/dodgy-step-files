Tfa034 — Face orientation flag inconsistent with shell normal (FixFaceOrientation)

§12.3c face-sliver-sewing

topology

View raw fixture (.stp) step-examples/12-3c-faces/Tfa034.stp

Sources

  • 05-occt-shapefix F033 (ShapeFix_Shell::FixFaceOrientation)
  • 09-healing-menus H101 (Netgen FixFaceOrientation)
  • 13-quaoar B026
  • 11-vendor W010, W043

Description

One or more faces in a closed shell have orientation flags inverted relative to the outward direction. Visualization shows mixed red/blue normals. Common after Booleans or sloppy hand-built shells; also from sender mirror-block instances.

Reproducer recipe

`MANIFOLD_SOLID_BREP` where one `ADVANCED_FACE` is referenced with inverted sense (`.F.` where `.T.` required) so its normal points inward.

Expected kernel behavior

heal; orientation-propagation flood-fill from a known-correct seed; flip face/wire orientations consistently with face's outward normal; reject if shell is too disconnected to orient consistently.

Notes

**See also**: Tsh009, Tsh018, Twi024. Synonyms: "face normal points wrong way", "face orientation flipped relative to shell", "mixed inward and outward normals on shell", "boolean leaves inverted face flags", "shell has some faces inside-out".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(27) ifc=schema_n/a

Tier-3 assertions

  • n_edges_total >= 24
  • face[0].surface_type == "plane"
  • face[5].surface_type == "plane"
