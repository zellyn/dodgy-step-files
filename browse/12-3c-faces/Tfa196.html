Description

A toroidal face whose minor radius approaches zero creates a "pinch" singularity where opposite surface points coincide. The singularity detector must recognize this degenerate locus; incomplete classification allows pinched geometries to pass validation unchecked, producing unpredictable healing outcomes downstream.

Reproducer recipe

Expected kernel behavior

heal: classify pinch as boundary singularity and mark for extra scrutiny; reject: if pinch radius falls below configured tolerance

Notes

Cross-oracle: OCCT caches singularity state; re-computation may fail on modified surfaces. Synonyms: "toroidal pinch-point undetected", "torus minor radius degeneracy", "singularity cache miss on periodic surface".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(9) ifc=schema_n/a

Tier-3 assertions

  • n_faces_total == 1
  • face[0].surface_type == "torus"
  • face[0].quadric.major_radius == 5.0
  • face[0].quadric.minor_radius == 0.005
