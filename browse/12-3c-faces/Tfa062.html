Tfa062 — Face crash during fix on invalid face — null inner wire

§12.3c faces/sewing

P0 — receiver crash / hang / OOM

Sources

  • OCCT MANTIS#0026524
  • OCCT MANTIS#0033179 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

An `ADVANCED_FACE` lists a `FACE_BOUND` with a null / unresolvable wire reference. The face-fix routine, when iterating bounds, dereferences the null wire and segfaults instead of skipping or rejecting.

Reproducer recipe

`ADVANCED_FACE('',(#100,$),#10,.T.);` where the second bound is the literal `$` (omitted), or where it points to a non-existent entity ID.

Expected kernel behavior

bounds list with null/missing entries must be rejected with diagnostic before any geometric computation; never dereference a null bound.

Notes

Cross-oracle: pure-Python Part-21 validator rejects (reject(E_UNRESOLVED_REFS)); OCCT silently accepts (load is `empty`). OCC auto-heals a spec-level violation.

Expected validation

occt=signal(11)/signal(11) gmsh=signal(11) ifc=schema_n/a

Byte assertions

  • contains(b"ADVANCED_FACE('null_bound',(#56,$),#14,.T.)")
  • contains(b'#56,$')
