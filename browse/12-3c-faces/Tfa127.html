Description

Thin rectangular face (10x1.5) loads as an ordinary valid face; pin-face checking is never invoked to classify it

Reproducer recipe

Expected kernel behavior

Accept: a 10x1.5mm rectangular face is an ordinary, unambiguous quadrilateral regardless of its aspect ratio, so a read must load it as a single, valid 4-edge face (n_faces_total == 1) without any pin-morphology classification.

Notes

Corrected 2026-07-16 (truth-in-labeling audit): retitled/redescribed — original claimed pin-face checking reports a false negative on an oversized pin; that method is never invoked on an ordinary read, so no classification (correct or incorrect) is observable. Part of the ~127-entry face-repair/small-face-check misnomer family — see `BACKLOG.md` Q14. Synonyms: "thin rectangular face loads without pin classification".
