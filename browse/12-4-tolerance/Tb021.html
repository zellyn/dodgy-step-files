Tb021 — Multiple UNCERTAINTY entries with conflicting values, no labels

Description

A `GEOMETRIC_REPRESENTATION_CONTEXT` lists three `UNCERTAINTY_MEASURE_WITH_UNIT`s with values 1e-3, 1e-6, 1e-9 and no distinguishing `name` field. The spec allows the list. A kernel taking `min` (most strict) uses 1e-9. A kernel taking `max` (most lax) uses 1e-3. A kernel taking the first uses 1e-3. A kernel taking the last uses 1e-9. Same file, four different working tolerances depending on receiver policy. All other tolerance-boundary defects in this section are amplified by this ambiguity.

Reproducer recipe

PRODUCT-wrapped simple shape; context lists three unlabelled `UNCERTAINTY_MEASURE_WITH_UNIT`s with values 1e-3, 1e-6, 1e-9.

Expected kernel behavior

multiple uncertainties must be either resolved by a documented selection policy (min/max/labelled) or rejected as ambiguous.
