N020 — Coordinate-system origin offset: hard-coded BOARD_OFFSET 0.05mm in PCB→MCAD pipeline

§12.4 (sub-class: origin-offset / working precision)

P1 — silent data loss

assembly

Sources

  • 22-niche-forums Y001 (KiCad #21127)

Sender

KiCad pcbnew STEP exporter

Description

KiCad hard-codes a `BOARD_OFFSET = 0.05 mm` constant on every component's `AXIS2_PLACEMENT_3D`, floating components above the board surface to avoid Z-fighting in viewers. Downstream MCAD tools that build enclosure geometry against the PCB top face see consistent 0.05 mm misalignment that doesn't correspond to any physical clearance.

Reproducer recipe

Export any KiCad PCB to STEP. Inspect the `MAPPED_ITEM` for any footprint-attached 3D model: its `AXIS2_PLACEMENT_3D` location's Z is shifted 0.05 mm relative to the board top face.

Expected kernel behavior

accept; surface a flag warning "consumer-applied placement offset detected" when small uniform Z offsets across many child instances are present.

Notes

Synonyms: "KiCad PCB components float 0.05 mm above board", "hard-coded board offset misaligns components", "PCB to MCAD pipeline shifts parts by 0.05 mm", "every component placed slightly above PCB top".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • count_entity_def(b'AXIS2_PLACEMENT_3D') == 3
  • matches(rb'0\.05')
  • not_contains(b'EDGE_CURVE')

Tier-3 assertions

  • shape_null == True
