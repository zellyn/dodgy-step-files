Description

A live 1-face quad whose bottom-left vertex is displaced 0.05mm from its edge's authored `LINE` (only that endpoint — the ordinary per-vertex-bump path, not the line-shift path N174 covers). the edge-translation stage bumps that vertex's tolerance to `1.000001*0.05≈0.0500000500` — three orders of magnitude above the file's declared 1.0E-7 model uncertainty and any realistic `settol` target band. The `ShapeProcess` `"SetTolerance"` operator (`settol`) calls the tolerance-limiting pass(shape, val/ratio, val*ratio)`; against this fixture's live, reader-produced tolerance data (not N001's `shape_null==True` scaffold), the outlier genuinely falls outside a realistic band and gets clamped.

Reproducer recipe

a 1-face `ADVANCED_FACE`/`OPEN_SHELL` whose bottom-left `VERTEX_POINT` sits 0.05mm off the corresponding edge's authored `LINE` (temp1≠temp2, so the ordinary per-vertex bump fires, not the line-shift branch), wrapped in a normal product chain.

Expected kernel behavior

`settol` (or an equivalent tolerance-sanity pass) should be applied by default, or the reader should surface a diagnostic when a repaired tolerance lands far outside any declared-uncertainty-derived band, rather than leaving the outlier silently in place unless a user opts in to `SetTolerance`.

Notes

Live-verified (2026-07-12, OCP 7.8.1, direct probing — not mirrored/guessed): after the reader.TransferRoots()`, the displaced vertex's tolerance is exactly `0.05000005` (== `1.000001*0.05`). Calling the tolerance-limiting pass().LimitTolerance(shape, 1.0E-4, 1.0E-2)` — the exact API `settol` invokes, band `[val/ratio,val*ratio]` with val=1.0E-3, ratio=10 — on this live shape returns `True` (at least one tolerance modified) and clamps that vertex's tolerance DOWN to `0.01`; the four untouched vertices (at the file's declared `1.0E-7` uncertainty) simultaneously get raised UP to the band floor `0.0001`. `settol` is an opt-in `ShapeProcess` sequence operator (same category as this corpus's `dropsmallsolids`-driven Tsh238/Tsh239), not run by the reader's default transfer. Provenance tier: runtime-only (the operator is opt-in; the fixture delivers a live shape with a genuinely out-of-band tolerance for the operator to act on, demonstrated via a direct, documented API call reproducing `settol`'s own invocation). **See also**: N001 (dead scaffold precedent), N174 (sibling per-vertex-bump mechanism, line-shift subvariant), N173 (multi-vertex/multi-edge sibling). Synonyms: "tolerance outside acceptable band", "settol clamp", "the tolerance-limiting pass LimitTolerance band violation", "reader-inflated vertex tolerance exceeds target ratio".
