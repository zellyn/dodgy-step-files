N023 — `EDGE_CURVE` based on `LINE` displaced from true vertex position

§12.4 (sub-class: working precision / edge geometry inconsistency)

P1 — silent data loss

Sender

FPX Expert 2013 (PCB design system)

Description

STEP files emit an `EDGE_CURVE` whose underlying `LINE` is parallel-displaced from the line that actually passes through both vertex points. Direction is correct; position is offset. Translator must shift the line so it passes through both vertices, preserving direction.

Reproducer recipe

VERTEX_POINT A at `(0,0,0)`, VERTEX_POINT B at `(10,0,0)`, EDGE_CURVE referring to LINE whose `pnt`/`dir` give a parallel line offset by 0.001 mm.

Expected kernel behavior

heal — replace the line so it passes through both vertices, preserving original direction.

Notes

**See also**: Gs021. Synonyms: "edge LINE doesn't pass through its vertices", "line direction correct but offset", "translator must shift line to vertex points", "underlying line parallel to actual edge".

  • count_entity_def(b'LINE') == 1
