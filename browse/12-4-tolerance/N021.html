N021 — VRML/STEP origin convention mismatch within same producer

§12.4 (sub-class: origin-offset)

P1 — silent data loss

spec-violation

View raw fixture (.stp) step-examples/12-4-tolerance/N021.stp

Sources

  • 22-niche-forums Y002 (KiCad #23235)

Sender

KiCad pcbnew (VRML vs STEP exporters)

Description

KiCad VRML export places Z=0 at the board *center*; STEP export places Z=0 at the board *bottom*. Downstream tools mixing the two formats see components shifted by half-board-thickness, even though both come from the same producer.

Reproducer recipe

For a 1.6 mm board, export both VRML and STEP from the same KiCad project. Inspect the bounding box and assembly origin in each.

Expected kernel behavior

heal — when a producer with known origin-convention drift is detected (via `FILE_DESCRIPTION` heuristics), warn and offer re-anchoring.

Notes

Synonyms: "VRML uses board center, STEP uses board bottom", "Z=0 differs between formats from same producer", "components shifted by half board thickness across formats".
