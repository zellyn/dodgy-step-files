Tb013 — Coordinate at 1e-300 tests as "near zero" only under denormalized math

  • synthesized time-bomb.

Description

A `CARTESIAN_POINT` has coordinate `(1.0E-300, 0, 0)` — a denormalized double. A kernel comparing `|x| < tol` for tol=1e-7 says "yes, near zero". A kernel comparing `x*x < tol*tol = 1e-14` says `1e-600` which underflows to 0, also "yes, near zero". A kernel that flushes-to-zero in its math library may treat `1e-300` as exactly zero before any tolerance compare. A kernel without flush-to-zero may keep the value alive and trip on `1.0/(1e-300)` overflow elsewhere. The same input behaves differently depending on the host's float environment.

Reproducer recipe

`CARTESIAN_POINT('escape',(1.0E-300,0.0,0.0))` used as one vertex of a degenerate edge in a wrapped face; declared tolerance 1e-7.

Expected kernel behavior

subnormal/denormal coordinates must be rejected or normalized to a documented sentinel before downstream math; the "near zero" classification must be defined explicitly.
