Sender

Description

The bottom edge of a live quad face is authored as a `LINE` from `(0,0,0)` to `(10,0,0)`, but BOTH its `VERTEX_POINT` endpoints sit at `(0,0.001,0)` and `(10,0.001,0)` — an IDENTICAL 0.001mm perpendicular offset at both ends, preserving the vertex-to-vertex distance (unlike N007, which displaces only ONE endpoint). `StepToTopoDS_TranslateEdge`'s line-shift gate — `Abs(temp1-temp2)<preci` AND `Abs(U2-U1-dist(pnt1,pnt2))<Precision::Confusion()` AND the curve `IsKind(Geom_Line)` — is satisfied by this "correct direction, wrong position" signature, so instead of merely enlarging vertex tolerance, OCCT RIGIDLY SHIFTS the `LINE` along its own direction so it passes exactly through the displaced vertices.

Reproducer recipe

an `EDGE_CURVE` whose `LINE` is authored at the nominal (undisplaced) position, but both of whose `VERTEX_POINT` endpoints are offset by the SAME perpendicular amount, preserving the segment length, wired into a live `ADVANCED_FACE`/`OPEN_SHELL`.

Expected kernel behavior

reject the inconsistent curve/vertex data, or heal it while flagging that the AUTHORED curve geometry (not just a tolerance value) was altered — silently rewriting the curve's location changes the model's geometric record without any visible trace in the output beyond the shifted numbers.

Notes

Live-verified (2026-07-12, OCP 7.8.1, direct `BRep_Tool::Curve`/`BRep_Tool::Tolerance` probing on the transferred edge — not mirrored/guessed): the bottom edge's bound 3D curve after transfer is a `Geom_Line` whose location is `(0.0, 0.001, 0.0)` — genuinely shifted off the authored `(0,0,0)` origin to pass through the displaced vertices, confirming the line-shift branch (not the generic per-vertex-bump branch) fired. Both endpoint vertices' tolerance is `0.001000001` (== `1.000001*0.001`) — the SAME bump formula N007 uses, applied even though the underlying curve was rigidly repositioned; the two untouched vertices retain the file's declared `1.0E-7` tolerance. **See also**: N007 (ordinary-gap sibling — only one endpoint displaced, takes the generic bump branch instead), N172 (single-outlier settol-band sibling). Provenance tier: bytes-sufficient. Synonyms: "displaced line correct direction", "PCB export line shift", "FPX Expert line shifted vertex gap", "rigid line reposition on projection mismatch", "bug 25415 line displaced true position".
