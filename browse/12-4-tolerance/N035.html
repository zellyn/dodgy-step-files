N035 — Default tolerance precision: missing decimal-place qualifier

§12.4 (sub-class: PMI numeric)

P1 — silent data loss

pmi

View raw fixture (.stp) step-examples/12-4-tolerance/N035.stp

Sources

  • 02-caxif (PMI v4.1 §4.1)

Description

Some CAD systems ignore tolerance values that lack an explicit decimal-place qualifier even if a global default precision is set. The fallback hierarchy is: precision at tolerance value → precision at nominal value → global default. Receivers that don't walk the chain show wrong-precision tolerance.

Reproducer recipe

Dimension with nominal value `5.0`, tolerance `+0.01/-0.01`, but no `precision_qualifier` on either the value or the nominal, and no global default.

Expected kernel behavior

accept; fall through the precision hierarchy correctly; emit warning when default is needed.

Notes

**See also**: Pmi008. Synonyms: "tolerance ignored without decimal-place qualifier", "default precision not picked up", "tolerance value shown wrong precision", "fallback chain broken for precision qualifier".

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a

Byte assertions

  • count_entity_def(b'PLUS_MINUS_TOLERANCE') == 2
  • contains(b'0.01') and contains(b'-0.01')
  • contains(b'5.0')

Tier-3 assertions

  • shape_null == False
  • n_vertices_total == 1
