N126 — ShapeAnalysis_ShapeTolerance.InTolerance vertex-filtering-inverted

§12.4 tolerance (sub-class: vertex-filtering bug)

topology

Sources

  • OCCT/ShapeAnalysis_ShapeTolerance.cxx:131-141 (vertex case uses tol >= valmax)

Description

InTolerance filters vertices by tolerance range but uses inverted comparison (tol >= valmax) vs FACE/EDGE (tol <= valmax). Query for vertices with tolerance in [0.001, 0.002] returns only those >= 0.002, reversing the range semantics.

Reject or heal by using correct comparison operator
