Le006 — `\X4\…\X0\` (UCS-4) escape with hex run not divisible by 8 or containing surrogate code points

§12.1a encoding/strings (sub-class: `\X4\` directive)

P1 — silent data loss

Description

`\X4\` requires hex digit count divisible by eight (one 32-bit code point per group). Tools emit 4-digit or 6-digit groups, embed UTF-16 surrogate halves directly (illegal as UCS-4 code points), or omit `\X0\`.

Reproducer recipe

`'pi=\X4\03C0\X0\'` (only 4 digits); `'oops=\X4\0000D83D\X0\'` (lone surrogate); `'\X4\00110000\X0\'` (above U+10FFFF).

Expected kernel behavior

reject; tolerant readers should at minimum flag surrogate code points (U+D800.U+DFFF) and values above U+10FFFF as malformed.

Notes

Synonyms: "X4 UCS-4 escape malformed", "supplementary plane character broken", "lone surrogate in X4 escape", "code point above U+10FFFF in STEP", "X4 hex run not divisible by 8".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'\\X4\\03C0\\X0\\')
  • contains(b'\\X4\\0000D83D\\X0\\')
  • contains(b'\\X4\\00110000\\X0\\')
