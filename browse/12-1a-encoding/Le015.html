Le015 — Unterminated string literal

§12.1a encoding/strings (sub-class: unterminated string)

encoding

View raw fixture (.stp) step-examples/12-1a-encoding/Le015.stp

Sources

  • T009/stepcode Str.cc:162-169, expscan.l:240-244
  • A008/CVE-2024-1847-style OOB-read pattern

Description

A string with an opening apostrophe but no matching close advances the scanner past the end of the intended attribute and may swallow the rest of the file or read sensitive memory until a lucky `'` byte is found.

Reproducer recipe

`#1=IFCPERSON($,$,'unterminated,$);\n#2=..` or `#1=PERSON('unclosed_string_then_eof`

Expected kernel behavior

bound the scan to remaining buffer size; emit `E_UNTERMINATED_STRING` with offset; do not silently re-synchronise on a later `'`.

Notes

Often pairs with subsequent OOB write when the caller allocates `(end - start)` bytes. **See also**: Ad001, Ls029. Synonyms: "unterminated string in STEP", "missing closing quote", "string runs to EOF", "parser hangs on unclosed string", "STEP string never closes".

Expected validation

occt=reject/reject gmsh=reject ifc=schema_n/a

  • not_contains(b'END-ISO-10303-21;')
  • matches(rb"#20=PERSON\(")
