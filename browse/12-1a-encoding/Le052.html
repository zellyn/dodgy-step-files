Le052 — `\X2\…\X0\` (UCS-2) escape: whitespace splits the hex run

§12.1a encoding/strings (sub-class: `\X2\` directive)

P1 — silent data loss

spec-violation encoding

Sources

  • Q065/StepData_StepReaderData.cxx:218-272
  • N005/ISO 10303-21 Ed.3 §6.4.3.4

Description

The hex run inside `\X2\.\X0\` must be contiguous (multiple of four hex digits). Embedding whitespace between two 4-digit groups is malformed even if it would be a legal continuation in some Java/host string forms.

Reproducer recipe

`'name=\X2\30A2 30A4\X0\rest'` — a space between `30A2` and `30A4`.

Expected kernel behavior

emit `E_BAD_X2_DIRECTIVE`; reject the string or, in lenient mode, drop the whitespace and continue with a warning.

Notes

**See also**: Le005, Le051, Le053. Synonyms: "whitespace inside X2 hex run", "X2 hex broken by space", "X2 groups split by whitespace", "whitespace mid-Unicode-escape", "X2 payload non-contiguous".

Expected validation
