Le011 — `\N\` notation directive misused as C-style newline escape

§12.1a encoding/strings (sub-class: `\N\` directive)

crash encoding

View raw fixture (.stp) step-examples/12-1a-encoding/Le011.stp

Sources

  • N010/ISO 10303-21 Ed.3 §6.4.3 Table 4
  • W032/CAD Exchanger CHANGES v3.24.12

Description

`\N\` toggles a notation context. Generators emit it without the spec-required following digit, or assume it means "newline" (it does not; newlines must be encoded as `\X\0A`). The same defect can also span a physical line break in the source.

Reproducer recipe

`'line1\N\line2'` (writer assumed `\N\` == LF).

Expected kernel behavior

spec semantics differ from C `\n`; tolerant readers should at least not crash and should warn that `\N\` is not a newline escape.

Notes
