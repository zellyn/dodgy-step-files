Le039 — `\PE\` selector letter outside the legal A.I range

§12.1a encoding/strings (sub-class: lesser-known directives)

P2 — spec deviation (no data loss)

spec-violation encoding

View raw fixture (.stp) step-examples/12-1a-encoding/Le039.stp

Sources

  • 16-iso-spec ISO 10303-21 Ed.3 §6.4.3 (`\PE\` page selector A.I)

Description

ISO 10303-21 defines code pages A through I (nine pages) for `\PA\.\PI\` alphabet selectors and `\PE\` as the alphabet-extend directive whose follow byte denotes one of the same nine pages. An out-of-range selector (e.g. `Z`) does not name any defined page; the receiver must reject, fall back, or treat the operand as a literal and resync.

Reproducer recipe

`PRODUCT.name='bad=\PE\Z\S\xx'` — operand `Z` is not in the legal selector range A.I.

Expected kernel behavior

reject with a diagnostic citing the invalid selector; fallback (treat as default page) is acceptable if a warning is emitted.

Notes

**See also**: Le037. Synonyms: "PE selector outside A.I range", "out-of-range page selector letter", "STEP PE with selector Z", "invalid page-selector letter", "code-page letter not in legal set".
