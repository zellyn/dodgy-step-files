Le030 — `\PE\` selector and `\Q\x` directive support

§12.1a encoding/strings (sub-class: lesser-known directives)

P2 — spec deviation (no data loss)

encoding

View raw fixture (.stp) step-examples/12-1a-encoding/Le030.stp

Sources

  • S003/SFA-User-Guide-v7 Fig. 90 (`\PE\`, `\Q\x`)

Description

ISO 10303-21 also defines `\PE\` (UCS extended) and `\Q\x` (alternate-quote) directives that some legacy generators emit. Few parsers implement these, so the bytes pass through to the user as literal `\PE\` or `\Q'`.

Reproducer recipe

`'\PE\foo'`; `'\Q\'foo\Q\'`

Expected kernel behavior

Heal and accept: at minimum, recognise the directives and consume the documented number of operands without lexer desynchronisation; warn-and-accept if decoding is not fully implemented.

Notes

**See also**: Le012. Synonyms: "PE directive not implemented", "Q directive passes through as literal", "alternate-quote escape unrecognised", "legacy Q directive in STEP", "STEP PE escape ignored".

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a

Byte assertions

  • contains(b'\\PE\\') or contains(b'\\Q\\')
  • contains(b'\\Q\\') or contains(b'\\PE\\')
