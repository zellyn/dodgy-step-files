Le012 — Unrecognised backslash control directive in a string

§12.1a encoding/strings (sub-class: malformed `\X\`/`\X2\`/`\X4\`/`\S\`/`\P{X}\`/`\F\`/`\N\` directives)

P1 — silent data loss

encoding

Sources

  • S003/SFA-User-Guide-v7 §7 Fig. 90

Description

A string contains a backslash directive that is not one of the spec-recognised forms (`\X\`, `\X2\…\X0\`, `\X4\…\X0\`, `\S\x`, `\Q\x`, `\PE\`, `\N\n`, `\F\`).

Reproducer recipe

embed `'foo\Z\bar'` in a string-valued attribute.

Expected kernel behavior

reject the directive; recover by passing the bytes through literally with a warning.

Notes

**See also**: Le030. Synonyms: "unknown backslash escape in string", "made-up control directive", "STEP rejects unknown escape", "vendor-extension escape passes through", "non-standard backslash sequence". Provenance tier: bytes-only — defect is context/metadata OCC does not read at BRep load; mutation-test verified oracle-invisible (2026-07-01).

occt=empty/empty gmsh=empty ifc=schema_n/a
