Pf019 — Memory leaks in STEP/IGES controller initialisation enum tables

§12.10 (sub-class: leak)

P2 — spec deviation (no data loss)

Sources

  • 18-other-issues.md I019 (OCCT #1024)

Description

LeakSanitizer flags allocations originating from the static enum-table initialisation triggered by the STEP/IGES controller constructor; static singletons are retained on shutdown rather than freed at exit.

Reproducer recipe

Build with LeakSanitizer, initialise the STEP controller, exit cleanly. Observe leak reports for the static enum tables.

Expected kernel behavior

Heal and accept: free typed-value tables on library teardown; coerce to bounded resident memory.

Expected validation

occt=empty/empty gmsh=empty ifc=schema_n/a
