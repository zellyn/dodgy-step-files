Description

A complex entity references itself, an `EXTERNAL_FILE` resolves to the same file under translation, an `SHAPE_REPRESENTATION_RELATIONSHIP` whose `rep_2` is itself, or a composite curve segment cycles. Reference resolver loops forever or stack-overflows.

Reproducer recipe

- `#1=(NAMED_UNIT(*) SI_UNIT(..) DERIVED_UNIT_ELEMENT(#1, 1.0));` - `APPLIED_EXTERNAL_IDENTIFICATION_ASSIGNMENT` to same `.step` file path - `SHAPE_REPRESENTATION_RELATIONSHIP` whose `rep_2` is itself - `COMPOSITE_CURVE_SEGMENT` whose parent_curve is the composite
