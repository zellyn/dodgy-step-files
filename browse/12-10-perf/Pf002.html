Sender

IFC pipeline (FZK Haus IfcStair) → OCCT writer

Description

`write_step_file` on a 214 423-entity model takes ~30 minutes, dominated by repeated linear scans over the entity table while serializing references. Common shape: a dense forward-reference `VERTEX_POINT` / `EDGE_CURVE` / `ADVANCED_FACE` web sized to tens of thousands of entities each, exercising O(N²) writer reference-resolution cost.

Reproducer recipe

Convert any IFC architectural model with > 100k entities through OCCT's STEP writer; time the write phase.

Expected kernel behavior

Heal and accept (performance contract): sub-minute write at 200k entities via amortized O(N) writer with indexed reference resolution. Must not hang.
