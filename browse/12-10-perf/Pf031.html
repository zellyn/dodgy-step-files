Pf031 — STEP read parsing slow due to single-pass tokenisation

§12.10 performance

P2 — spec deviation (no data loss)

performance

Sources

  • OCCT MANTIS#0023979 (OCCT MANTIS tracker 502 as of 2026-05-02)

Description

A STEP reader's parser reads each character in single-byte fashion through a buffered stream, calling the buffer's underlying read function per character. For a 100 MB file, this issues hundreds of millions of OS read calls, dominating runtime.

Reproducer recipe

Large (100 MB) STEP file with millions of small entities. Read; observe parser CPU dominated by I/O syscalls.

Expected kernel behavior

Heal and accept: parser uses bulk-buffered I/O; tokenisation operates on memory-mapped or fully-buffered input. Must not hang on cold-cache reads.
