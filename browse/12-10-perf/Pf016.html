Pf016 — STEP assembly reader hangs in Transfer on cyclic `SHAPE_REPRESENTATION_RELATIONSHIP` web (Catia/NX-emitted file, OCCT 7.9)

Sender

CATIA / NX (file `250709r8000_asm-all`)

Description

STEP file is accepted by Catia and NX but hangs OCCT 7.9 indefinitely during the Transfer phase (post-parse). Common shape: a small set of `SHAPE_REPRESENTATION` entities connected by many `SHAPE_REPRESENTATION_RELATIONSHIP` edges forming a cyclic cross-relation web (e.g. 8 SRs joined by 16 SRRs as a ring with diagonals), causing the Transfer traversal to follow cycles indefinitely.

Reproducer recipe

Real assembly file; reproduces on any code path calling `reader.Transfer(doc)` after `ReadFile` returns `IFSelect_RetDone`.

Expected kernel behavior

Reject with E_TRANSFER_TIMEOUT diagnostic: bound transfer time, detect pathological cyclic SHAPE_REPRESENTATION_RELATIONSHIP loops, and bail with a diagnostic. Must not hang. Must not infinite loop.

Notes

distinct from #417 (huge-shell ShapeFix slowness). **See also**: A026.

Expected validation

occt=shape(1)/shape(1) gmsh=shape(1) ifc=schema_n/a
