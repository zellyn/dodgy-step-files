Description

A wire-healing pass iterates until its modification flags settle; each fix can introduce a new defect that needs another pass (e.g., reordering exposes self-intersection; closing a gap exposes a tolerance violation). Vendors document "running healing twice converts splines to analytics" — an admission that single-pass coverage is insufficient. Without an iteration cap, pathological inputs loop indefinitely.

Reproducer recipe

STEP wire with simultaneous reorder need, 3D/2D mismatch, and self-intersecting micro-loop; run an iterative wire-healing pass with default settings.

Expected kernel behavior

Reject with E_ITERATION_LIMIT diagnostic: bounded iteration count with an explicit ceiling; bail with a structured error on divergence. Must not infinite loop.
