Pf013 — Entity-count amplification: tiny file, many GB resident

Description

A 50 MB file declares 5M tiny entities each holding 100 references; the parser allocates O(N) instance pointer table and O(N) reverse-reference map, peaking at ~40 GB resident. Hub-style back-reference patterns (10⁷ tiny entities pointing at one HUB) cause contiguous-vector reallocation thrash.

Reproducer recipe

synthetic file with 5M `CARTESIAN_POINT`s each referencing 100 neighbours; or 10M small entities all referencing one hub entity.

Expected kernel behavior

Heal and accept: streaming-friendly architecture with opt-in eager loading; coerce typical reads to bounded resident memory. Must not OOM.
