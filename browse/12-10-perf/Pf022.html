Pf022 — Non-deterministic empty-export from in-memory state leakage

§12.10 (sub-class: non-deterministic)

round-trip performance

View raw fixture (.stp) step-examples/12-10-perf/Pf022.stp

Sources

  • 22-niche-forums.md Y020 (gmsh #3332)
  • 13-quaoar.md B011

Sender

gmsh writing STEP from a once-populated, now-cleared model; OCCT Draw `stepread` followed by `stepwrite`

Description

After import-then-partial-clear, the writer emits "No suitable CAD data found" non-deterministically; depends on past actions, not on whether the document currently contains shapes. In OCCT Draw, a `stepread` populates a transient model that the next `stepwrite` re-uses, doubling the output and producing a file twice the expected size.

Reproducer recipe

import STEP, `gmsh.model.remove()` some entities, then `gmsh.write("out.step")`; or `stepread file.stp sh *` followed by `stepwrite a sh_1 file.stp`.

Expected kernel behavior

Heal and accept: writer state must be a pure function of input; normalize global state per call.
