Description

`doc = TDocStd_Document(TCollection_ExtendedString ("STEP"))` triggers process abort under code-server / extension-host runtimes when reading a multi-level assembly. Symptom of resource / signal-handling assumptions that fail at scale.

Reproducer recipe

Run inside `code-server` container; create the document while opening a multi-level assembly STEP.
