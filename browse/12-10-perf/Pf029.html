Pf029 — `TDocStd_Document` creation aborts process under VSCode server runtime

§12.10 (sub-class: OOM / process-fatal at scale)

crash performance

View raw fixture (.stp) step-examples/12-10-perf/Pf029.stp

Sources

  • 18-other-issues.md I048 (pythonocc-core #1428)

Description

`doc = TDocStd_Document(TCollection_ExtendedString ("STEP"))` triggers process abort under code-server / extension-host runtimes when reading a multi-level assembly. Symptom of resource / signal-handling assumptions that fail at scale.

Reproducer recipe

Run inside `code-server` container; create the document while opening a multi-level assembly STEP.

Expected kernel behavior

no process abort; recoverable error;

Notes

Validation observed: this is a deliberately scaled-down representative; the structural pattern is present but the production-scale resource exhaustion / catastrophic timing is not exercised at fixture size. To trigger the documented kernel-crash, multiply the entity-replication factor by ~10^N as noted in the reproducer recipe.
