# STEP Example Files

Original-work STEP files, one per canonical entry in `STEP_PROBLEM_CATALOG.md`. Each file exhibits the defect described by its corresponding entry. **None of these files are copied from third-party sources**; they are constructed from scratch to license-cleanly demonstrate the defect class.

## Layout

Files are organized by §12.x category:

- `12-1a-encoding/`: encoding & string-literal defects (Le-prefix entries)
- `12-1b-header/`: header & instance-numbering defects (Lh)
- `12-1c-syntax/`: Part-21 syntax / grammar defects (Ls, In)
- `12-2a-pcurves/`: pcurve defects (Gp)
- `12-2b-nurbs/`: NURBS / B-spline defects (Gn)
- `12-2c-surfaces/`: surface & curve degeneracy defects (Gs, Gb)
- `12-3a-shells/`: shell / orientation defects (Tsh, Bo, Sw, Ps)
- `12-3b-wires/`: wire / loop / edge defects (Twi)
- `12-3c-faces/`: face / sewing / free-bound defects (Tfa, Hea)
- `12-4-tolerance/`: tolerance & numerical-precision defects (N, Tb)
- `12-5-units/`: unit & coordinate-system defects (U)
- `12-6-assembly/`: assembly-hierarchy defects (A, P)
- `12-7-pmi/`: PMI / GD&T / AP242 feature-definition defects (Pmi)
- `12-8-mixed/`: tessellation / validation-property / AP238 / AP209 / AP203 / AP210 (M, Os, Fi)
- `12-10-perf/`: scale & performance defects (Pf)
- `12-11-adversarial/`: adversarial / parser-robustness / security defects (Ad)
- `12-12-cross-product/`: synthesised multi-defect cross-product fixtures (Xp)
- `12-13-writer-pathology/`: producer-side / writer-emit defects (Wr)

## Filename convention

Each file is named `{entry-id}.stp` matching its catalog entry. For example:

- `12-1a-encoding/Le001.stp`: UTF-8 BOM at start of `ISO-10303-21;`
- `12-3b-wires/Twi023.stp`: Pcurves shifted by integer period on closed surface (FixShifted)
- `12-11-adversarial/Ad027.stp`: Resource-exhaustion via deep entity-graph cycles

## File header convention

Every file's HEADER section names the entry ID in `FILE_NAME` arg 1, and includes a comment in the DATA section above the defect-bearing entities describing what is being demonstrated. For files that intentionally violate Part-21 syntax (most §12.1 and §12.11 entries), the comment lives at the top of the file as a `/* ... */` Part-21 comment outside any section.

## Generation provenance

Files were generated by automated agents reading entries in `STEP_PROBLEM_CATALOG.md` and constructing minimal Part-21 cases. Each file was adversarially reviewed by a separate agent to verify it actually exhibits the claimed defect.
